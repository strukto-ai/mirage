An HTTP `200` from a shell request means that the request completed.
Check `exit_code` to determine whether the command succeeded.

API errors return JSON with `detail` and `request_id`. Preserve the request ID
when reporting a failed request.

## HTTP status codes

| Status | Meaning | Recovery |
| --- | --- | --- |
| `400` | A request field, filter, or cursor is invalid. | Correct the field named in `detail`. |
| `401` | The bearer token is missing, invalid, or expired. | Supply a valid token or sign in again. |
| `403` | The account or API key cannot perform the operation. | Check the account and key permissions. |
| `404` | The requested resource was not found. | Verify the resource name or UID and account. |
| `409` | The operation conflicts with an existing resource or its current state. | Resolve the conflict before retrying. |
| `413` | The request exceeds the body-size limit. | Reduce the request size. |
| `429` | A request or resource limit was reached. | Honor `Retry-After` when present and reduce the request rate. |
| `502` | An upstream service is unavailable. | Retry later; preserve the request ID if the failure continues. |
| `503` | A required service is unavailable or not configured. | Retry later or contact support with the request ID. |

Each endpoint's collapsed **Errors** section lists its documented failures.
Only successful response examples appear in the right pane.

## Examples

### Missing or invalid credentials

```json
{"detail":"missing bearer token","request_id":"req_example"}
```

Send the token as `Authorization: Bearer <token>`.
See [Authentication](/api/authentication).

### Workspace name already exists

```json
{"detail":"workspace demo already exists","request_id":"req_example"}
```

Choose another name for a new workspace or retrieve the existing workspace.

### Invalid log page size

```json
{"detail":"limit must be 1-200","request_id":"req_example"}
```

Use `limit` from `1` to `200` on [List workspace logs](/api/operations/workspaces/list-workspace-logs).

For errors from a server you operate, see the [HTTP guide](/home/access/http).
