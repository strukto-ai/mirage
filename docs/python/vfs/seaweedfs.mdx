`SeaweedFSVFS` mounts one bucket on a SeaweedFS S3 gateway: every object becomes
a file and every `/` in a key a folder. It reaches the gateway (port `8333` by
default) through its S3 API. Credentials are set up on the
[SeaweedFS page](/home/setup/seaweedfs).

## Install

```bash
pip install "mirage-ai[s3]"
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.seaweedfs import SeaweedFSConfig, SeaweedFSVFS

config = SeaweedFSConfig(
    bucket=os.environ["SEAWEEDFS_BUCKET"],
    endpoint_url=os.environ["SEAWEEDFS_ENDPOINT"],
    access_key_id=os.environ["SEAWEEDFS_ACCESS_KEY"],
    secret_access_key=os.environ["SEAWEEDFS_SECRET_KEY"],
)
ws = Workspace({"/seaweedfs": SeaweedFSVFS(config)}, mode=MountMode.WRITE)

result = await ws.shell("ls /seaweedfs && find /seaweedfs -name '*.csv'")
print(await result.stdout_str())
await ws.close()
```

`endpoint_url` is required, since the server is self-hosted. `region` defaults
to `us-east-1`. A mount takes `MountMode.READ`, `WRITE` or `EXEC`.

## Authentication

Credentials come from the first of:

1. `access_key_id` and `secret_access_key`, an identity's key pair from the
   gateway's S3 config, with `session_token` for temporary credentials.
2. `aws_profile`, a profile in `~/.aws/credentials`.
3. The AWS credential chain: environment variables, then the instance or
   container role.

The identity needs the `Read` and `List` actions on the bucket, and `Write` to
write. A gateway with no identities accepts any key pair. A request the
credentials may not make answers `Permission denied`.

## Layout

```text
/seaweedfs/
  data/
    config.json
    file.txt
  reports/
    q1.csv
    q2.csv
```

`/seaweedfs/data/file.txt` is the key `data/file.txt`. Folders come from the `/`
in keys; SeaweedFS stores no folder objects.

## Behavior

- **Key prefix:** `key_prefix="users/42/"` mounts only that part of the bucket,
  so `/seaweedfs/notes.md` is the key `users/42/notes.md`. A leading `/` is
  dropped and a trailing `/` added.
- **Path style:** requests are path-style; `path_style` defaults to `True`.
- **Blaxel Agent Drive:** a drive is backed by SeaweedFS. Set `endpoint_url` to
  the drive's `s3Url` and use a drive access token's credentials as the key
  pair.

## Integration

SeaweedFS answers these commands through its own API, so fewer objects are read.
See [Integration](/home/integration/overview).

- `find`: one recursive listing.
- `du`: one recursive listing.
- `ls -R` and `tree`: one recursive listing.
