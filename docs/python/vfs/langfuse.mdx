`LangfuseVFS` mounts one Langfuse project as read-only files: its traces with
their observations and scores, sessions, prompt versions and datasets. The key
pair is set up on the [Langfuse page](/home/setup/langfuse).

## Install

```bash
pip install "mirage-ai[langfuse]"
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.langfuse import LangfuseConfig, LangfuseVFS

config = LangfuseConfig(
    public_key=os.environ["LANGFUSE_PUBLIC_KEY"],
    secret_key=os.environ["LANGFUSE_SECRET_KEY"],
    host=os.environ["LANGFUSE_HOST"],
)
ws = Workspace({"/langfuse": LangfuseVFS(config)}, mode=MountMode.READ)

result = await ws.shell("ls /langfuse/traces && ls /langfuse/prompts")
print(await result.stdout_str())
```

`default_trace_limit` sets how many traces a listing shows, and
`default_from_timestamp` lists only traces from an ISO 8601 time on.

## Authentication

The mount reads with a project's key pair, the public key (`pk-lf-...`) and
the secret key (`sk-lf-...`), and sees only that project. `host` is the
project's region, such as `https://cloud.langfuse.com` (EU) or
`https://us.cloud.langfuse.com` (US), or a self-hosted URL. The mount reads
the Langfuse v4 API, so a self-hosted instance must run Langfuse v4.

## Layout

```text
/langfuse/
  traces/
    <trace-id>.json
  sessions/
    <session-id>/
      <trace-id>.json
  prompts/
    <prompt-name>/
      1.json
      2.json
  datasets/
    <dataset-name>/
      items.jsonl
      runs/
        <run-name>.jsonl
```

- **`traces/`:** one `.json` file per trace: the trace's root observation,
  with its other observations (spans, generations, events) in `observations`
  and its scores in `scores`. `input` and `output` are the strings Langfuse
  stores; `jq '.input | fromjson'` parses a JSON one.
- **`sessions/`:** the sessions of the traces `traces/` lists, each holding
  its own traces.
- **`prompts/`:** one folder per prompt name, one file per version (`1.json`,
  `2.json`) with the prompt content and metadata.
- **`datasets/`:** one folder per dataset, with `items.jsonl` (its items) and
  `runs/`, one `.jsonl` file per experiment run.

## Behavior

- **Read only:** no command changes Langfuse.
- **Trace limit:** `traces/` lists up to `default_trace_limit` traces (100),
  from `default_from_timestamp` on. The cap bounds the listing, not the tree:
  `stat` and `cat` still reach an older trace by its id, and
  `sessions/<id>/` serves only that session's traces.
- **Search:** `grep` and `rg` read each file as `cat` renders it. Langfuse has
  no content search, so `grep -r` over `traces/` reads every trace the listing
  returns.
- **No counts:** Langfuse has no count endpoint, so `wc -l traces/` is not
  supported.
