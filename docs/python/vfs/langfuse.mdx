The Langfuse VFS exposes LLM observability data (traces, observations,
prompts, datasets, scores) as a virtual filesystem mounted at some prefix
such as `/langfuse/`.

For credential setup, see [Langfuse Setup](/home/setup/langfuse).

Install the extra:

```bash
pip install "mirage-ai[langfuse]"
```

## Config

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.langfuse import LangfuseConfig, LangfuseVFS

config = LangfuseConfig(
    public_key=os.environ["LANGFUSE_PUBLIC_KEY"],
    secret_key=os.environ["LANGFUSE_SECRET_KEY"],
    host=os.environ.get("LANGFUSE_HOST", "https://cloud.langfuse.com"),
)
vfs = LangfuseVFS(config=config)
ws = Workspace({"/langfuse": vfs}, mode=MountMode.READ)
```

## Filesystem Layout

```text
/langfuse/
  traces/
    <trace-id>.json
    ...
  sessions/
    <session-id>/
      <trace-id>.json
      ...
  prompts/
    <prompt-name>/
      <version>.json
      ...
  datasets/
    <dataset-name>/
      items.jsonl
      runs/
        <run-name>.jsonl
        ...
```

Example:

```text
/langfuse/
  traces/
    abc123.json
    def456.json
  sessions/
    chat-session-1/
      abc123.json
      ghi789.json
  prompts/
    summarize/
      1.json
      2.json
    classify/
      1.json
  datasets/
    eval-v1/
      items.jsonl
      runs/
        run-2026-04-01.jsonl
```

### Traces

`/langfuse/traces/` lists traces (capped at `default_trace_limit`,
from `default_from_timestamp` on). The cap bounds the listing, not the tree:
`stat` and `cat` still reach an older trace by its id, and `sessions/<id>/`
serves only that session's traces.
Each trace is a `.json` file containing the full trace object with nested
observations (spans, generations, events).

### Sessions

`/langfuse/sessions/` groups traces by session ID. Each session directory
contains trace `.json` files belonging to that session.

### Prompts

`/langfuse/prompts/` lists prompt names as directories. Each prompt directory
contains version files (`1.json`, `2.json`, etc.) with the prompt content
and metadata.

### Datasets

`/langfuse/datasets/` lists dataset names as directories. Each contains
`items.jsonl` (dataset items) and `runs/` with run results.

## grep and rg

grep and rg read each file as `cat` renders it, at every scope; `grep -r`
and `rg` walk a directory. No provider-side content search is used, so a
search over `traces/` reads every trace the listing returns.

```bash
grep -r "error" "/langfuse/traces/"
rg -l "classify" "/langfuse/prompts/"
```

## Limits

| Command                  | Limit behavior                                       |
| ------------------------ | ---------------------------------------------------- |
| `ls traces/`             | Returns up to `default_trace_limit` traces           |
| `cat traces/<id>.json`   | Full trace (single doc, no limit needed)             |
| `grep -r traces/`         | Reads every trace `ls traces/` lists                 |
| `wc -l traces/`          | Not supported (Langfuse has no count endpoint)       |

## Cache

The Langfuse VFS uses `IndexCacheStore` (same as other mounts).
Index entries store trace IDs, session IDs, and prompt names.

## Integration

The most files one command reads on Langfuse. [Integration](/home/integration/overview) explains each command.

| Command | On Langfuse |
| --- | --- |
| Full scan | `grep -r`, `find`, `du` and other walks stop after [`full_scan_limit`](/home/integration/search#full_scan_limit) files (default 1000); a glob matching more, `tar -c`, `cp -r` and `rm -r` are refused. `-1` for no limit |

## Example

```python
import asyncio
import os

from dotenv import load_dotenv

from mirage import MountMode, Workspace
from mirage.vfs.langfuse import LangfuseConfig, LangfuseVFS

load_dotenv(".env.development")

config = LangfuseConfig(
    public_key=os.environ["LANGFUSE_PUBLIC_KEY"],
    secret_key=os.environ["LANGFUSE_SECRET_KEY"],
)
vfs = LangfuseVFS(config=config)


async def main():
    ws = Workspace({"/langfuse": vfs}, mode=MountMode.READ)

    # List top-level resources
    r = await ws.shell("ls /langfuse/")
    print(await r.stdout_str())

    # List traces
    r = await ws.shell("ls /langfuse/traces/")
    print(await r.stdout_str())

    # Read a specific trace
    traces = (await r.stdout_str()).strip().splitlines()
    if traces:
        r = await ws.shell(f'cat "/langfuse/traces/{traces[0]}"')
        print((await r.stdout_str())[:500])

    # List prompts
    r = await ws.shell("ls /langfuse/prompts/")
    print(await r.stdout_str())

    # Search the listed traces
    r = await ws.shell('grep -r "error" "/langfuse/traces/"')
    print(await r.stdout_str())

    # List datasets
    r = await ws.shell("ls /langfuse/datasets/")
    print(await r.stdout_str())



if __name__ == "__main__":
    asyncio.run(main())
```

## Shell Commands

| Command         | Notes                                                  |
| --------------- | ------------------------------------------------------ |
| `ls`            | List traces, sessions, prompts, datasets               |
| `cat`           | Read trace JSON, prompt version, dataset items         |
| `head` / `tail` | Read the beginning/end of a file; directories are rejected |
| `grep` / `rg`   | Lexically search files; recursive forms walk listed files |
| `jq`            | Query JSON trace/prompt data                           |
| `stat`          | Metadata (trace count, prompt versions, dataset items) |
| `find`          | Search across resources with `-name`                   |
| `tree`          | Directory tree view                                    |
