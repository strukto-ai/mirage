`R2VFS` mounts one Cloudflare R2 bucket: every object becomes a file and every
`/` in a key a folder. It reaches R2 through its S3-compatible API at
`https://<account_id>.r2.cloudflarestorage.com`. Credentials are set up on the
[R2 page](/home/setup/r2).

## Install

```bash
pip install "mirage-ai[r2]"
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.r2 import R2Config, R2VFS

config = R2Config(
    bucket=os.environ["R2_BUCKET"],
    account_id=os.environ["R2_ACCOUNT_ID"],
    access_key_id=os.environ["R2_ACCESS_KEY_ID"],
    secret_access_key=os.environ["R2_SECRET_ACCESS_KEY"],
)
ws = Workspace({"/r2": R2VFS(config)}, mode=MountMode.WRITE)

result = await ws.shell("ls /r2 && find /r2 -name '*.csv'")
print(await result.stdout_str())
await ws.close()
```

A bucket in a jurisdiction has its own endpoint, such as
`https://<account_id>.eu.r2.cloudflarestorage.com`; set `endpoint_url` to it. A
mount takes `MountMode.READ`, `WRITE` or `EXEC`.

## Authentication

Credentials come from the first of:

1. `access_key_id` and `secret_access_key`, an R2 API token's key pair, with
   `session_token` for temporary credentials.
2. `aws_profile`, a profile in `~/.aws/credentials`.
3. The AWS credential chain: environment variables, then the instance or
   container role.

The token needs **Object Read only** on the bucket, or **Object Read & Write**
to write. A request the credentials may not make answers `Permission denied`.

## Layout

```text
/r2/
  data/
    config.json
    file.txt
  reports/
    q1.csv
    q2.csv
```

`/r2/data/file.txt` is the key `data/file.txt`. Folders come from the `/` in
keys; R2 stores no folder objects.

## Behavior

- **Key prefix:** `key_prefix="users/42/"` mounts only that part of the bucket,
  so `/r2/notes.md` is the key `users/42/notes.md`. A leading `/` is dropped and
  a trailing `/` added.

## Integration

R2 answers these commands through its own API, so fewer objects are read. See
[Integration](/home/integration/overview).

- `md5sum`: the object's ETag, when it is the MD5 (a single-part upload,
  unencrypted or under SSE-S3).
- `find`: one recursive listing.
- `du`: one recursive listing.
- `ls -R` and `tree`: one recursive listing.
