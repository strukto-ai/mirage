`NextcloudVFS` mounts a [WebDAV](http://www.webdav.org/specs/rfc4918.html)
server: Nextcloud, ownCloud, Hetzner Storage Share or any other WebDAV
endpoint. Its folders and files appear as they are, with their own names and
bytes. The URL and app password are set up on the
[Nextcloud page](/home/setup/nextcloud).

## Install

```bash
pip install "mirage-ai[nextcloud]"
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.nextcloud import NextcloudConfig, NextcloudVFS

config = NextcloudConfig(
    url=os.environ["NEXTCLOUD_URL"],
    username=os.environ["NEXTCLOUD_USERNAME"],
    password=os.environ["NEXTCLOUD_PASSWORD"],
)
ws = Workspace({"/nc": NextcloudVFS(config)}, mode=MountMode.WRITE)

result = await ws.shell("ls /nc && find /nc -name '*.md'")
print(await result.stdout_str())
```

`url` is the WebDAV URL of the user's files, such as
`https://cloud.example.com/remote.php/dav/files/alice/`. `verify_ssl=False`
turns off the TLS check only for some requests; reads, most writes and
listings always verify the certificate.

## Authentication

The mount sends `username` and `password` as Basic Auth; without them it sends
no credentials. Use an app password (Settings, Security in Nextcloud) rather
than the account password: it can be revoked on its own. A request the server
refuses answers `Permission denied`.

## Layout

```text
/nc/
  Documents/
    notes.md
    contract.pdf
  Photos/
    2024/
      cat.jpg
```

`/nc/Documents/notes.md` is `<NEXTCLOUD_URL>/Documents/notes.md` on the
server.

## Behavior

- **Partial reads:** reads stream in chunks, and partial reads such as
  `head -c` send HTTP `Range` requests.
- **Writes:** a write buffers the whole file before it uploads. `cp`, `mv`,
  `rm` and `mkdir` run as WebDAV `COPY`, `MOVE`, `DELETE` and `MKCOL`.
- **Snapshots:** a snapshot keeps the mount's settings but not the password,
  so hand the password back when loading it. Files are not checked for
  changes on replay.

## Integration

Nextcloud answers these commands through its own API, so fewer files are read.
See [Integration](/home/integration/overview).

- `md5sum`, `sha256sum` and the other hash commands: the digest Nextcloud
  keeps (`oc:checksums`), when the uploading client set one.
- `find`: one recursive listing.
- `du`: one recursive listing.
- `ls -R` and `tree`: one recursive listing.
