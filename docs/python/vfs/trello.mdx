`TrelloVFS` mounts Trello as read-only JSON files: workspaces, boards, lists,
cards with their comments, members and labels. Set up the API key and token as in [Trello setup](/home/setup/trello).

## Install

```bash
pip install mirage-ai
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.trello import TrelloConfig, TrelloVFS

config = TrelloConfig(
    api_key=os.environ["TRELLO_API_KEY"],
    api_token=os.environ["TRELLO_API_TOKEN"],
)
ws = Workspace({"/trello": TrelloVFS(config)}, mode=MountMode.READ)

result = await ws.shell("tree -L 4 /trello/workspaces")
print(await result.stdout_str())
await ws.close()
```

`workspace_id` or `board_ids` limits the mount to one workspace or some
boards. `base_url` points at a proxy.

## Behavior

- **Read only:** the mount cannot change cards. Use the
  [`trello`](/python/cli/trello) CLI to create, move, assign and comment on
  cards; the tree serves the same entities as JSON files. The CLI takes
  `workspace_id` and `board_ids` in its own config, so it covers the boards
  the mount lists only when both are configured alike.
- **Recent writes:** Trello indexes a write some time after it lands, so a
  search can miss a recent change. See Integration.

    **Supported Unix Commands for VFS**

    Unix commands work on each path as on a local filesystem, as far as the path supports them:

    | Path | Supported |
    | --- | --- |
    | `/<path>` | Commands that read files (`ls`, `cat`, `grep`, `find`, `jq` and the rest). `grep -r` and `rg` with `-w` ask `trello` which files may match. |

    **Limitations of Unix Commands for VFS**

    Where a path differs from a local filesystem:

    | Path | Limitations |
    | --- | --- |
    | `/<path>` | Read only: no command changes files. Without `-w`, `grep -r` and `rg` read every file. `trello` answers only for `workspaces/*/boards/*/lists/*/cards/*/card.json`; `grep -r` and `rg` read every other file. `grep -r`, `find` and `du` stop after 1000 files; a glob matching more, `tar -c`, `cp -r` and `rm -r` are refused. |

    Run `man <cmd>` or `<cmd> --help` for one command's usage.
