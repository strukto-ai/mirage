The Ceph VFS is a thin wrapper over the [S3 VFS](/python/vfs/s3).
It maps a `CephConfig` to an `S3Config` and reuses the exact same backend,
commands, and behavior as S3, it just points at your Ceph Rados Gateway
`endpoint_url` and uses path-style addressing by default.

Ceph RGW is self-hosted, so `endpoint_url` is **required** (there is no
region-derived host). Uses aioboto3 against the gateway's S3-compatible API.

Install the extra:

```bash
pip install "mirage-ai[s3]"
```

## Config

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.ceph import CephConfig, CephVFS

config = CephConfig(
    bucket=os.environ["CEPH_BUCKET"],
    endpoint_url=os.environ["CEPH_ENDPOINT_URL"],
    access_key_id=os.environ["CEPH_ACCESS_KEY_ID"],
    secret_access_key=os.environ["CEPH_SECRET_ACCESS_KEY"],
    # Optional:
    # region="us-east-1",   # default
    # path_style=True,      # default
    # timeout=30,
    # proxy="http://proxy:8080",
)
vfs = CephVFS(config)
ws = Workspace({"/ceph": vfs}, mode=MountMode.READ)
```

Both `READ` and `WRITE` modes are supported.

{/* generated: config-table ceph start */}
| Field | Required | Default | Description |
| --- | --- | --- | --- |
| `bucket` | yes |  | Name of the bucket to mount. |
| `region` | no | `'us-east-1'` | Region requests are signed for; the gateway's endpoint does not depend on it. |
| `endpoint_url` | yes |  | URL of the self-hosted S3 gateway, such as `http://localhost:9000`. |
| `access_key_id` | no |  | Access key ID, used only together with `secret_access_key`. Unset falls back to the AWS credential chain: `aws_profile`, the environment, the shared credentials file, then an instance role. Redacted in snapshots. |
| `secret_access_key` | no |  | Secret access key paired with `access_key_id`. Redacted in snapshots. |
| `session_token` | no |  | Session token for temporary credentials, sent with the access key pair. Redacted in snapshots. |
| `aws_profile` | no |  | Named profile in the shared AWS config and credentials files that supplies credentials when no access key pair is given. |
| `path_style` | no | `True` | Address the bucket in the URL path (`<endpoint>/<bucket>/<key>`) instead of as a subdomain of the endpoint. |
| `key_prefix` | no |  | Key prefix inside the bucket that the mount treats as its root; keys outside it are not visible. Leading slashes are dropped and a trailing `/` is added. |
| `timeout` | no | `30` | Seconds to wait to connect, and for each read of a response, before the request fails. |
| `proxy` | no |  | Proxy URL for every HTTP and HTTPS request to the endpoint. Redacted in snapshots. |
{/* generated: config-table ceph end */}

## Example

```python
import asyncio
import os

from dotenv import load_dotenv

from mirage import MountMode, Workspace
from mirage.vfs.ceph import CephConfig, CephVFS

load_dotenv(".env.development")

config = CephConfig(
    bucket=os.environ["CEPH_BUCKET"],
    endpoint_url=os.environ["CEPH_ENDPOINT_URL"],
    access_key_id=os.environ["CEPH_ACCESS_KEY_ID"],
    secret_access_key=os.environ["CEPH_SECRET_ACCESS_KEY"],
)
vfs = CephVFS(config)


async def main() -> None:
    ws = Workspace({"/ceph/": vfs}, mode=MountMode.READ)

    r = await ws.shell("ls /ceph/")
    print(await r.stdout_str())

    r = await ws.shell("find /ceph/ -name '*.json'")
    print(await r.stdout_str())


if __name__ == "__main__":
    asyncio.run(main())
```

## Notes

- Ceph registers under its own `VFSName` and routes through the same `core/s3`
  implementation, so the full S3 shell-command set applies. See the
  [S3 VFS](/python/vfs/s3) for the complete command reference,
  range reads, streaming, and the index cache fast path.
- For credential setup, see [Ceph Setup](/home/setup/ceph).
