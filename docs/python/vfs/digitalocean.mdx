The DigitalOcean VFS is a thin wrapper over the [S3 VFS](/python/vfs/s3).
It maps a `DigitalOceanConfig` to an `S3Config` and reuses the exact same
backend, commands, and behavior as S3, it just derives the right Spaces
endpoint from `region`. Uses aioboto3 against DigitalOcean Spaces'
S3-compatible API.

The endpoint is computed from `region` as `<region>.digitaloceanspaces.com`
(e.g. `nyc3.digitaloceanspaces.com`). Pass `endpoint_url` to override.

Install the extra:

```bash
pip install "mirage-ai[s3]"
```

## Config

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.digitalocean import DigitalOceanConfig, DigitalOceanVFS

config = DigitalOceanConfig(
    bucket=os.environ["DO_SPACE"],
    region=os.environ.get("DO_REGION", "nyc3"),
    access_key_id=os.environ["DO_ACCESS_KEY_ID"],
    secret_access_key=os.environ["DO_SECRET_ACCESS_KEY"],
    # Optional:
    # endpoint_url="https://nyc3.digitaloceanspaces.com",
    # timeout=30,
    # proxy="http://proxy:8080",
)
vfs = DigitalOceanVFS(config)
ws = Workspace({"/data": vfs}, mode=MountMode.READ)
```

Both `READ` and `WRITE` modes are supported.

| Field | Required | Default | Description |
| --- | --- | --- | --- |
| `bucket` | yes |  | Name of the bucket to mount. |

| `secret_access_key` | no |  | Secret access key paired with `access_key_id`. Redacted in snapshots. |
| `session_token` | no |  | Session token for temporary credentials, sent with the access key pair. Redacted in snapshots. |
| `aws_profile` | no |  | Named profile in the shared AWS config and credentials files that supplies credentials when no access key pair is given. |
| `path_style` | no | `False` | Address the bucket in the URL path (`<endpoint>/<bucket>/<key>`) instead of as a subdomain of the endpoint. |
| `key_prefix` | no |  | Key prefix inside the bucket that the mount treats as its root; keys outside it are not visible. Leading slashes are dropped and a trailing `/` is added. |
| `timeout` | no | `30` | Seconds to wait to connect, and for each read of a response, before the request fails. |

## Example

```python
import asyncio
import os

from dotenv import load_dotenv

from mirage import MountMode, Workspace
from mirage.vfs.digitalocean import DigitalOceanConfig, DigitalOceanVFS

load_dotenv(".env.development")

config = DigitalOceanConfig(
    bucket=os.environ["DO_SPACE"],
    region=os.environ.get("DO_REGION", "nyc3"),
    access_key_id=os.environ["DO_ACCESS_KEY_ID"],
    secret_access_key=os.environ["DO_SECRET_ACCESS_KEY"],
)
vfs = DigitalOceanVFS(config)


async def main() -> None:
    ws = Workspace({"/data/": vfs}, mode=MountMode.READ)

    r = await ws.shell("ls /data/")
    print(await r.stdout_str())

    r = await ws.shell("tree /data/")
    print(await r.stdout_str())


if __name__ == "__main__":
    asyncio.run(main())
```

## Notes

- DigitalOcean registers under its own `VFSName` and routes through the same `core/s3`
  implementation, so the full S3 shell-command set applies. See the
  [S3 VFS](/python/vfs/s3) for the complete command reference,
  range reads, streaming, and the index cache fast path.
- For credential setup, see [DigitalOcean Setup](/home/setup/digitalocean).
