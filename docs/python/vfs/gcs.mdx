`GCSVFS` mounts one Google Cloud Storage bucket: every object becomes a file and
every `/` in a key a folder. It reaches GCS through the S3-compatible XML API at
`https://storage.googleapis.com`, signed with an HMAC key. Credentials are set
up on the [GCS page](/home/setup/gcs).

## Install

```bash
pip install "mirage-ai[gcs]"
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.gcs import GCSConfig, GCSVFS

config = GCSConfig(
    bucket=os.environ["GCS_BUCKET"],
    access_key_id=os.environ["GCS_ACCESS_KEY_ID"],
    secret_access_key=os.environ["GCS_SECRET_ACCESS_KEY"],
)
ws = Workspace({"/gcs": GCSVFS(config)}, mode=MountMode.WRITE)

result = await ws.shell("ls /gcs && find /gcs -name '*.csv'")
print(await result.stdout_str())
await ws.close()
```

`endpoint_url` defaults to `https://storage.googleapis.com` and `region` to
`auto`: one host serves every region. A mount takes `MountMode.READ`, `WRITE` or
`EXEC`.

## Authentication

Credentials come from the first of:

1. `access_key_id` and `secret_access_key`, a service account's HMAC key, with
   `session_token` for temporary credentials.
2. `aws_profile`, a profile in `~/.aws/credentials`.
3. The AWS credential chain: environment variables, then the instance or
   container role.

The service account needs **Storage Object Viewer** on the bucket, or **Storage
Object User** (or **Storage Object Admin**) to write. A new key can take up to a
minute to work. A request the credentials may not make answers
`Permission denied`.

## Layout

```text
/gcs/
  data/
    config.json
    file.txt
  reports/
    q1.csv
    q2.csv
```

`/gcs/data/file.txt` is the key `data/file.txt`. Folders come from the `/` in
keys; GCS stores no folder objects.

## Behavior

- **Key prefix:** `key_prefix="users/42/"` mounts only that part of the bucket,
  so `/gcs/notes.md` is the key `users/42/notes.md`. A leading `/` is dropped
  and a trailing `/` added.

## Integration

GCS answers these commands through its own API, so fewer objects are read. See
[Integration](/home/integration/overview).

- `md5sum`: the object's ETag, when it is the MD5 (a single-part upload,
  unencrypted or under SSE-S3).
- `find`: one recursive listing.
- `du`: one recursive listing.
- `ls -R` and `tree`: one recursive listing.
