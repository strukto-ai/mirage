`WasabiVFS` mounts one bucket: every object becomes a file and every `/` in
a key a folder. It is the [S3 VFS](/python/vfs/s3) pointed at Wasabi's
endpoint, so commands behave as they do on S3. Credentials are set up on the
[Wasabi page](/home/setup/wasabi).

## Install

```bash
pip install "mirage-ai[s3]"
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.wasabi import WasabiConfig, WasabiVFS

config = WasabiConfig(
    bucket=os.environ["WASABI_BUCKET"],
    region=os.environ["WASABI_REGION"],
    access_key_id=os.environ["WASABI_ACCESS_KEY_ID"],
    secret_access_key=os.environ["WASABI_SECRET_ACCESS_KEY"],
)
ws = Workspace({"/wasabi": WasabiVFS(config)}, mode=MountMode.WRITE)

result = await ws.shell("ls /wasabi && find /wasabi -name '*.csv'")
print(await result.stdout_str())
```

`region` also picks the endpoint, `https://s3.<region>.wasabisys.com`,
or `https://s3.wasabisys.com` for `us-east-1`, the default; `endpoint_url`
replaces it.
A mount takes `MountMode.READ`, `WRITE` or `EXEC`.

## Authentication

Credentials come from the first of:

1. `access_key_id` and `secret_access_key`, with `session_token` for temporary
   credentials.
2. `aws_profile`, a profile in `~/.aws/credentials`.
3. The AWS credential chain: environment variables, then the instance or
   container role.

The key needs read access to the bucket, and write and delete access for a
write mount. A sub-user whose policy covers only the bucket is the safer
choice.
An object the key may not read or change answers `Permission denied`.

## Layout

```text
/wasabi/
  README.md
  logs/
    app-2026-11-15.log
    app-2026-11-16.log
  reports/
    2026-q3.csv
    2026-q4.csv
```

`/wasabi/reports/2026-q3.csv` is the key `reports/2026-q3.csv`. Folders come
from the `/` in keys.

## Behavior

- **Key prefix:** `key_prefix="users/42/"` mounts only that part of the bucket,
  so `/wasabi/notes.md` is the key `users/42/notes.md`. A leading `/` is dropped
  and a trailing `/` added.

## Integration

Wasabi answers these commands through its own API, so fewer objects are
read. See [Integration](/home/integration/overview).

- `md5sum`: the object's ETag, when it is the MD5 (a single-part upload,
  unencrypted or under SSE-S3).
- `find`: one recursive listing.
- `du`: one recursive listing.
- `ls -R` and `tree`: one recursive listing.
