`BoxVFS` mounts a Box account, or one folder of it: every item keeps its real
name and raw bytes, and folders stay folders. Tokens and apps are set up on
the [Box page](/home/setup/box).

## Install

```bash
pip install mirage-ai
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.box import BoxConfig, BoxVFS

config = BoxConfig(
    client_id=os.environ["BOX_CLIENT_ID"],
    client_secret=os.environ["BOX_CLIENT_SECRET"],
    refresh_token=os.environ["BOX_REFRESH_TOKEN"],
)
ws = Workspace({"/box": BoxVFS(config)}, mode=MountMode.WRITE)

result = await ws.shell("ls /box && grep -rlw report /box/Contracts")
print(await result.stdout_str())
await ws.close()
```

`root_folder_id` mounts one folder instead of the whole account. To try the
mount quickly, pass only `access_token` with a developer token.

## Authentication

Set one of these credential sets:

1. `access_token`: a developer token, used as is. It lasts 60 minutes, cannot
   be renewed by code, and wins over every other credential.
2. `client_id` and `refresh_token`, with `client_secret` unless the app is a
   PKCE client: OAuth for a user. Box rotates the refresh token on every
   refresh and the old one stops working after its first use, so pass
   `on_refresh_token_rotated`, an async callable given each new token, to
   persist it across restarts.
3. `client_id`, `client_secret` and `enterprise_id`: client credentials for
   the app's service account, fetched again on expiry with no refresh token.

Access tokens are renewed 5 minutes before they expire. A service account
starts with an empty root: share folders with its email address to see them.

The app needs the **Read all files and folders stored in Box** scope, and
**Write all files and folders stored in Box** for a `write` mount. In an
enterprise, a Box admin may have to enable the app first; until then Box
answers `403 access_denied`.

## Layout

```text
/box/
  Contracts/
    2026_MSA.pdf
  Roadmap.gdoc
  Team Notes.boxnote
  data.csv
```

Box addresses items by numeric ID, and the account root is folder `0`. The
mount resolves each path one folder level at a time, so the first access to a
nested folder costs one request per level, and keeps the result.

## Behavior

- **Folder root:** `root_folder_id` mounts one folder, its ID taken from the
  web URL (`app.box.com/folder/<id>`). Unlike a path, it survives renames and
  moves. Paths outside it are unreachable.
- **Box files:** `.boxnote` and `.boxcanvas` come back as the JSON Box
  stores, so `cat notes.boxnote | jq .` works. `.gdoc`, `.gsheet` and
  `.gslides` come back as the Office zips Box stores (`docx`, `xlsx`,
  `pptx`). Mirage does not convert them; for an editable view of Google
  files, mount [Google Drive](/python/vfs/gdrive) instead.
- **`read: fresh`:** a cached file is checked against the SHA-1 Box keeps,
  with one request. A file Box reports without a SHA-1 cannot be checked, so
  each fresh read downloads it again. Listings are fetched again once per
  command, since a folder's version does not change with its children.

## Integration

Box answers these commands through its own API, so fewer files are read. See
[Integration](/home/integration/overview).

- `grep -rw` and `rg -w`: Box search names the files to read, for whole
  words. Every file is read when the search fails, reaches its 10,000-match
  limit or finds nothing, or when the searched path is not a folder.
  [Search](/home/integration/search) lists how each option uses it. Box
  searches the text it extracted, not the bytes, and indexes a write some
  time after it lands, so it can miss Office files, PDFs, archives, the end
  of a large file, a word Box splits differently (`foo.bar`) and recent
  writes. `walk_limit: -1` in the mount's `"@all"`
  [command limit](/home/limits#command-output) reads every file instead.
- `grep -r` and `rg` without `-w`: every file is read.
- `sha1sum`: the SHA-1 Box keeps, asked live.
