`SqlVFS` keeps a filesystem in a database's tables: a SQLite file, or a
Postgres server through its driver. Every command that writes works, and the
files persist with the database. Setup is on the [SQL page](/home/setup/sql).

## Install

```bash
pip install mirage-ai
```

A SQLite file needs no extra: the mount uses Python's own `sqlite3`. Postgres
needs `pip install "mirage-ai[postgres]"`.

## Configure

```python
from mirage import MountMode, Workspace
from mirage.vfs.sql import SqlVFS

ws = Workspace({"/sql": SqlVFS("./workspace.db")}, mode=MountMode.WRITE)

result = await ws.shell("echo hello > /sql/note.txt && ls /sql")
print(await result.stdout_str())
await ws.close()
```

Leave out the path to keep the database in memory. `capacity="100MB"` caps the
bytes the database's files hold; see [capacity](/home/setup/vfs#mount-capacity).
To keep the tables in Postgres, pass its driver:

```python
import os

from mirage.vfs.sql import PostgresSqlDriver, SqlVFS

driver = PostgresSqlDriver(os.environ["DATABASE_URL"])
vfs = SqlVFS(driver=driver)
```

### Fields

| Field | Default | Notes |
| --- | --- | --- |
| `path` | in memory | The SQLite file, opened and closed with the mount. |
| `capacity` | none | The most bytes the database's files may hold, like `100MB`. |
| `driver` | none | A database to borrow instead of a file: `SqliteDriver` or `PostgresSqlDriver`. The caller closes it. Not with `path`. |
| `root` | `/` | The folder of the database the mount serves, made if missing. |

## Layout

```text
/sql/
  notes/
    hello.txt
  users.csv
```

The tables are laid out as [AgentFS](https://github.com/tursodatabase/agentfs)'s:

- `fs_inode`: one row per file and folder, with its size and mtime.
- `fs_dentry`: each entry's name under its parent folder.
- `fs_data`: a file's bytes, in rows of the database's chunk size (4 KiB unless
  the database says otherwise).
- `fs_config`: the chunk size.

## Behavior

- **One filesystem, both runtimes:** the TypeScript mount reads and writes the
  same tables, so a Python and a Node process on one file serve one filesystem.
- **Several mounts on one database:** a mount serves one folder of its
  database, `/` by default. Hand two mounts one driver to serve the whole
  database and one folder as a mount of its own:

  ```python
  from mirage.vfs.sql import SqliteDriver

  driver = SqliteDriver("./workspace.db")
  ws = Workspace(
      {
          "/": SqlVFS(driver=driver, capacity="1GB"),
          "/workspace": SqlVFS(driver=driver, root="/workspace", capacity="1GB"),
      },
      mode=MountMode.WRITE,
  )
  ```

- **Capacity:** `capacity` counts every file in the database, whichever mount
  wrote it. Mounts on one driver with the same `capacity` share one count, so
  their writes together stay within it. Mounts on separate drivers count apart,
  even on one file, and together they can pass it.
- **Snapshots:** a snapshot keeps the mount's own folder, and loading it
  replaces that folder. The rest of the database stays as it was.
