`DiskVFS` mounts a directory on the host: every file and folder under `root`
appears under the mount, and reads and writes go to the real files. It needs
no credentials; see the [Disk page](/home/setup/disk).

## Install

```bash
pip install mirage-ai
```

## Configure

```python
from mirage import MountMode, Workspace
from mirage.vfs.disk import DiskVFS

ws = Workspace({"/data": DiskVFS(root="./files")}, mode=MountMode.WRITE)

result = await ws.shell("ls /data && find /data -name '*.json'")
print(await result.stdout_str())
await ws.close()
```

`capacity="1GB"` caps the bytes the root may hold; see
[capacity](/home/setup/vfs#mount-capacity). A mount takes `MountMode.READ`,
`WRITE` or `EXEC`.

### Fields

| Field | Default | Notes |
| --- | --- | --- |
| `root` | required | The host directory the mount mirrors. |
| `folder_versions` | `True` | Store each listing at its folder's version, so a `read: fresh` mount re-lists only folders that changed. Must be a boolean. |
| `capacity` | none | The most bytes the root may hold, a size like `100MB` or a count of bytes. |

## Layout

```text
/data/
  notes.txt
  config.json
  reports/
    q1.csv
    q2.csv
```

The mount mirrors `root`: with `root="./files"`, `/data/reports/q1.csv` is
the file `./files/reports/q1.csv`.

## Behavior

- **Root boundary:** a path such as `../../etc/passwd` is rejected; every path
  resolves inside `root`.
- **One mount per folder:** a second disk mount whose `root` resolves to a
  folder already mounted is refused; a folder inside one is fine.
- **Folder versions:** they assume a local POSIX filesystem, where adding,
  renaming or removing an entry moves the folder's change time. Set
  `folder_versions=False` for a network or FUSE root (NFS, SMB, rclone, s3fs,
  Mirage's own FUSE). A folder changed in the last 2 seconds gets no version
  and is re-listed until it has been quiet that long.
- **Snapshots:** a snapshot carries the mount's files, and loading it restores
  them.
