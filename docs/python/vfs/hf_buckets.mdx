`HfBucketsVFS` mounts one
[Hugging Face Storage Bucket](https://huggingface.co/docs/hub/storage-buckets):
every file in it becomes a file and every `/` in its path a folder. Set up the bucket and token as in [HF Buckets setup](/home/setup/hf_buckets).

## Install

```bash
pip install "mirage-ai[hf-buckets]"
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.hf_buckets import HfBucketsConfig, HfBucketsVFS

config = HfBucketsConfig(
    bucket=os.environ["HF_BUCKET_NAME"],
    token=os.environ["HF_TOKEN"],
)
ws = Workspace({"/hf": HfBucketsVFS(config)}, mode=MountMode.WRITE)

result = await ws.shell("ls /hf && find /hf -name '*.json'")
print(await result.stdout_str())
await ws.close()
```

`bucket` is the bucket's id, `<owner>/<name>`. `endpoint` points the mount at
a mirror or a self-hosted Hub. A mount takes `MountMode.READ`, `WRITE` or
`EXEC`.

## Behavior

- **Key prefix:** `key_prefix="users/42/"` mounts only that part of the bucket, so
  `/hf/notes.md` is the file `users/42/notes.md`. A leading `/` is dropped and
  a trailing `/` added.
- **Folders:** a folder exists only while it holds a file, so `mkdir` creates
  nothing.
- **No move:** `mv` and `rmdir` are not supported.
- **No history:** a bucket keeps no history, so a removed file is gone for
  good.
