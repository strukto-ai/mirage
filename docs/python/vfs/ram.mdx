`RAMVFS` keeps files in process memory, for scratch work, tests and trying
Mirage. The mount starts empty and its files are gone when the process exits.
It needs no service and no credentials; see the [RAM page](/home/setup/ram).

## Install

```bash
pip install mirage-ai
```

## Configure

```python
from mirage import MountMode, Workspace
from mirage.vfs.ram import RAMVFS

ws = Workspace({"/data": RAMVFS()}, mode=MountMode.WRITE)

result = await ws.shell("echo hello > /data/note.txt && cat /data/note.txt")
print(await result.stdout_str())
await ws.close()
```

`RAMVFS()` takes no config object. `RAMVFS(capacity="100MB")` caps the bytes
the store holds; a write past it fails with "Disk quota exceeded". See
[capacity](/home/setup/vfs#mount-capacity).

## Layout

```text
/data/
  notes.txt
  config.json
  reports/
    q1.csv
    q2.csv
```

The mount starts empty. Files and folders exist once a command such as
`touch`, `mkdir`, `tee` or `cp` writes them. The root `/` always exists.
