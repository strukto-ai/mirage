`MongoDBVFS` turns MongoDB databases into a read-only tree: every collection
and view is a folder holding its sampled schema and its documents as JSON
lines. Set up the connection URI as in [MongoDB setup](/home/setup/mongodb).

## Install

```bash
pip install "mirage-ai[mongodb]"
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.mongodb import MongoDBConfig, MongoDBVFS

config = MongoDBConfig(uri=os.environ["MONGODB_URI"], databases=["sample_mflix"])
ws = Workspace({"/mongodb": MongoDBVFS(config)}, mode=MountMode.READ)

result = await ws.shell("head -n 3 /mongodb/sample_mflix/collections/movies/documents.jsonl")
print(await result.stdout_str())
await ws.close()
```

`databases` limits the tree to those databases.
`elide_fields={"sample_mflix.movies": ["plot_embedding"]}` drops heavy fields,
such as embeddings, from what an agent reads.

## Behavior

- **Read-only:** the mount only reads; no command changes the database.
- **Streaming:** `cat`, `grep`, `jq` and `head` read documents in batches, and
  `head` stops after its count. Commands that need the whole input, such as
  `sort` or `jq -s`, still buffer it, so read a large collection in bounded
  slices.
- **Read limit:** `tail -n` with a count past `max_doc_limit` on a collection
  that long fails with `File too large` rather than printing fewer lines.
- **Elided fields:** fields under `elide_fields` are dropped from
  `documents.jsonl`, for `cat` and `tail -f` alike, and keep their type in
  `schema.json`. Nested paths use dots, such as `metadata.embedding`.
- **File size:** `documents.jsonl` is rendered on demand, so `stat` and `ls -l`
  show `-` for its size and `du` counts `0`. `wc -c` measures the bytes and
  `wc -l` counts the documents; both may scan the collection. A nonempty
  `ls -l` prints `total ?`.
- **Following inserts:** `tail -f` prints the last lines, then follows new
  inserts through a change stream. That needs a replica set on MongoDB 5.0 or
  later, which Atlas is; on a standalone server, and on a view, it polls.

    **Supported Unix Commands for VFS**

    Unix commands work on each path as on a local filesystem, as far as the path supports them:

    | Path | Supported |
    | --- | --- |
    | `/<path>` | Commands that read files (`ls`, `cat`, `grep`, `find`, `jq` and the rest). `grep` and `rg` ask `mongodb` for the matching lines. `tail` and `wc -l` ask `mongodb` instead of reading a file. |
