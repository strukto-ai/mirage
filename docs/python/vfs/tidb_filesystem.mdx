`TiDBFilesystemVFS` mounts a [TiDB Cloud Filesystem](https://www.pingcap.com/tidb/tidb-cloud-filesystem/)
through its REST API. Agents list, read, write, move and remove files under
the mount with ordinary shell commands, and no FUSE mount is needed.

For tokens and regions, see [TiDB Cloud Filesystem Setup](/home/setup/tidb).

## Config

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.tidb_filesystem import (
	TiDBFilesystemConfig,
	TiDBFilesystemVFS,
)

vfs = TiDBFilesystemVFS(TiDBFilesystemConfig(
	host=os.environ["TIDB_FILESYSTEM_HOST"],
	token=os.environ["TIDB_FILESYSTEM_TOKEN"],
	root_path="/workspace",
))
ws = Workspace({"/fs": vfs}, mode=MountMode.WRITE)
```

## Mount mode

`read`, `write` or `exec`. Use `exec` if `python3` or `js` should run scripts from the mount.

## Behavior

- A file under 50,000 bytes is written with one request; a larger one goes up
  in parts, a few at a time, and reads of it stream from object storage,
  ranged when a command reads only part of it.
- `>>` onto a file of 50,000 bytes or more sends only the new bytes and the
  file's last part; a smaller file is read and written back.
- `mv` is one server-side rename, for a file or a whole directory. `rm -r`
  is one recursive delete.
- `cp` reads the file and writes the copy, so the two never share content.
- Before a write, `mkdir` or `mv`, Mirage asks the file system what the
  destination and its parents are, so a missing parent, a file in the way or a
  directory target fails as it does on a local disk.
- A file in the extent layout, which only the file system's FUSE client
  writes and reads, reads as `Operation not supported`.

## Example

```python
import asyncio
import os

from mirage import MountMode, Workspace
from mirage.vfs.tidb_filesystem import (
	TiDBFilesystemConfig,
	TiDBFilesystemVFS,
)

vfs = TiDBFilesystemVFS(TiDBFilesystemConfig(
	host=os.environ["TIDB_FILESYSTEM_HOST"],
	token=os.environ["TIDB_FILESYSTEM_TOKEN"],
))


async def main() -> None:
	ws = Workspace({"/fs": vfs}, mode=MountMode.WRITE)
	await ws.shell("mkdir -p /fs/notes && echo hello > /fs/notes/a.txt")
	r = await ws.shell("ls -l /fs/notes && cat /fs/notes/a.txt")
	print(await r.stdout_str())
	await ws.close()


if __name__ == "__main__":
	asyncio.run(main())
```
