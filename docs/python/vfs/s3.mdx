`S3VFS` mounts one bucket: every object becomes a file and every `/` in a key a
folder. It works with Amazon S3 and any S3-compatible server, such as MinIO,
Ceph or SeaweedFS. Credentials are set up on the [S3 page](/home/setup/s3).

## Install

```bash
pip install "mirage-ai[s3]"
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.s3 import S3Config, S3VFS

config = S3Config(
    bucket=os.environ["AWS_S3_BUCKET"],
    region=os.environ["AWS_DEFAULT_REGION"],
    aws_access_key_id=os.environ["AWS_ACCESS_KEY_ID"],
    aws_secret_access_key=os.environ["AWS_SECRET_ACCESS_KEY"],
)
ws = Workspace({"/s3": S3VFS(config)}, mode=MountMode.WRITE)

result = await ws.shell("ls /s3 && find /s3 -name '*.csv'")
print(await result.stdout_str())
```

For MinIO or another S3-compatible server, add `endpoint_url` and, if the
server needs it, `path_style=True`. A mount takes `MountMode.READ`, `WRITE` or
`EXEC`.

## Authentication

Credentials come from the first of:

1. `aws_access_key_id` and `aws_secret_access_key`, with `aws_session_token`
   for temporary credentials.
2. `aws_profile`, a profile in `~/.aws/credentials`.
3. The AWS credential chain: environment variables, then the instance or
   container role.

The mount needs `s3:ListBucket` on the bucket, `s3:GetObject` to read, and
`s3:PutObject` and `s3:DeleteObject` to write. An object the credentials cannot
read answers `Permission denied`. Without `s3:ListBucket`, a missing file
answers `Permission denied` too, since S3 then hides which keys exist.

## Layout

```text
/s3/
  data/
    config.json
    file.txt
  reports/
    q1.csv
    q2.csv
```

`/s3/data/file.txt` is the key `data/file.txt`. Folders come from the `/` in
keys; S3 stores no folder objects.

## Behavior

- **Key prefix:** `key_prefix="users/42/"` mounts only that part of the bucket,
  so `/s3/notes.md` is the key `users/42/notes.md`. A leading `/` is dropped
  and a trailing `/` added.
- **Content type:** written objects carry `default_content_type` when it is
  set; otherwise the server picks its default.

## Integration

S3 answers these commands through its own API, so fewer objects are read. See
[Integration](/home/integration/overview).

- `md5sum`: the object's ETag, when it is the MD5 (a single-part upload,
  unencrypted or under SSE-S3).
- `find`: one recursive listing.
- `du`: one recursive listing.
- `ls -R` and `tree`: one recursive listing.
