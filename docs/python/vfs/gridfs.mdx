`GridFSVFS` mounts a MongoDB GridFS bucket: every file in the bucket becomes a
file and every `/` in a filename a folder. Metadata lives in the
`<bucket>.files` collection and content in `<bucket>.chunks`. Set up the connection URI as in [GridFS setup](/home/setup/gridfs).

## Install

```bash
pip install "mirage-ai[gridfs]"
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.gridfs import GridFSConfig, GridFSVFS

config = GridFSConfig(uri=os.environ["MONGODB_URI"], database="app")
ws = Workspace({"/gridfs": GridFSVFS(config)}, mode=MountMode.WRITE)

result = await ws.shell("echo hello > /gridfs/notes/a.txt && find /gridfs -name '*.txt'")
print(await result.stdout_str())
await ws.close()
```

`bucket` names a bucket other than `fs`, `key_prefix` scopes the mount to part
of it, and `keep_revisions` bounds the history each file keeps. A mount takes
`MountMode.READ`, `WRITE` or `EXEC`.

## Behavior

- **Key prefix:** `key_prefix="users/42/"` mounts only that part of the bucket,
  so `/gridfs/data/notes.md` is the filename `users/42/data/notes.md`. A
  leading `/` is dropped and a trailing `/` added; an empty prefix means none.
- **Range reads:** `head -c` and `tail -c` seek by chunk, so a large file is
  never downloaded whole. A file smaller than the chunk size is one chunk.
- **Trash:** `rm`, and a file `mv` overwrites, retag every revision to
  `/trash/<filename>`. No mount path reaches the trash, so the name reads as
  gone, and the full original filename stays traceable.

### Revisions

GridFS filenames are not unique: every write uploads a new revision and keeps
the old ones. Reads and listings serve the newest revision per filename, and a
snapshot-pinned read resolves an older revision by its `_id`. `mv` retags every
revision's filename on the server, so history moves with the file.

`keep_revisions` bounds the history. Set it, and a write or an `rm` deletes the
revisions past that count per filename, oldest first, under the file's name and
in the trash alike; a snapshot pinned to a pruned revision then fails to read
it. Unset keeps every revision.
