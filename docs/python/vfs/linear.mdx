`LinearVFS` mounts a Linear workspace as read-only JSON files: teams, members,
issues with their comments, projects, cycles and documents. Set up the API key as in [Linear setup](/home/setup/linear).

## Install

```bash
pip install mirage-ai
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.linear import LinearConfig, LinearVFS

config = LinearConfig(api_key=os.environ["LINEAR_API_KEY"])
ws = Workspace({"/linear": LinearVFS(config)}, mode=MountMode.READ)

result = await ws.shell("ls /linear/teams && tree -L 2 /linear/teams")
print(await result.stdout_str())
await ws.close()
```

`team_ids` limits the mount to some teams. `base_url` points at another
GraphQL endpoint, such as a proxy.

    **`/<path>`**

    ```text
    /<path>
      teams/
        <team-key>__<team-name>__<team-id>/
          team.json
          members/
            <display-name>__<user-id>.json
          issues/
            <issue-key>__<issue-id>/

          projects/
            <name>__<project-id>.json
          cycles/
            <name>__<cycle-id>.json
          documents/
            <title>__<document-id>.json
    ```

    - A named segment is `<sanitized-name>__<id>`; the id after the last `__`
      is exact. `ls` the parent for exact names rather than building them.
    - Files are JSON normalized by Mirage with snake_case keys (`issue_key`,
      `state_name`, `assignee_email`, `label_names`), not Linear's GraphQL
      shape. `comments.jsonl` holds one comment per line.
    - `team.json` lists the team's workflow states; a project file lists its
      issues with their state.
    - To create, update, assign, transition or comment on issues, use the
      `linear` CLI if installed (`linear --help`).

    **Supported Unix Commands for VFS**

    Unix commands work on each path as on a local filesystem, as far as the path supports them:

    | Path | Supported |
    | --- | --- |
    | `/<path>` | Commands that read files (`ls`, `cat`, `grep`, `find`, `jq` and the rest). `grep -r` and `rg` ask `linear` which files may match. |

    **Limitations of Unix Commands for VFS**

    Where a path differs from a local filesystem:

    | Path | Limitations |
    | --- | --- |
    | `/<path>` | Read only: no command changes files. `linear` answers only for `teams/*/issues/*/issue.json`, `teams/*/members/*`, `teams/*/projects/*`, `teams/*/cycles/*` and `teams/*/documents/*`; `grep -r` and `rg` read every other file. `grep -r`, `find` and `du` stop after 1000 files; a glob matching more, `tar -c`, `cp -r` and `rm -r` are refused. |

    Run `man <cmd>` or `<cmd> --help` for one command's usage.
