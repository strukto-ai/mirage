`HfSpacesVFS` mounts one [Hugging Face Space](https://huggingface.co/spaces)
repository as read-only files: its app code, README, config and requirements.
A token for a private Space is set up on the
[HF Spaces page](/home/setup/hf_spaces).

## Install

```bash
pip install mirage-ai
```

## Configure

```python
import os

from mirage import MountMode, Workspace
from mirage.vfs.hf_spaces import HfSpacesConfig, HfSpacesVFS

config = HfSpacesConfig(
    repo_id=os.environ["HF_SPACE_REPO"],
    token=os.environ.get("HF_TOKEN"),
)
ws = Workspace({"/space": HfSpacesVFS(config)}, mode=MountMode.READ)

result = await ws.shell("ls /space && grep -l import /space/*.py")
print(await result.stdout_str())
await ws.close()
```

`revision` picks a branch, tag or commit (`main` when unset), `key_prefix`
mounts one folder of the repository, and `endpoint` points at a mirror or a
self-hosted Hub.

## Authentication

A public Space needs no token: unset `token` sends anonymous requests, which
reach public repositories only. A private Space needs a **Read** token, or a
**Fine-grained** one with read access to that Space's repository.

## Layout

```text
/space/
  Dockerfile
  README.md
  app.py
  requirements.txt
  scripts/
    precompute.py
```

`repo_id` is `namespace/space-name`, set at mount time, and the tree mirrors
the repository at `revision`: `/space/app.py` is `app.py`.

## Behavior

- **Read only:** a Hub write is a commit, and a POSIX write cannot say where a
  commit ends, so `echo >`, `rm`, `cp` and `mv` are refused rather than making
  one commit per file. The [`hf` CLI](/python/cli/hf) is the write half:
  `hf download --local-dir` puts a copy on a RAM or disk mount, and
  `hf upload` sends it back as one commit.
- **Fresh reads:** under `read: fresh`, each command checks the commit
  `revision` resolves to with one small request, also when `revision` is a
  full commit SHA, since a branch or tag could carry the same name.

## Integration

The Hub answers this command through its own API, so fewer files are read.
See [Integration](/home/integration/overview).

- `sha256sum`: the LFS sha256 the Hub keeps; other files are read.
