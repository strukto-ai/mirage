The Redis VFS creates a persistent virtual filesystem backed by
Redis. It supports full read and write operations.

Install the extra:

```bash
pip install "mirage-ai[redis]"
```

## Config

```python
from mirage import MountMode, Workspace
from mirage.vfs.redis import RedisVFS

vfs = RedisVFS(
    url="redis://localhost:6379/0",
    key_prefix="mirage:fs:",
)
ws = Workspace({"/redis": vfs}, mode=MountMode.WRITE)
```

| Parameter    | Required | Default                  | Description             |
| ------------ | -------- | ------------------------ | ----------------------- |
| `url`        | no       | `redis://localhost:6379/0` | Redis connection URL  |
| `key_prefix` | no       | `mirage:fs:`             | Key namespace prefix    |
| `walk_limit` | no | `1000` | Most files one command walks under a folder: `grep -r`, `find` and other walks stop there, and a larger glob, `tar -c`, `cp -r` or `rm -r` is refused. `-1` lifts the limit. |

Keys are stored as:
- `{prefix}file:{path}` - file content (raw bytes)
- `{prefix}dir` - Redis set of directory paths
- `{prefix}modified:{path}` - modification timestamps

## Supported Unix Commands for VFS

Unix commands work on each path as on a local filesystem, as far as the path supports them:

| Path | Supported |
| --- | --- |
| `/<path>` | Almost all Unix commands. |

## Limitations of Unix Commands for VFS

Where a path differs from a local filesystem:

| Path | Limitations |
| --- | --- |
| `/<path>` | `grep -r`, `find` and `du` stop after 1000 files; a glob matching more, `tar -c`, `cp -r` and `rm -r` are refused. |

Run `man` to list every command, and `man <cmd>` or `<cmd> --help` for one command's usage.

```text

    error.log
  cache/
    session-abc.json
```

## Cache

Index TTL is `0`, so listings are read from Redis every time. A
workspace `index:` block still applies its `ttl` to this mount.

## Integration

What Redis answers through its own API, so fewer files are read. [Integration](/home/integration/overview) explains each command.

| Command | On Redis |
| --- | --- |
| `find`, `du`, `ls -R`, `tree` | One recursive listing |

## Example

```python
import asyncio

from mirage import MountMode, Workspace
from mirage.vfs.redis import RedisVFS

vfs = RedisVFS(url="redis://localhost:6379/0")


async def main():
    ws = Workspace({"/redis": vfs}, mode=MountMode.WRITE)

    # Create directories and files
    await ws.shell("mkdir -p /redis/data/")
    await ws.shell('echo "hello world" | tee /redis/data/hello.txt')

    # Read back
    r = await ws.shell("cat /redis/data/hello.txt")
    print(await r.stdout_str())

    # List files
    r = await ws.shell("ls /redis/data/")
    print(await r.stdout_str())

    # Copy and move
    await ws.shell("cp /redis/data/hello.txt /redis/data/copy.txt")
    await ws.shell("mv /redis/data/copy.txt /redis/data/renamed.txt")

    # Search
    r = await ws.shell('grep -r "hello" /redis/data/')
    print(await r.stdout_str())

    # Clean up
    await ws.shell("rm -r /redis/data/")


if __name__ == "__main__":
    asyncio.run(main())
```

## Shell Commands

| Command                | Notes                                      |
| ---------------------- | ------------------------------------------ |
| `ls`                   | List files and directories                 |
| `cat`                  | Read file content                          |
| `head` / `tail`        | First/last N lines                         |
| `grep` / `rg`          | Pattern search                             |
| `wc`                   | Line/word/byte counts                      |
| `find`                 | Recursive search with `-name`, `-maxdepth` |
| `tree`                 | Directory tree view                        |
| `mkdir`                | Create directories                         |
| `touch`                | Create empty files                         |
| `cp` / `mv` / `rm`    | Copy, move, delete                         |
| `tee`                  | Write stdin to file                        |
| `diff` / `cmp`         | Compare files                              |
| `sort` / `cut` / `tr`  | Text processing                            |
| `tar` / `zip` / `gzip` | Compression                                |
| `base64` / `md5` / `sha256sum` | Encoding and checksums           |
