Read and send Slack messages, manage reactions and pins, and look up members or search messages. The action names follow [OpenClaw](https://github.com/openclaw/openclaw); `search` and `list-members` are Mirage extensions.

## Setup

Use the bot and user token scopes in [Slack setup](/home/setup/slack). The bot token handles ordinary actions; `search` needs `search_token` (`searchToken` in TypeScript).

```python
from mirage import Workspace
from mirage.commands.cli.builtin.slack import SLACK
from mirage.core.slack.config import SlackConfig

config = SlackConfig(token="xoxb-...", search_token="xoxp-...")
ws = Workspace({})
ws.register_cli("slack", SLACK, config)
```

No service mount is required. For YAML and multiple accounts, see the
[CLI overview](/python/cli/index#register-a-cli).

## Supported commands

Run `slack <command> --help` for the supported flags and operands.
This list is generated from Mirage's registered command tree.

| Command | Description |
| --- | --- |
| `slack send-message` | Post a message to a channel or thread |
| `slack read-messages` | Read the most recent messages of a channel |
| `slack react` | Add an emoji reaction to a message |
| `slack reactions` | List the reactions on a message |
| `slack pin-message` | Pin a message to its channel |
| `slack unpin-message` | Remove a pin from a message |
| `slack list-pins` | List the pinned items of a channel |
| `slack member-info` | Fetch one user's profile |
| `slack list-members` | List workspace members, optionally filtered |

## Messages, reactions and pins

```bash
slack read-messages --channel C04KEPWF6V7 --limit 20
slack send-message --channel C04KEPWF6V7 --text "Release is ready"
slack send-message --channel C04KEPWF6V7 --thread-ts 1712345678.123456 --text "Thread reply"
slack react --channel C04KEPWF6V7 --ts 1712345678.123456 --emoji thumbsup
slack reactions --channel C04KEPWF6V7 --ts 1712345678.123456
slack pin-message --channel C04KEPWF6V7 --ts 1712345678.123456
slack list-pins --channel C04KEPWF6V7
slack unpin-message --channel C04KEPWF6V7 --ts 1712345678.123456
```

Channels and users are Slack IDs. A message is identified by its channel
and timestamp (`--ts`); replies use the parent's timestamp in `--thread-ts`.

## Find people and messages

```bash
slack member-info --user U04K21SEVR9
slack list-members --query alice
slack emoji-list
slack search --query 'from:@priya in:#general launch' --count 20 --page 1
```

Search accepts Slack operators such as `from:`, `in:` and `after:`. Results
are JSON and can be piped to `jq`.

## VFS and limits

The optional [Slack VFS](/python/vfs/slack) exposes channels and messages
as files. Its IDs can be passed to this CLI, but the CLI gets credentials
from its own registration and does not need the mount.

Only the listed actions are implemented; this is not Slack's app-development
CLI. Mount read-only mode does not prevent service writes—use command policy
to restrict sending messages, reactions or pin changes.
