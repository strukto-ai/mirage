Read and send Slack messages, share files, manage reactions and pins, and look up members or search messages. The action names follow [OpenClaw](https://github.com/openclaw/openclaw); `search` and `list-members` are Mirage extensions.

## Setup

Use the bot and user token scopes in [Slack setup](/home/setup/slack). The bot token handles ordinary actions; `search` needs `search_token`.

```python
from mirage import Workspace
from mirage.commands.cli.builtin.slack import SLACK
from mirage.core.slack.config import SlackConfig

config = SlackConfig(token="xoxb-...", search_token="xoxp-...")
ws = Workspace({})
ws.register_cli("slack", SLACK, config)
```

No service mount is required. For YAML and multiple accounts, see the
[CLI overview](/python/cli/index#register-a-cli).
