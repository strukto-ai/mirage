Print a PDF file's document information: its metadata, page count, page
size, encryption and PDF version. Mirage implements
[poppler](https://poppler.freedesktop.org)'s `pdfinfo` fields, messages and
exit codes with its own PDF reader.

## Setup

`pdfinfo` has no account config. It reads PDF files through existing mounts.

```python
from mirage import Workspace
from mirage.commands.cli.builtin.pdf import PDFINFO
from mirage.vfs.ram import RAMVFS

ws = Workspace({"/data/": RAMVFS()})
ws.register_cli("pdfinfo", PDFINFO)
```

For YAML registration, see the [CLI overview](/python/cli/index#register-a-cli).
