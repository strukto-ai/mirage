Query Linear teams, issues, projects, cycles, comments, users and documents. Mirage's noun/verb interface draws partly on [schpet/linear-cli](https://github.com/schpet/linear-cli), with its own supported command tree and normalized JSON output for `jq`.

## Setup

Create an API key using [Linear setup](/home/setup/linear).

```python
from mirage import Workspace
from mirage.commands.cli.builtin.linear import LINEAR
from mirage.core.linear.config import LinearConfig

config = LinearConfig(api_key="lin_api_...")
ws = Workspace({})
ws.register_cli("linear", LINEAR, config)
```

No service mount is required. For YAML and multiple accounts, see the
[CLI overview](/python/cli/index#register-a-cli).

## Find work

```bash
linear team list
linear team members ENG
linear issue list --team ENG
linear issue get ENG-42
linear project list --team ENG
linear cycle current --team ENG
linear comment list ENG-42
linear user get sam@example.com
linear document list --team ENG
linear search "login bug"
```

Issues take a positional key such as `ENG-42` or a raw ID. `--team` accepts
a team key, name or ID. Use the list commands to discover project, cycle,
label and document IDs.

## Update work

```bash
linear issue create --team ENG --title "Fix login" --description "Reproduction steps"
linear issue update ENG-42 --title "Fix expired-session login"
linear issue assign ENG-42 --assignee-email user@example.com
linear issue transition ENG-42 --state-name "In Review"
linear issue set-priority ENG-42 --priority 2
linear issue set-project ENG-42 --project-name "Search"
linear issue add-label ENG-42 --label-name bug
echo 'Ready for review' | linear comment add ENG-42
linear comment update --comment COMMENT_ID --body "Reviewed"
```

| Value | Accepted forms |
| --- | --- |
| Assignee | `--assignee-email` or `--assignee-id` |
| Workflow state | `--state-name` or `--state-id` |
| Project | `--project-name` or `--project` with an ID |
| Label | `--label-name` or `--label` with an ID; preserves existing labels |
| Priority | `0` none, `1` urgent, `2` high, `3` normal, `4` low |

Descriptions and comment bodies can come from stdin. Issue creation requires
`--team` and `--title`; updates use the values explicitly supplied.

## VFS and limits

The [Linear VFS](/python/vfs/linear) lets agents browse the same service
as files. The CLI takes service IDs and its own config; piping a mounted
file into a body does not make that mount the CLI's account.

Only the commands above are implemented. Commands, flags and JSON output
follow this reference; Mirage does not promise full compatibility with
`schpet/linear-cli`. That project uses the
[ISC license](https://github.com/schpet/linear-cli/blob/main/LICENSE).
Mirage's command implementation is Apache-2.0; see
[compatibility and licenses](/home/setup/clis#compatibility-and-licenses).
