Work with GitHub repositories, issues, pull requests, releases and Actions, or call REST and GraphQL directly. Mirage implements the supported subset below of the [GitHub CLI (`gh`)](https://github.com/cli/cli), with workspace files and configured account credentials.

## Setup

Use [GitHub setup](/home/setup/github) for token permissions. No GitHub mount
or local checkout is required.

```python
from mirage import Workspace
from mirage.commands.cli.builtin.gh import GH
from mirage.core.github.config import GhConfig

ws = Workspace({})
ws.register_cli("gh", GH, GhConfig(token="ghp_...", repo="acme/tools"))
```

`repo` is the default repository and `branch` the current branch, as a
checkout would give them to a host `gh`: `branch` fills the API's `{branch}`
placeholder, names the pull request a `pr` command acts on when given none,
and is the head `pr create` opens from. `base_url` (`baseUrl` in TypeScript) selects an API host. An
Enterprise REST base ending in `/api/v3` uses `/api/graphql` for GraphQL;
other bases use `/graphql` beneath that base.

For YAML and multiple accounts, see [registration](/python/cli/index#register-a-cli).
