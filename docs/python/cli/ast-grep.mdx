Install `mirage-ai[ast-grep]` to load the shared Rust parser with Wasmtime.

```python
from mirage.commands.cli.builtin.ast_grep import AST_GREP

ws.register_cli("ast-grep", AST_GREP)
```

See [setup and shell examples](/home/setup/cli/ast-grep) for supported languages, rules and resource limits.
