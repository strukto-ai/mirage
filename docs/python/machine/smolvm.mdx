What to install and a runnable Python example. The settings, how the workspace connects and the notes are on [smolvm](/home/setup/machine/smolvm), shared by both SDKs.

## Usage

`captures` defaults to [`@external`](/home/setup/machine/overview#captures):
every program Mirage does not have itself. Name `@python` to run
Python in the machine too.

```python
from mirage import RAMVFS, MountMode, Workspace

ws = Workspace(
    {"/data": RAMVFS()},
    mode=MountMode.EXEC,
    machines={"box": {"provider": "smolvm", "machine": "mirage-box", "captures": ["@python", "@external"]}},
)
await ws.shell("python3 -c 'print(1 + 1)'")
```
