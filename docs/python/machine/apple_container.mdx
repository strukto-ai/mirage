What to install and a runnable Python example. The settings, how the workspace connects and the notes are on [Apple Container](/home/setup/machine/apple_container), shared by both SDKs.

## Usage

`captures` defaults to [`@external`](/home/setup/machine/overview#captures):
every program Mirage does not have itself. Name `@python` to run
Python in the container too. For one container per agent, make each
container a machine of its own and send each session to its machine with a
[route](/home/policy/route-machine#route-a-line).

```python
from mirage import RAMVFS, MountMode, Workspace

ws = Workspace(
    {"/data": RAMVFS()},
    mode=MountMode.EXEC,
    machines={"box": {"provider": "apple_container", "container": "my-sandbox", "captures": ["@python", "@external"]}},
)
await ws.shell("python3 -c 'print(1 + 1)'")
```
