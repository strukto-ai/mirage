Runs programs in a Daytona cloud sandbox. Settings and notes: [Daytona](/home/setup/machine/daytona).

## Install

```bash
pip install 'mirage-ai[daytona]'
```

## Usage

`captures` defaults to [`@external`](/home/setup/machine/overview#captures):
every program Mirage does not have itself. Name `@python` to run
Python in the sandbox too.

```python
from mirage import RAMVFS, MountMode, Workspace

ws = Workspace(
    {"/data": RAMVFS()},
    mode=MountMode.EXEC,
    machines={"box": {"provider": "daytona", "sandbox_id": "sandbox-id", "captures": ["@python", "@external"]}},
)
await ws.shell("python3 -c 'print(1 + 1)'")
```
