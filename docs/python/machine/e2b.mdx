Runs programs in an E2B cloud sandbox. Settings and notes: [E2B](/home/setup/machine/e2b).

## Install

```bash
pip install 'mirage-ai[e2b,ssh]'
```

## Usage

`captures` defaults to [`@external`](/home/setup/machine/overview#captures):
every program Mirage does not have itself. Name `@python` to run
Python in the sandbox too.

```python
from mirage import RAMVFS, MountMode, Workspace

ws = Workspace(
    {"/data": RAMVFS()},
    mode=MountMode.EXEC,
    machines={
        "box": {
            "provider": "e2b",
            "sandbox_id": "sandbox-id",
            "mount_type": "ssh",
            "captures": ["@python", "@external"],
        }
    },
)
await ws.shell("python3 -c 'print(1 + 1)'")
```

## Connecting the workspace

Pick a [`mount_type`](/home/setup/machine/overview#connecting-the-workspace). `ssh`, `mirage` and `both` do not work in browsers. Under
`ssh` each file call is about 150 ms for a small file from a laptop; under
`mirage`, files on `ram` and `sql` mounts stay cached in the sandbox once
read, unless a policy judges the session's file calls, and its template
needs `mirage-fuse`. With `own`,
base the template on [the machine image](/home/setup/machine/overview#the-machine-image)
and run `mirage workspace create /tmp/sandbox.yaml` in the sandbox.

### A template for ssh

Build a template with `sshfs` and pass its sandbox ID as `sandbox_id`:

```python
from e2b import AsyncSandbox, Template

Template.build(Template().from_base_image().apt_install("sshfs"), "mirage-sshfs")
sandbox = await AsyncSandbox.create("mirage-sshfs", timeout=3600)
print(sandbox.sandbox_id)
```

### A template for mirage

`mirage` needs [`mirage-fuse`](/home/setup/machine/overview#mirage), built
for x86_64, and `fuse3` in the sandbox. Build a template with both, from the
directory holding `mirage-fuse`, and name it as `template`:

```python
from e2b import Template

Template.build(
    Template()
    .from_base_image()
    .apt_install("fuse3")
    .copy("mirage-fuse", "/usr/local/bin/mirage-fuse", user="root", mode=0o755),
    "mirage-fuse",
)
```
