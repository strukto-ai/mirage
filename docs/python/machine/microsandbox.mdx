What to install and a runnable Python example. The settings, how the workspace connects and the notes are on [microsandbox](/home/setup/machine/microsandbox), shared by both SDKs.

## Usage

`captures` defaults to [`@external`](/home/setup/machine/overview#captures).
Add `@python` to run Python programs in the guest too.

```python
from mirage import RAMVFS, MountMode, Workspace

ws = Workspace(
    {"/data": RAMVFS()},
    mode=MountMode.EXEC,
    machines={"box": {"provider": "microsandbox", "sandbox": "mirage-box", "captures": ["@python", "@external"]}},
)
await ws.shell("python3 -c 'print(1 + 1)'")
```
