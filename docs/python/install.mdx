## Quick Install

Mirage needs Python 3.12 or newer. In a uv project, install the base package:

```bash
uv add mirage-ai
```

In a plain virtual environment, `uv pip install mirage-ai` or
`python -m pip install mirage-ai` does the same.

The base package ships the workspace, the RAM and Disk VFS and the shell, and
is enough to follow the [Python Quickstart](/python/quickstart).

storage, machine or agent SDK you use, with `uv add "mirage-ai[<extra>]"`:

A VFS that talks HTTP, such as Slack, Notion or the Hugging Face Hub, needs no
extra.

## The `mirage` CLI

To use only the `mirage` CLI, run it with `uvx` or install it on `PATH`:

```bash
uvx --from mirage-ai mirage --help
uv tool install mirage-ai
```

`uv tool install --upgrade mirage-ai` upgrades it.

## Install From Source

Building from source needs Rust. Install [rustup](https://rustup.rs); the repository's `rust/rust-toolchain.toml` selects the toolchain.

To contribute to Mirage or run the examples:

```bash
git clone https://github.com/strukto-ai/mirage.git
cd mirage/python
uv sync --all-extras
```
