## Quick Install

Mirage requires Python 3.12 or newer. In a uv project, install the base package with:

```bash
uv add mirage-ai
```

This is enough to start with local workflows such as the RAM VFS and to understand the Mirage execution model.

In an activated standalone virtual environment, use either installer:

```bash
uv pip install mirage-ai
# or
python -m pip install mirage-ai
```

## Use Mirage as a CLI

If you only want the `mirage` CLI (not the library), there are two convenient paths.

**One-shot run with `uvx`**, no install, just runs:

```bash
uvx --from mirage-ai mirage --help
uvx --from mirage-ai mirage workspace create workspace.yaml --id demo
```

**Persistent install with `uv tool install`**, drops `mirage` on your PATH globally:

```bash
uv tool install mirage-ai
mirage --help
```

To upgrade later:

```bash
uv tool install --upgrade mirage-ai
```

## VFS Extras

Install extras when a VFS needs optional dependencies:

```bash
uv add "mirage-ai[s3]"
uv add "mirage-ai[r2]"
uv add "mirage-ai[redis]"
uv add "mirage-ai[fuse]"
```

Use the VFS docs in the Python section when you are ready to connect real systems.

## Install From Source

If you are contributing to Mirage or want the full local development setup:

```bash
git clone https://github.com/strukto-ai/mirage.git
cd mirage/python
uv sync --all-extras
```

## Recommended Path

1. Install the base package.
2. Follow the [Python Quickstart](/python/quickstart) with the RAM VFS.
3. Add the VFS extras and follow the [FUSE setup](/python/setup/fuse) if you need to expose mounts as a real filesystem.
