[Agno](https://docs.agno.com) groups an agent's tools into `Toolkit` classes. Mirage ships `MirageToolkit`, a toolkit over a `Workspace`, so the agent's shell and file tools run in the workspace's mounts instead of on the host.

## Install

```bash
uv add 'mirage-ai[agno]'
```

## Usage

```python
import asyncio

from agno.agent import Agent
from agno.models.openai import OpenAIResponses

from mirage import MountMode, RAMVFS, Workspace
from mirage.agents.agno import MirageToolkit

ws = Workspace({"/data": RAMVFS()}, mode=MountMode.WRITE)

agent = Agent(
    model=OpenAIResponses(id="gpt-6.1-sol"),
    tools=[MirageToolkit(ws)],
    instructions="Use the shell tools to explore and read files.",
    markdown=True,
)


async def main() -> None:
    await ws.shell('echo "hello from mirage" | tee /data/hello.txt')
    await agent.aprint_response(
        "List all files under /data and show the contents of each one.")
    await ws.close()


asyncio.run(main())
```

## Tools

The toolkit serves the session's seven tools, [`session.tools`](/python/access/in-app#session-tools): `shell`, `read`, `write`, `edit`, `ls`, `grep` and `glob`, filtered by the session's profile. Each tool is a sync and async pair under one name. Agno calls the async one in `arun` and `aprint_response`, and the sync one otherwise.

`MirageToolkit(ws, session_id="agent")` acts as a session made with [`ws.session`](/python/access/in-app#workspace-methods), so its profile judges every call. `stale_write_protection=False` lets the agent overwrite a file that changed since it read it.
