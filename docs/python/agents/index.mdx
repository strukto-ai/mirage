## Coding Agents

Run the agent as it is, on a workspace the `mirage` CLI creates.

| Agent | CLI | SSH | FUSE |
| --- | :-: | :-: | :-: |
| [Claude Code](/python/agents/claude-code) | ✓ | | ✓ |
| [Codex](/python/agents/codex) | ✓ | ✓ | ✓ |
| [Grok Build](/python/agents/grok-build) | ✓ | | ✓ |

- **CLI**: the agent adds Mirage's seven tools from `mirage mcp`.
- **SSH**: the agent's own tools run in the workspace.
- **FUSE**: the agent's own tools work on the workspace, mounted as a folder.

## Agent SDKs

Your program holds the workspace and hands it to the framework.

| Framework | Hand it | The agent gets |
| --- | --- | --- |
| [Claude Agent SDK](/python/agents/claude-agent-sdk) | `MirageServer(ws)` | Mirage's seven tools |
| [Agno](/python/agents/agno) | `MirageToolkit(ws)` | Mirage's seven tools |
| [OpenAI Agents](/python/agents/openai-agents) | `MirageShellExecutor(ws)`, `MirageEditor(ws)`, `MirageSandboxClient(ws)` | its shell, patch and sandbox tools, run in Mirage |
| [LangChain Deep Agents](/python/agents/langchain) | `LangchainWorkspace(ws)` | its file and shell tools, run in Mirage |
| [OpenHands](/python/agents/openhands) | `MirageWorkspace(workspace=ws)` | its workspace and terminal, run in Mirage |
| [Pydantic AI](/python/agents/pydantic-ai) | `PydanticAIWorkspace(ws)` | its file and shell tools, run in Mirage |
| [Haystack](/python/agents/haystack) | `MirageShellTool(...)` | a bash tool |

Mirage's seven tools are the session's [`session.tools`](/python/access/in-app#session-tools): `shell`, `read`, `write`, `edit`, `ls`, `grep` and `glob`.

Each framework is an extra: `claude-agent-sdk`, `agno`, `openai`, `deepagents`, `openhands` or `pydantic-ai`.

```bash
uv add 'mirage-ai[agno]'
```

Haystack installs as `mirage-haystack`, which deepset maintains.
