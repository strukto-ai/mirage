Connect an agent in one of three ways. Every call it makes through Mirage goes
through its mounts, modes and policy.

These run unchanged, on a workspace the `mirage` CLI creates, whatever
language the app is in.

Mirage's seven tools are the session's
[`session.tools`](/python/access/in-app#session-tools): `shell`, `read`,
`write`, `edit`, `ls`, `grep` and `glob`. A session gets only the ones its
[profile](/home/policy/explain#which-tools-the-agent-gets) leaves it, so an
agent is never offered a tool whose every call would be refused. Haystack's
integration is deepset's own package.

## API & Environment

The provider runs the agent, and the workspace is its environment: its own
shell and file tools run in Mirage.

| API | Hand it | The agent gets |
| --- | --- | --- |

| <img noZoom src="/images/claude-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[Claude Managed Agents](/python/agents/claude-managed-agents) | `mirage_tools(ws)`, in an `EnvironmentWorker` | its `bash`, `read`, `write`, `edit`, `glob` and `grep`, run in Mirage |
