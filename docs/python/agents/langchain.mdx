[Deep Agents](https://docs.langchain.com/oss/python/deepagents/overview) is LangChain's harness for long-running agents. It takes a pluggable `backend` for its file and shell tools. Mirage ships `LangchainWorkspace`, a backend over a `Workspace`, so every file the agent touches and every command it runs stays in the workspace's mounts.

## Install

```bash
uv add 'mirage-ai[deepagents]' langchain-anthropic
```

Add the LangChain integration package for the chat model in use, such as `langchain-anthropic` or `langchain-openai`.

## Usage

```python
import asyncio

from deepagents import create_deep_agent

from mirage import MountMode, RAMVFS, Workspace
from mirage.agents.langchain import (
    LangchainWorkspace,
    build_system_prompt,
    extract_text,
)

ws = Workspace({"/": RAMVFS()}, mode=MountMode.WRITE)


async def main() -> None:
    agent = create_deep_agent(
        model="anthropic:claude-sonnet-5-5",
        system_prompt=await build_system_prompt(
            mount_info={"/": "In-memory filesystem (read/write)"},
        ),
        backend=LangchainWorkspace(ws),
    )
    result = await agent.ainvoke({
        "messages": [{"role": "user", "content": "Create /report.md and summarize."}],
    })
    for text in extract_text(result["messages"][-1:]):
        print(text)
    await ws.close()


asyncio.run(main())
```

## Tools

The agent keeps Deep Agents' own file tools, run in Mirage: `ls`, `read_file`, `write_file`, `edit_file`, `delete`, `glob` and `grep`. `LangchainWorkspace` is a sandbox backend, so the agent also gets `execute`, which runs a command line in Mirage's shell. Every call acts as the session (`session_id`, default the workspace's own), so its profile and the mount modes judge it.

`read_file` passes images, PDFs, audio, video and PowerPoint files to the model as multimodal content, when the model supports that input. Text files keep line-based pagination.
