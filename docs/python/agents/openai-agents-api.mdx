OpenAI's [Agents API](https://developers.openai.com/api/docs/guides/agents-api/overview) runs the agent on OpenAI's servers. With a `self_hosted` environment, its shell commands, file reads and patches run in a Mirage workspace, under the workspace's profile and mount modes. No sandbox holds the files.

The workspace connects through Codex's exec-server relay, set up on the [Codex page](/python/agents/codex#exec-server-forward).

## Install

```bash
uv add openai
```

## Workspace

OpenAI's examples work in `/workspace`:

```yaml workspace.yaml
mode: write
mounts:
  /workspace:
    vfs: ram
  /data:
    vfs: s3
    mode: read
    config:
      bucket: my-bucket
```

```bash
mirage workspace create workspace.yaml --id demo
```

## Create a session

```python
from openai import OpenAI

client = OpenAI()
session = client.beta.agents.sessions.create(
    agent={"model": "gpt-6-astra"},
    environment={"type": "self_hosted", "workspace_directory": "/workspace"},
)
print(session.environment.id, session.environment.remote_url)
```

## Connect the workspace

Hand the session's `environment.id` and `environment.remote_url`, with an [environment key](https://developers.openai.com/api/docs/guides/agents-api/environments/self-hosted#authentication), to [`codex exec-server forward`](/python/agents/codex#exec-server-forward) pointed at workspace `demo`. Then [send input](https://developers.openai.com/api/docs/guides/agents-api/sessions#send-input) to the session. The agent's commands run in the workspace, and what it writes lands in its mounts.

The Agents API is in beta.
