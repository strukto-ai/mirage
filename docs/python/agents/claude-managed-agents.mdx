[Claude Managed Agents](https://platform.claude.com/docs/en/managed-agents/overview) runs the agent loop on Anthropic's servers. In a [self-hosted environment](https://platform.claude.com/docs/en/managed-agents/self-hosted-sandboxes), a worker on private infrastructure runs the agent's tool calls. `mirage_tools(ws)` gives that worker Mirage's `bash`, `read`, `write`, `edit`, `glob` and `grep`, so every call runs in the workspace, under its profile, mounts and policies. The worker only connects out to Anthropic.

## Install

```bash
uv add 'mirage-ai[claude-managed-agents]'
```

## Usage

Create a self-hosted environment, generate its environment key, and create an agent with the `agent_toolset_20260401` toolset, as [Anthropic's guide](https://platform.claude.com/docs/en/managed-agents/self-hosted-sandboxes) shows. Then serve the environment's sessions from a workspace:

```python
import asyncio
import os

from anthropic import AsyncAnthropic
from anthropic.lib.environments import EnvironmentWorker

from mirage import MountMode, RAMVFS, Workspace
from mirage.agents.claude_managed_agents import mirage_tools


async def main() -> None:
    ws = Workspace({"/workspace": RAMVFS()}, mode=MountMode.WRITE)
    environment_key = os.environ["ANTHROPIC_ENVIRONMENT_KEY"]
    try:
        async with AsyncAnthropic(auth_token=environment_key) as client:
            await EnvironmentWorker(
                client,
                environment_id=os.environ["ANTHROPIC_ENVIRONMENT_ID"],
                environment_key=environment_key,
                tools=mirage_tools(ws),
            ).run()
    finally:
        await ws.close()


asyncio.run(main())
```

The worker authenticates with the environment key alone, so the Claude API key stays off the worker's machine. Create sessions that target the environment from anywhere else; the worker claims each one and answers its tool calls.

## Tools

- The tools keep the toolset's names. One the session's [profile](/home/policy/overview) would always refuse is left out: a read-only workspace gets no `write` or `edit`.
- `bash` runs Mirage's shell, so a line sees the workspace's mounts and commands, not the worker's machine. A `restart` is refused, since the session keeps its directory and variables. A relative path resolves against the session's working directory, which `cd` moves.
- `write` overwrites a file only after the agent read all of it, and `write` and `edit` refuse a file that changed since the agent read it. `stale_write_protection=False` turns that off.
- `session_id=` runs the tools as another session, with its profile.
- `web_search` and `web_fetch` still run on Anthropic's servers. Turn them off in the agent's toolset to keep the agent to the workspace.
