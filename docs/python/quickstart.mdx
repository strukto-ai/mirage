## Installation

Use Python 3.11 or newer. In a uv project, install Mirage with:

```bash
uv add mirage-ai
```

In another activated environment, install it with:

```bash
python -m pip install mirage-ai
```

## Create a Workspace

Start with the RAM VFS so you can try Mirage without credentials.

```python quickstart.py
import asyncio

from mirage import MountMode, Workspace
from mirage.vfs.ram import RAMVFS


async def main() -> None:
    ws = Workspace({"/data": RAMVFS()}, mode=MountMode.WRITE)
    await ws.shell('echo \'{"name": "alice"}\' > /data/user.json')
    for command in (
        "ls /data",
        'jq -r ".name" /data/user.json',
        "grep alice /data/user.json",
    ):
        result = await ws.shell(command)
        print(await result.stdout_str(), end="")
    await ws.close()


asyncio.run(main())
```

For a uv project, run `uv run python quickstart.py`. If you installed Mirage in
another activated environment, run `python quickstart.py`. It lists `user.json`,
prints `alice`, then prints the matching JSON document.

Shell failures are returned in the result; check `exit_code` and `stderr_str()`
when needed. See the [in-app API reference](/python/access/in-app#session-shell).
