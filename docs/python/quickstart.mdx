## Installation

Use Python 3.12 or newer. In a uv project, install Mirage with:

```bash
uv add mirage-ai
```

For other environments and extras, see [Installation](/python/install).

## Create a Workspace

Start with the RAM VFS, an in-memory filesystem mounted at `/data` that needs
no credentials.

```python quickstart.py
import asyncio

from mirage import MountMode, Workspace
from mirage.vfs.ram import RAMVFS


async def main() -> None:
    ws = Workspace({"/data": RAMVFS()}, mode=MountMode.WRITE)
    await ws.shell('echo \'{"name": "alice"}\' > /data/user.json')

    files = await ws.shell("ls /data")
    print(await files.stdout_str(), end="")

    name = await ws.shell('jq -r ".name" /data/user.json')
    print(await name.stdout_str(), end="")

    match = await ws.shell("grep alice /data/user.json")
    print(await match.stdout_str(), end="")

    await ws.close()


asyncio.run(main())
```

Run it with `uv run python quickstart.py`, or `python quickstart.py` in another
activated environment. Output:

```text
user.json
alice
{"name": "alice"}
```

Mounts are read-only unless you set a mode. `MountMode.WRITE` lets the shell create and change files under `/data`.

`ws.shell` does not raise when a command fails. Check `result.exit_code`, and
read the message with `await result.stderr_str()`. See the
[in-app API reference](/python/access/in-app#session-shell).

Later pages show the body of an `async def main()`; run it with
`asyncio.run(main())`, as here.
