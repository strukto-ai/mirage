## Installation

Use Python 3.12 or newer. In a uv project, install Mirage with:

```bash
uv add mirage-ai
```

In another activated environment, install it with:

```bash
python -m pip install mirage-ai
```

## Create a Workspace

Start with the RAM VFS, which needs no credentials.

```python quickstart.py
import asyncio

from mirage import MountMode, Workspace
from mirage.vfs.ram import RAMVFS


async def main() -> None:
    ws = Workspace({"/data": RAMVFS()}, mode=MountMode.WRITE)
    await ws.shell('echo \'{"name": "alice"}\' > /data/user.json')

    files = await ws.shell("ls /data")
    print(await files.stdout_str(), end="")

    name = await ws.shell('jq -r ".name" /data/user.json')
    print(await name.stdout_str(), end="")

    match = await ws.shell("grep alice /data/user.json")
    print(await match.stdout_str(), end="")

    await ws.close()


asyncio.run(main())
```

Run it with `uv run python quickstart.py`, or `python quickstart.py` in another
activated environment. It lists `user.json`,
prints `alice`, then prints the matching JSON document.

Shell failures are returned in the result; check `exit_code` and `stderr_str()`
when needed. See the [in-app API reference](/python/access/in-app#session-shell).
