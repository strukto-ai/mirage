The HF Buckets resource mounts a [Hugging Face Bucket](https://huggingface.co/docs/buckets)
as a virtual filesystem. Reads go directly over HF's HTTP API with `aiohttp`
(true async streaming, no SDK dependency). Writes use the `huggingface_hub`
SDK for the Xet upload protocol.

For credential setup, see [HF Buckets Setup](/python/setup/hf_buckets).

## Config

```python
import os

from mirage import MountMode, Workspace
from mirage.resource.hf_buckets import HfBucketsConfig, HfBucketsResource

config = HfBucketsConfig(
    bucket=os.environ["HF_BUCKET_NAME"],
    token=os.environ["HF_TOKEN"],
)
resource = HfBucketsResource(config)
ws = Workspace({"/hf": resource}, mode=MountMode.READ)
```

## Filesystem Layout

Bucket paths map to virtual paths under the mount prefix.

For example, if bucket `your-user/my-data` contains:

```text
data/example.json
data/example.parquet
data/example.jsonl
```

Then mounting at `/hf/` exposes:

```text
/hf/
  data/
    example.json
    example.parquet
    example.jsonl
```

Path mapping: virtual `/hf/data/example.json` resolves to bucket key
`data/example.json`.

## Cache

Uses `IndexCacheStore` with 10-minute TTL. Directory listings populate
file-size/type entries that `stat` reads via a fast path, so a `readdir`
followed by per-entry `stat` calls (which is what `ls`, FUSE `getattr`,
and most shell commands trigger) costs one HTTP request instead of N.

## Example

```python
import asyncio
import os

from dotenv import load_dotenv

from mirage import MountMode, Workspace
from mirage.resource.hf_buckets import HfBucketsConfig, HfBucketsResource

load_dotenv(".env.development")

config = HfBucketsConfig(
    bucket=os.environ["HF_BUCKET_NAME"],
    token=os.environ["HF_TOKEN"],
)
resource = HfBucketsResource(config)


async def main():
    ws = Workspace({"/hf/": resource}, mode=MountMode.READ)

    r = await ws.execute("ls /hf/")
    print(await r.stdout_str())

    r = await ws.execute("cat /hf/data/example.json | head -n 10")
    print(await r.stdout_str())

    r = await ws.execute("tree /hf/")
    print(await r.stdout_str())

    r = await ws.execute("stat /hf/data/example.json")
    print(await r.stdout_str())


if __name__ == "__main__":
    asyncio.run(main())
```

## Shell Commands

The HF Buckets resource mirrors the S3 command surface (`cat`, `ls`, `head`,
`tail`, `grep`, `rg`, `wc`, `find`, `tree`, `jq`, `stat`, `du`, plus the
full text-processing/compression/encoding/data-format set). Parquet, Feather,
ORC, and HDF5 reads pretty-print through the optional filetype dispatch.

Writes (`write_bytes`, `unlink`, `create`, `mkdir`) require the
`hf_buckets` extra to be installed.
