## Quick Install

For Node applications, use Node 22.20+ on Node 22, 24.12+ on Node 24, or
25+. Install the Node package:

```bash
pnpm add @struktoai/mirage-node
```

It includes the workspace, the shell, and the RAM and Disk VFS: enough for the [Quickstart](/typescript/quickstart).

The packages use ECMAScript modules (ESM). In your application directory,
set `"type": "module"` in `package.json` before importing them:

```bash
npm pkg set type=module
```

npm, pnpm and yarn all work. For FUSE with pnpm, see [FUSE setup](/typescript/setup/fuse).

The FUSE binding also needs pnpm's `onlyBuiltDependencies` allow-list and, on macOS, the macFUSE 4+ symlink workaround described in the [TypeScript FUSE setup](/typescript/setup/fuse).

For a browser application, install `@struktoai/mirage-browser` instead and
follow the [browser quickstart](/typescript/browser-quickstart).

## Install From Source

To contribute to Mirage or run the examples:

Building from source needs Rust 1.88 or newer. Install it with [rustup](https://rustup.rs).

```bash
git clone https://github.com/strukto-ai/mirage.git
cd mirage/typescript
pnpm install
pnpm build
```

The examples in `examples/typescript/` link to the workspace packages via pnpm's workspace protocol, so changes in `packages/core` or `packages/node` are picked up on the next `pnpm build`.
