| Way | Claude Code gets | Needs |
| --- | --- | --- |
| [CLI](#cli) | Mirage's seven tools, beside its own | the `mirage` CLI |
| [FUSE](#fuse) | its own tools, on the workspace as a folder | a [FUSE driver](/home/setup/fuse) |

## Install

```bash
npm install -g @struktoai/mirage-cli
```

On macOS, FUSE also needs the [macFUSE 4 workaround](/typescript/setup/fuse#macos-4-symlink-workaround). Install [Claude Code](https://docs.claude.com/en/docs/claude-code/setup) separately.

## Workspace

```yaml workspace.yaml
mode: write
mounts:
  /:
    vfs: ram
    backend: fuse                 # FUSE only
    mountpoint: /tmp/mirage-demo  # FUSE only
  /s3:
    vfs: s3
    mode: read
    config:
      bucket: my-bucket
```

```bash
mirage workspace create workspace.yaml --id demo
```

## CLI

```bash
claude mcp add mirage -- mirage mcp -w demo
```

Claude Code gets `shell`, `read`, `write`, `edit`, `ls`, `grep` and `glob` from the workspace's [MCP server](/home/access/mcp).

## FUSE

```bash
cd /tmp/mirage-demo && claude
```

Every file and shell call Claude Code makes goes through Mirage: `/tmp/mirage-demo/s3` is the bucket. `mirage workspace delete demo` unmounts it. On macOS the daemon holds one FUSE mount at a time.
