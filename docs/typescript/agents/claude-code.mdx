| --- | --- | --- |

## Install

```bash
npm install -g @struktoai/mirage-cli
```

Install [Claude Code](https://docs.claude.com/en/docs/claude-code/setup) separately.

## Plugin

Install the Mirage plugin from Claude Code:

```text
/plugin marketplace add strukto-ai/mirage
/plugin install mirage@mirage
```

The plugin bundles filesystem and VFS authoring skills with a workspace MCP
launcher. The launcher runs `npx -y @struktoai/mirage-cli mcp`, so it needs Node.js
and a configured Mirage workspace. See [MCP access](/home/access/mcp) to select
a workspace or connect to a remote server.

## Workspace

```yaml workspace.yaml
mode: write
mounts:
  /:
    vfs: ram
```

```bash
mirage workspace create workspace.yaml --id demo
```

## CLI

```bash
claude mcp add mirage -- mirage mcp -w demo
```

Claude Code gets `shell`, `read`, `write`, `edit`, `ls`, `grep` and `glob` from the workspace's [MCP server](/home/access/mcp).

## FUSE

Install your platform's [FUSE driver](/home/setup/fuse). On macOS, also follow the [macFUSE 4 workaround](/typescript/setup/fuse#macfuse-4-symlink-workaround). Then expose the RAM mount at a local folder:

```yaml workspace-fuse.yaml
mode: write
mounts:
  /:
    vfs: ram
    backend: fuse
    mountpoint: /tmp/mirage-demo
```

```bash
mirage workspace create workspace-fuse.yaml --id demo-fuse
cd /tmp/mirage-demo && claude
```

File operations inside `/tmp/mirage-demo` go through Mirage. The mount does not restrict the agent’s access to other host paths. `mirage workspace delete demo-fuse` unmounts it. On macOS the daemon holds one FUSE mount at a time.
