The [Vercel AI SDK](https://sdk.vercel.ai) (`ai`) drives tool-calling agents around any provider in its registry. Mirage ships an AI SDK 7 tool factory that gives `generateText`, `streamText` and agent loops a session's seven tools.

## Install

`@struktoai/mirage-vercel` is runtime-agnostic. Pair it with `@struktoai/mirage-node` for Node or `@struktoai/mirage-browser` for the browser.

<CodeGroup>
```bash Node
pnpm add @struktoai/mirage-vercel @struktoai/mirage-node ai @ai-sdk/openai
```
```bash Browser
pnpm add @struktoai/mirage-vercel @struktoai/mirage-browser ai @ai-sdk/openai
```
</CodeGroup>

## Usage

```ts
import { MountMode, RAMVFS, Workspace } from '@struktoai/mirage-node'
import { generateText, stepCountIs } from 'ai'
import { openai } from '@ai-sdk/openai'
import { buildSystemPrompt, mirageTools } from '@struktoai/mirage-vercel'

const ws = new Workspace({ '/': new RAMVFS() }, { mode: MountMode.WRITE })

const { text } = await generateText({
  model: openai('gpt-5.4-mini'),
  system: await buildSystemPrompt({
    mountInfo: { '/': 'In-memory filesystem (read/write)' },
  }),
  prompt:
    "Create /hello.txt with 'hi from mirage' and /data/numbers.csv with 3 sample rows. " +
    'Then list and read every file back.',
  tools: mirageTools(ws),
  stopWhen: stepCountIs(20),
})

console.log(text)
```

## Exports

{/* generated: exports vercel start */}
| Symbol | Purpose |
| --- | --- |
| `MIRAGE_SYSTEM_PROMPT` | The default system prompt: how the Mirage filesystem differs from a plain one. |
| `buildSystemPrompt` | Returns `MIRAGE_SYSTEM_PROMPT` followed by a description of the mounted paths and any extra instructions, ready to use as an agent's system prompt. |
| `BuildSystemPromptOptions` | Options for `buildSystemPrompt`: a `workspace` (and `sessionId`) whose mounts to describe, or `mountInfo` mapping a prefix to a description when there is no workspace, and `extraInstructions` to append. |
| `mirageTools` | Returns Mirage's tool table as AI SDK tools, `{ shell, read, write, edit, ls, grep, glob }`, to spread into `tools`; `options` takes `sessionId` and `staleWriteProtection`. |
{/* generated: exports vercel end */}

`read` uses AI SDK 7's `toModelOutput`: text files come back as numbered lines, PDFs and supported images become file content parts, and other binary formats return a metadata note.
