The [Vercel AI SDK](https://sdk.vercel.ai) (`ai`) drives tool-calling agents around any provider in its registry. Mirage ships an AI SDK 7 tool factory that exposes a `Workspace` as Mirage's seven tools (`shell`, `read`, `write`, `edit`, `ls`, `grep`, `glob`), the same table MCP serves, for `generateText` / `streamText` / agent loops.

## Install

`@struktoai/mirage-agents/vercel` is runtime-agnostic. Pair it with `@struktoai/mirage-node` for Node or `@struktoai/mirage-browser` for the browser.

<CodeGroup>
```bash Node
pnpm add @struktoai/mirage-agents @struktoai/mirage-node ai @ai-sdk/openai
```
```bash Browser
pnpm add @struktoai/mirage-agents @struktoai/mirage-browser ai @ai-sdk/openai
```
</CodeGroup>

## Usage

```ts
import { MountMode, OpsRegistry, RAMVFS, Workspace } from '@struktoai/mirage-node'
import { generateText, stepCountIs } from 'ai'
import { openai } from '@ai-sdk/openai'
import { mirageTools } from '@struktoai/mirage-agents/vercel'
import { buildSystemPrompt } from '@struktoai/mirage-agents/openai'

const ram = new RAMVFS()
const ops = new OpsRegistry()
for (const op of ram.ops()) ops.register(op)
const ws = new Workspace({ '/': ram }, { mode: MountMode.WRITE, ops })

const { text } = await generateText({
  model: openai('gpt-5.4-mini'),
  system: await buildSystemPrompt({
    mountInfo: { '/': 'In-memory filesystem (read/write)' },
  }),
  prompt:
    "Create /hello.txt with 'hi from mirage' and /data/numbers.csv with 3 sample rows. " +
    'Then list and read every file back.',
  tools: mirageTools(ws),
  stopWhen: stepCountIs(20),
})

console.log(text)
```

## Exports

| Symbol | Purpose |
| --- | --- |
| `mirageTools(ws, options?)` | Returns `{ shell, read, write, edit, ls, grep, glob }`, each a `tool()` from `ai` ready to spread into `tools: { ... }`. Each answers `{ text, isError }` as the MCP tool of the same name does. |

### Tool reference

| Tool | Input | Answer |
| --- | --- | --- |
| `shell` | `{ command }` | the line's output; `isError` when it exits nonzero |
| `read` | `{ path, offset?, limit? }` | numbered lines; images and PDFs become file content parts |
| `write` | `{ path, content }` | creates parents; an existing file must be read in full first |
| `edit` | `{ path, old_string, new_string, replace_all? }` | refuses a file changed since it was read |
| `ls` | `{ path }` | one entry per line |
| `grep` | `{ pattern, path, ignore_case?, fixed_strings?, include?, context?, files_with_matches?, count?, max_count? }` | `grep -rn` output |
| `glob` | `{ pattern, path? }` | matching files, sorted |

`read` uses AI SDK 7's `toModelOutput`: text files come back as numbered lines, PDFs and supported images become file content parts, and other binary formats return a metadata note.
