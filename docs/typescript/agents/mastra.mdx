[Mastra](https://mastra.ai) is an opinionated TypeScript framework for AI agents and workflows. Mirage ships a tool factory that gives a Mastra `Agent` a session's seven tools.

<Note>
  Node only. The Mirage adapter is runtime-agnostic, but most Mastra setups (memory, evals, workflows) depend on Node APIs.
</Note>

## Install

```bash
pnpm add @struktoai/mirage-mastra @struktoai/mirage-node @mastra/core
```

## Usage

```ts
import { MountMode, RAMVFS, Workspace } from '@struktoai/mirage-node'
import { Agent } from '@mastra/core/agent'
import { buildSystemPrompt, mirageTools } from '@struktoai/mirage-mastra'

const ws = new Workspace({ '/': new RAMVFS() }, { mode: MountMode.WRITE })

const agent = new Agent({
  id: 'mirage-ram-agent',
  name: 'Mirage RAM Agent',
  instructions: await buildSystemPrompt({
    mountInfo: { '/': 'In-memory filesystem (read/write)' },
  }),
  model: 'openai/gpt-5.4-mini',
  tools: mirageTools(ws),
})

const result = await agent.generate(
  "Create /hello.txt with 'hi from mirage' and list every file under /.",
  { maxSteps: 20 },
)
console.log(result.text)
```

## Exports

{/* generated: exports mastra start */}
| Symbol | Purpose |
| --- | --- |
| `MIRAGE_SYSTEM_PROMPT` | The default system prompt: how the Mirage filesystem differs from a plain one. |
| `buildSystemPrompt` | Returns `MIRAGE_SYSTEM_PROMPT` followed by a description of the mounted paths and any extra instructions, ready to use as an agent's system prompt. |
| `BuildSystemPromptOptions` | Options for `buildSystemPrompt`: a `workspace` (and `sessionId`) whose mounts to describe, or `mountInfo` mapping a prefix to a description when there is no workspace, and `extraInstructions` to append. |
| `mirageTools` | Returns Mirage's tool table as Mastra tools, `{ shell, read, write, edit, ls, grep, glob }` as far as the session's profile allows them (`MirageToolOperations.names`), each a `createTool()` with the id `mirage-<tool>`; `options` takes `sessionId` and `staleWriteProtection`. |
