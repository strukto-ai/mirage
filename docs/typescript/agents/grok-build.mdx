| Way | Grok Build gets | Needs |
| --- | --- | --- |
| [CLI](#cli) | Mirage's seven tools, beside its own | Node.js 20.10 or newer |
| [FUSE](#fuse) | its own tools, on the workspace as a folder | a [FUSE driver](/home/setup/fuse) |

## Install

```bash
npm install -g @struktoai/mirage-cli
```

On macOS, FUSE also needs the [macFUSE 4 workaround](/typescript/setup/fuse#macos-4-symlink-workaround). Install [Grok Build](https://x.ai/cli) separately; its command is `grok`.

## Workspace

```yaml .mirage/workspace.yaml
mode: write
mounts:
  /:
    vfs: ram
    backend: fuse                 # FUSE only
    mountpoint: /tmp/mirage-demo  # FUSE only
  /s3:
    vfs: s3
    mode: read
    config:
      bucket: my-bucket
```

## CLI

```bash
grok plugin install strukto-ai/mirage
```

The plugin runs `mirage mcp` through `npx` on your project's `.mirage/workspace.yaml`, so Grok gets `shell`, `read`, `write`, `edit`, `ls`, `grep` and `glob`, and a skill on how to use them. Open `/plugins` in `grok` to check that it is on.

## FUSE

```bash
mirage workspace create .mirage/workspace.yaml --id demo
cd /tmp/mirage-demo && grok
```

Every file and shell call Grok makes goes through Mirage: `/tmp/mirage-demo/s3` is the bucket. `mirage workspace delete demo` unmounts it. On macOS the daemon holds one FUSE mount at a time.
