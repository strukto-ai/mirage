## Coding Agents

Claude Code, Codex and Grok Build run as they are, on a workspace the `mirage` CLI creates, whatever language you build in. Their guides are under [Agents](/home/agents#coding-agents).

To replace an agent's own file and shell tools instead, load Mirage into it as a plugin:

| Agent | Plugin |
| --- | --- |
| [Pi Coding Agent](/typescript/agents/pi) | `mirageExtension(ws)` |
| [OpenCode](/typescript/agents/opencode) | `@struktoai/mirage-opencode` in `opencode.json` |
| [DeepSeek Harness](/typescript/agents/dsh) | `@struktoai/mirage-dsh` |

## Agent SDKs

Your program holds the workspace and hands it to the framework.

| Framework | Hand it | The agent gets |
| --- | --- | --- |
| [Vercel AI SDK](/typescript/agents/vercel) | `mirageTools(ws)` | Mirage's seven tools |
| [Mastra](/typescript/agents/mastra) | `mirageTools(ws)` | Mirage's seven tools |
| [Claude Agent SDK](/typescript/agents/claude-agent-sdk) | `MirageServer(ws)` | Mirage's seven tools |
| [OpenAI Agents](/typescript/agents/openai) | `mirageTools(ws)`, or `MirageShellExecutor`, `MirageEditor` and `MirageSandboxClient` | Mirage's seven tools, or its shell, patch and sandbox tools run in Mirage |
| [LangChain Deep Agents](/typescript/agents/langchain) | `new LangchainWorkspace(ws)` | its file and shell tools, run in Mirage |

Mirage's seven tools are the session's [`session.tools`](/typescript/access/in-app#session-tools): `shell`, `read`, `write`, `edit`, `ls`, `grep` and `glob`. A session gets the ones its [profile](/home/policy/explain#which-tools-the-agent-gets) leaves it (`session.tools.names()`), so an agent is never offered a tool every call of which would be refused.

Each framework is its own package: `@struktoai/mirage-vercel`, `@struktoai/mirage-mastra`, `@struktoai/mirage-claude-agent-sdk`, `@struktoai/mirage-openai-agents` or `@struktoai/mirage-langchain`.

```bash
pnpm add @struktoai/mirage-vercel @struktoai/mirage-node
```

When the framework supports browsers, use `@struktoai/mirage-browser` in place of `@struktoai/mirage-node`.

## API & Environment

The provider runs the agent, and the workspace is its environment: its own shell and file tools run in Mirage.

| API | Hand it | The agent gets |
| --- | --- | --- |
| [OpenAI Agents API](/typescript/agents/openai-agents-api) | a `self_hosted` environment, through [exec-server forward](/home/agents/codex#exec-server-forward) | its shell, file and patch tools, run in Mirage |
| [Claude Managed Agents](/typescript/agents/claude-managed-agents) | `mirageTools(ws)`, in an `EnvironmentWorker` | its `bash`, `read`, `write`, `edit`, `glob` and `grep`, run in Mirage |
