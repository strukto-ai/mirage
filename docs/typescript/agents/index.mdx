Connect an agent in one of three ways. Every call it makes through Mirage goes
through its mounts, modes and policy.

language the app is in.

## Agent SDKs

The app holds the workspace and hands it to the framework.

| Framework | Install | Hand it | The agent gets |
| --- | --- | --- | --- |
| <Icon icon="triangle" size={14} /> [Vercel AI SDK](/typescript/agents/vercel) | `@struktoai/mirage-vercel` | `mirageTools(ws)` | Mirage's seven tools |
| <img noZoom src="/images/mastra-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[Mastra](/typescript/agents/mastra) | `@struktoai/mirage-mastra` | `mirageTools(ws)` | Mirage's seven tools |
| <img noZoom src="/images/claude-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[Claude Agent SDK](/typescript/agents/claude-agent-sdk) | `@struktoai/mirage-claude-agent-sdk` | `MirageServer(ws)` | Mirage's seven tools |
| <img noZoom src="/images/openai-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[OpenAI Agents](/typescript/agents/openai-agents) | `@struktoai/mirage-openai-agents` | `mirageTools(ws)`, or `MirageShellExecutor`, `MirageEditor` and `MirageSandboxClient` | Mirage's seven tools, or its shell, patch and sandbox tools run in Mirage |
| <img noZoom src="/images/langchain-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[LangChain Deep Agents](/typescript/agents/langchain) | `@struktoai/mirage-langchain` | `new LangchainWorkspace(ws)` | its file and shell tools, run in Mirage |

Install the adapter next to the host package, for example
`pnpm add @struktoai/mirage-vercel @struktoai/mirage-node`. When the framework
runs in a browser, use `@struktoai/mirage-browser` in place of
`@struktoai/mirage-node`.

Mirage's seven tools are the session's
[`session.tools`](/typescript/access/in-app#session-tools): `shell`, `read`,
`write`, `edit`, `ls`, `grep` and `glob`. A session gets only the ones its
[profile](/home/policy/explain#which-tools-the-agent-gets) leaves it, so an
agent is never offered a tool whose every call would be refused.

## API & Environment

The provider runs the agent, and the workspace is its environment: its own
shell and file tools run in Mirage.

| API | Hand it | The agent gets |
| --- | --- | --- |
| <img noZoom src="/images/openai-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[OpenAI Agents API](/typescript/agents/openai-agents-api) | a `self_hosted` environment, through [exec-server forward](/home/agents/codex#exec-server-forward) | its shell, file and patch tools, run in Mirage |
| <img noZoom src="/images/claude-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[Claude Managed Agents](/typescript/agents/claude-managed-agents) | `mirageTools(ws)`, in an `EnvironmentWorker` | its `bash`, `read`, `write`, `edit`, `glob` and `grep`, run in Mirage |
