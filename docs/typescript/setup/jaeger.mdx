For connection setup, see [Jaeger Setup](/home/setup/jaeger).
For the Python SDK, see [Jaeger (Python)](/python/vfs/jaeger).

```typescript
import { JaegerVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const ws = new Workspace({
  '/jaeger': new JaegerVFS({ host: 'http://localhost:16686' }),
}, { mode: MountMode.READ })

const res = await ws.shell('ls /jaeger/services')
console.log(res.stdoutText)
await ws.close()
```

The VFS ships in `@struktoai/mirage-node` only; `@struktoai/mirage-browser`
does not export it. In a YAML config or `buildVfs('jaeger', ...)`, the same
fields are snake_case (`default_trace_limit`).

## Config

| Field | Description |
| --- | --- |
| <code style={{ whiteSpace: 'nowrap' }}>host</code><br />default `'http://localhost:16686'` | Jaeger query service URL. |
| <code style={{ whiteSpace: 'nowrap' }}>defaultTraceLimit</code><br />default `100` | The most traces one service's `traces/` listing shows, newest first. An older trace is still readable by its id. |
| <code style={{ whiteSpace: 'nowrap' }}>defaultFromTimestamp</code> | Lower bound of trace listings, an ISO 8601 timestamp. Unset searches from the beginning. |
| <code style={{ whiteSpace: 'nowrap' }}>defaultToTimestamp</code> | Upper bound of trace listings, an ISO 8601 timestamp. Unset means now. |
| <code style={{ whiteSpace: 'nowrap' }}>timeout</code><br />default `DEFAULT_TIMEOUT` | Seconds a request may wait to connect, or between two reads of its answer, before it fails; a download that keeps flowing is never cut off. |

## Layout reference

| Path | Contents |
| --- | --- |
| `services/` | One directory per service Jaeger's `/api/services` reports, including Jaeger's own `jaeger` service when it traces itself |
| `services/<service>/operations.json` | The operation records `/api/operations` returns for the service |
| `services/<service>/traces/<trace-id>.json` | The trace document `/api/traces/<trace-id>` returns |

The `traces/` listing shows the newest `defaultTraceLimit` traces of the
service within `defaultFromTimestamp` and `defaultToTimestamp`. Unset bounds
search from the beginning up to now. A trace older than the listing is still
readable by its id, as long as one of its spans comes from that service.

A service Jaeger does not know, a trace id that is not 16 or 32 hex digits, and
a trace without a span from the addressed service are reported as missing
paths. Every listed file has an exact size, so `ls -l`, `du`, and `stat` work
without reading the files. The mount has no write operations.
