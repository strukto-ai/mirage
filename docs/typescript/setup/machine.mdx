`MachineVFS` shows the files of the workspace's machines at a prefix, reached
through the exec each machine's handle already holds. A workspace with
machines mounts `/tmp` and `/dev/shm` this way, and `'@local'` mounts any
other path; see [Machine files](/home/setup/machine/local).

## Install

```bash
npm install @struktoai/mirage-node
```

## Configure

```ts
import { MachineVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const ws = new Workspace(
  {
    '/testbed': '@local',
    '/gpu': new MachineVFS({ machines: ['gpu'], root: '/' }),
  },
  {
    mode: MountMode.WRITE,
    machines: {
      sandbox: { provider: 'docker', container: 'task-001499' },
      gpu: { provider: 'ssh', host: 'gpu.example.com' },
    },
  },
)
const result = await ws.shell('ls /gpu/models && grep -rn TODO /testbed/src')
console.log(result.stdoutText)
await ws.close()
```

`'@local'` at a prefix is `new MachineVFS({ root: prefix })` over every
machine. A machine mount needs a workspace with machines, and a name in
`machines` or `defaultMachine` that is none of them is refused when the
workspace is built.

## Behavior

- **Caching:** none; every read and listing asks the machine.
- **Placement:** on several machines a read goes to the machine holding the
  name and a new name lands on the machine running the command's program,
  else on `defaultMachine`. See
  [Several machines](/home/setup/machine/local#several-machines).
- **Commands:** a command whose every path is one machine's own runs on that
  machine whole. See
  [What runs on the machine](/home/setup/machine/local#what-runs-on-the-machine).
- **Browser:** a page has no machines, so `@struktoai/mirage-browser` mounts
  none of this.

## Integration

The machine answers these on its own side, so the bytes do not travel:

- `head -n`, `tail -n`: `head` and `tail` there.
- `wc -l`: `wc -l` there.
- `md5sum`, `sha256sum` and the other hash commands: the matching sum tool.
- `grep -r` and `rg`: `grep -l` there finds which files hold the text.
- `find`, `du`, `ls -R`, `tree`: one `find` there.
