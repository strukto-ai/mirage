`GSlidesVFS` exposes Slides decks as `.gslide.json` files containing the deck structure, slides, and text content.

Setup steps for OAuth credentials live at [Google Workspace Credentials](/home/setup/google).

## Node

```bash
pnpm add @struktoai/mirage-node
```

```ts
import { GSlidesVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const slides = new GSlidesVFS({
  clientId: process.env.GOOGLE_CLIENT_ID!,
  clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
  refreshToken: process.env.GOOGLE_REFRESH_TOKEN!,
})

const ws = new Workspace({ '/slides': slides }, { mode: MountMode.READ })
await ws.shell('ls /slides/owned/')
```

## Browser

```bash
pnpm add @struktoai/mirage-browser
```

```ts
import { GSlidesVFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const slides = new GSlidesVFS({
  clientId: GOOGLE_CLIENT_ID,
  clientSecret: GOOGLE_CLIENT_SECRET,
  refreshToken: localStorage.getItem('gslides.refresh_token')!,
})
```

## Config

{/* generated: config-table gslides start */}
| Field | Required | Default | Description |
| --- | --- | --- | --- |
| `accessToken` | no |  | OAuth access token, or a function (sync or async) that returns one, read on every request. Use it instead of `clientId` and `refreshToken` when your app already manages OAuth; it wins when both are set. Redacted in snapshots. |
| `clientId` | no |  | Google OAuth client ID. Required with `refreshToken` when `accessToken` is unset; mirage then mints and renews access tokens itself. |
| `clientSecret` | no |  | Google OAuth client secret, sent with the refresh-token grant. Omit it for a PKCE client. Redacted in snapshots. |
| `refreshToken` | no |  | User's OAuth refresh token. Required with `clientId` when `accessToken` is unset. Redacted in snapshots. |
| `refreshFn` | no |  | Function that takes the refresh token and returns `{ accessToken, expiresIn }` (seconds), called instead of Google's token endpoint, for example so the client secret stays on a backend. `clientId` and `refreshToken` are still required. Redacted in snapshots. |
| `apiBase` | no |  | One base URL that replaces every Google API host and the OAuth token endpoint, such as a test server. Unset uses Google's hosts. |
| `folderId` | no |  | Drive folder ID the `gdrive` mount uses as its root instead of My Drive; it may be a folder in a Shared Drive. Other Google mounts ignore it. |
| `contentSearch` | no | `false` | Let `grep -w` and `rg -w` read only the files Drive full-text search names. Drive searches a file's text, not the JSON the mount renders, and indexes a write with a delay, so a file that holds the word can be left out. |

## Mount mode

`read`. A `MountMode.WRITE` mount also allows `mv` (retitle) and `rm` (delete). Edit a deck with the [gws CLI](/typescript/cli/gws).

For the JSON structure (slides, layouts, text frames) see the [Python Slides docs](/python/vfs/gslides).
