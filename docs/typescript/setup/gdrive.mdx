`GoogleDriveVFS` exposes a user's Drive (My Drive plus shared drives the user can see) as a tree.

Setup steps for OAuth credentials live at [Google Workspace Credentials](/home/setup/google).

## Node

```bash
pnpm add @struktoai/mirage-node
```

```ts
import { GoogleDriveVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const drive = new GoogleDriveVFS({
  clientId: process.env.GOOGLE_CLIENT_ID!,
  clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
  refreshToken: process.env.GOOGLE_REFRESH_TOKEN!,
})

const ws = new Workspace({ '/drive': drive }, { mode: MountMode.WRITE })
await ws.shell('ls /drive/')
```

## Browser

```bash
pnpm add @struktoai/mirage-browser
```

```ts
import { GoogleDriveVFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const drive = new GoogleDriveVFS({
  clientId: GOOGLE_CLIENT_ID,
  clientSecret: GOOGLE_CLIENT_SECRET,
  refreshToken: localStorage.getItem('gdrive.refresh_token')!,
})

const ws = new Workspace({ '/drive': drive }, { mode: MountMode.WRITE })
```

The browser examples in `examples/browser/vfs/gdrive/gdrive_pkce.ts` show a full PKCE flow that keeps the secret out of the page.

## Mount mode

`read`, `write` and `exec`. Under write mode the standard write commands (`tee`, `cp`, `mv`, `rm`, `mkdir`, `sed -i`, ...) work on regular files and folders; Google-native files (`.gdoc.json`, `.gsheet.json`, `.gslide.json`) are mutated through the `gws` commands instead. Use `MountMode.EXEC` if `python3` or `js` should run scripts from the mount.

A Shared Drive is writable on the same terms as My Drive: every Drive call carries `supportsAllDrives`, so what you may change is decided by your role on that drive rather than by the mount, and a role that forbids the change fails with `EACCES` on that operand.

## Integration

What Google Drive answers through its own API, so fewer files are read. [Integration](/home/integration/overview) explains each command.

| Command | On Google Drive |
| --- | --- |
| `grep -r`, `rg` | Drive full-text search, for whole words (`-w`, `-x`). It can miss Docs, Sheets and Slides JSON, office files, PDFs, archives, the end of large files, words Drive splits differently (`foo.bar`) and recent writes. |
| `md5sum`, `sha1sum`, `sha256sum` | The digest Drive keeps; a Docs, Sheets or Slides file is read |
| `find`, `du`, `ls -R`, `tree` | One recursive listing |

The [Python Google Drive docs](/python/vfs/gdrive#integration) list when each search answers and what it can miss.
