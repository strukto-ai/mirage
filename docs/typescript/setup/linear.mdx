`LinearVFS` exposes a Linear workspace as a tree of teams, projects, and issues. Reads route through the Linear GraphQL API.

Setup steps for the API key live at [Linear Credentials](/home/setup/linear).

## Node

```bash
pnpm add @struktoai/mirage-node
```

```ts
import { LinearVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const linear = new LinearVFS({
  apiKey: process.env.LINEAR_API_KEY!,
})

const ws = new Workspace({ '/linear': linear }, { mode: MountMode.READ })
await ws.shell('ls /linear/teams/')
```

## Browser

```bash
pnpm add @struktoai/mirage-browser
```

```ts
import { LinearVFS, MountMode, Workspace } from '@struktoai/mirage-browser'
```

## Config

{/* generated: config-table linear start */}
| Field | Description |
| --- | --- |
| <code style={{ whiteSpace: 'nowrap' }}>apiKey</code><br />required, secret | Linear personal API key. |
| <code style={{ whiteSpace: 'nowrap' }}>workspace</code> | Accepted for compatibility; not read. |
| <code style={{ whiteSpace: 'nowrap' }}>teamIds</code> | Only these teams are listed or readable. Unset shows every team the key can reach. |
| <code style={{ whiteSpace: 'nowrap' }}>baseUrl</code><br />default `'https://api.linear.app/graphql'` | Linear GraphQL endpoint; override to point at a fake or proxy. |
| <code style={{ whiteSpace: 'nowrap' }}>contentSearch</code><br />default `false` | Let `grep -rw` and `rg -w` read only the issues Linear's search names, plus those whose other fields hold the word. Search lags writes. |

Fields marked secret are redacted in snapshots.

## Mount mode

`read`.

For the mounted layout (`teams/`, `projects/`, `issues/`) see the [Python Linear docs](/python/vfs/linear).
