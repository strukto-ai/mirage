`GDocsVFS` exposes Google Docs as `.gdoc.json` files. Reads return the document's structured content.

Setup steps for OAuth credentials live at [Google Workspace Credentials](/home/setup/google).

## Node

```bash
pnpm add @struktoai/mirage-node
```

```ts
import { GDocsVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const docs = new GDocsVFS({
  clientId: process.env.GOOGLE_CLIENT_ID!,
  clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
  refreshToken: process.env.GOOGLE_REFRESH_TOKEN!,
})

const ws = new Workspace({ '/docs': docs }, { mode: MountMode.WRITE })
await ws.shell('cat /docs/owned/MyDoc.gdoc.json')
```

## Browser

```bash
pnpm add @struktoai/mirage-browser
```

```ts
import { GDocsVFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const docs = new GDocsVFS({
  clientId: GOOGLE_CLIENT_ID,
  clientSecret: GOOGLE_CLIENT_SECRET,
  refreshToken: localStorage.getItem('gdocs.refresh_token')!,
})

const ws = new Workspace({ '/docs': docs }, { mode: MountMode.WRITE })
```

A PKCE example lives at `examples/browser/vfs/gdocs/gdocs_pkce.ts`.

## Config

| Field | Default | Notes |
| --- | --- | --- |
| `accessToken` | unset | An access token, or a function that returns one, read on every request. Use it instead of `clientId` and `refreshToken` when your app already manages OAuth. Redacted in snapshots. |
| `clientId` | unset | Google OAuth client ID. Required with `refreshToken` when `accessToken` is unset. |
| `clientSecret` | unset | Google OAuth client secret. Omit it for a PKCE client. Redacted in snapshots. |
| `refreshToken` | unset | User's refresh token. Required with `clientId` when `accessToken` is unset. Redacted in snapshots. |
| `refreshFn` | built-in | Optional override for the access-token refresh callback. |
| `apiBase` | Google's hosts | One host for every Google API and the OAuth token endpoint, such as a test server. |
| `contentSearch` | `false` | Let `grep -w` and `rg -w` read only the files Drive full-text search names. Drive searches a file's text, not its JSON, and indexes a write with a delay, so a file that holds the word can be left out; the [Python docs](/python/vfs/gdocs#grep-and-rg) list the cases. |

## Mount mode

`read`. A `MountMode.WRITE` mount also allows `mv` (retitle) and `rm` (delete). Append text with the [gws CLI](/typescript/cli/gws).

For the JSON shape see the [Python Google Docs docs](/python/vfs/gdocs).
