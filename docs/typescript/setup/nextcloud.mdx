The Nextcloud VFS mounts a [WebDAV](http://www.webdav.org/specs/rfc4918.html)
server (Nextcloud, ownCloud, Hetzner Storage Share, or any generic WebDAV
endpoint) at a prefix such as `/nc/`. Reads are streaming, with HTTP `Range`
requests for partial reads.

For credential and server setup, see [Nextcloud Setup](/home/setup/nextcloud).
For Python, see the [Nextcloud (Python)](/python/vfs/nextcloud) reference.

## Config

```typescript
import { MountMode, NextcloudVFS, normalizeNextcloudConfig, Workspace } from '@struktoai/mirage-node'

const config = normalizeNextcloudConfig({
  url: process.env.NEXTCLOUD_URL!,
  username: process.env.NEXTCLOUD_USERNAME,
  password: process.env.NEXTCLOUD_PASSWORD,
  // Optional:
  // timeout: 30,
})
const vfs = new NextcloudVFS(config)
const ws = new Workspace({ '/nc/': vfs }, { mode: MountMode.WRITE })
```

`NextcloudVFS` accepts a configuration object with the WebDAV URL and optional
Basic Auth credentials. Both `READ` and `WRITE` mount modes are supported.
Use an **app password** (Settings → Security in Nextcloud) rather than your
account password.

WebDAV resources map directly to virtual paths under the mount prefix.
For example, virtual `/nc/Documents/notes.md` issues HTTP WebDAV requests
against `<NEXTCLOUD_URL>/Documents/notes.md`.

## Cache

The Nextcloud VFS caches directory listings in Mirage's index cache. Directory
listings issue a single `PROPFIND Depth: 1` that populates file sizes, types,
and ETags for child entries. Subsequent `stat` operations read from this cache,
so operations like `ls` or directory scans cost one HTTP request instead of N.

## Example

```typescript
import { MountMode, NextcloudVFS, normalizeNextcloudConfig, Workspace } from '@struktoai/mirage-node'

const config = normalizeNextcloudConfig({
  url: process.env.NEXTCLOUD_URL!,
  username: process.env.NEXTCLOUD_USERNAME,
  password: process.env.NEXTCLOUD_PASSWORD,
})
const vfs = new NextcloudVFS(config)
const ws = new Workspace({ '/nc/': vfs }, { mode: MountMode.WRITE })

// List files
const ls = await ws.shell('ls -la /nc/')
console.log(await ls.stdoutStr())

// Read a remote document
const doc = await ws.shell('cat /nc/Documents/notes.md')
console.log(await doc.stdoutStr())

// Search document contents
const search = await ws.shell('grep -i "meeting" /nc/Documents/*.md')
console.log(await search.stdoutStr())
```
