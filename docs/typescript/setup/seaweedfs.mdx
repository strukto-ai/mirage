SeaweedFS speaks the S3 API with AWS Signature V4 against its S3 gateway endpoint (e.g. `http://localhost:8333`). The gateway is self-hosted, so the endpoint is required and path-style addressing is used by default.

Credentials (access key + secret key from the gateway's `-s3.config`) are created the same way in both runtimes, see [SeaweedFS Credentials](/home/setup/seaweedfs).

## Node (server-side)

```bash
pnpm add @struktoai/mirage-node
```

```ts
import { SeaweedFSVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const seaweedfs = new SeaweedFSVFS({
  bucket: process.env.SEAWEEDFS_BUCKET!,
  endpoint: process.env.SEAWEEDFS_ENDPOINT!,
  accessKeyId: process.env.SEAWEEDFS_ACCESS_KEY!,
  secretAccessKey: process.env.SEAWEEDFS_SECRET_KEY!,
})

const ws = new Workspace({ '/bucket/': seaweedfs }, { mode: MountMode.READ })
const res = await ws.shell('ls /bucket/')
console.log(res.stdoutText)
```

### Config

{/* generated: config-table seaweedfs start */}
| Field | Required | Default | Description |
| --- | --- | --- | --- |
| `bucket` | yes |  | Name of the bucket to mount. |
| `accessKeyId` | no |  | Access key ID, used only together with `secretAccessKey`. Unset falls back to the AWS SDK credential chain: `profile`, the environment, the shared credentials file, then an instance role. Redacted in snapshots. |
| `secretAccessKey` | no |  | Secret access key paired with `accessKeyId`. Redacted in snapshots. |
| `sessionToken` | no |  | Session token for temporary credentials, sent with the access key pair. Redacted in snapshots. |
| `profile` | no |  | Named profile in the shared AWS config and credentials files that supplies credentials when no access key pair is given. |
| `forcePathStyle` | no | `true` | Address the bucket in the URL path (`<endpoint>/<bucket>/<key>`) instead of as a subdomain of the endpoint. |
| `keyPrefix` | no |  | Key prefix inside the bucket that the mount treats as its root; keys outside it are not visible. Leading slashes are dropped and a trailing `/` is added. |
| `timeoutMs` | no |  | Milliseconds to wait to connect, and for each read of a response, before the request fails. Unset leaves the AWS SDK's own timeouts. |
| `proxy` | no |  | Proxy URL for every HTTP and HTTPS request to the endpoint. Redacted in snapshots. |
| `region` | no | `'us-east-1'` | Region requests are signed for; the gateway's endpoint does not depend on it. |
| `endpoint` | yes |  | URL of the self-hosted S3 gateway, such as `http://localhost:9000`. |
{/* generated: config-table seaweedfs end */}

## Browser (presigned URLs)

```bash
pnpm add @struktoai/mirage-browser
```

The browser `SeaweedFSVFS` is secret-free, your backend signs each operation using your SeaweedFS keys and returns a URL. SeaweedFS accepts AWS Signature V4, so `@aws-sdk/s3-request-presigner` works, pointed at your gateway endpoint.

### Config

{/* generated: config-table browser/seaweedfs start */}
| Field | Required | Default | Description |
| --- | --- | --- | --- |
| `bucket` | yes |  | Name of the bucket to mount. |
| `presignedUrlProvider` | yes |  | Function `(path, operation, options)` that returns a signed URL for one S3 operation (`GET`, `PUT`, `HEAD`, `DELETE`, `LIST` or `COPY`). Your server signs it with the provider's keys, so the browser holds none. Redacted in snapshots. |
| `region` | no |  | Region of the bucket. Most providers derive the endpoint from it; requests go to the host each presigned URL names. |
| `endpoint` | no |  | Endpoint URL that replaces the one the provider derives. Requests go to the host each presigned URL names; the mount uses it to name its storage location. |
| `defaultContentType` | no | `'application/octet-stream'` | `Content-Type` stored with every object the mount writes. |
| `keyPrefix` | no |  | Key prefix inside the bucket that the mount treats as its root; keys outside it are not visible. Leading slashes are dropped and a trailing `/` is added. The browser can change it before a URL is signed, so enforce the prefix on the signing server. |
{/* generated: config-table browser/seaweedfs end */}

### 1. Server: sign URLs with the SeaweedFS endpoint

```ts
import {
  CopyObjectCommand,
  DeleteObjectCommand,
  GetObjectCommand,
  HeadObjectCommand,
  ListObjectsV2Command,
  PutObjectCommand,
  S3Client,
} from '@aws-sdk/client-s3'
import { getSignedUrl } from '@aws-sdk/s3-request-presigner'

const client = new S3Client({
  region: 'us-east-1',
  endpoint: process.env.SEAWEEDFS_ENDPOINT,
  forcePathStyle: true,
  credentials: {
    accessKeyId: process.env.SEAWEEDFS_ACCESS_KEY!,
    secretAccessKey: process.env.SEAWEEDFS_SECRET_KEY!,
  },
})
const BUCKET = process.env.SEAWEEDFS_BUCKET!

app.post('/presign/seaweedfs', async (req, res) => {
  const { path, op, opts } = req.body
  const key = path.replace(/^\/+/, '')
  const ttl = typeof opts?.ttlSec === 'number' ? opts.ttlSec : 300
  let cmd
  switch (op) {
    case 'GET':    cmd = new GetObjectCommand({ Bucket: BUCKET, Key: key }); break
    case 'PUT':    cmd = new PutObjectCommand({ Bucket: BUCKET, Key: key, ContentType: opts?.contentType }); break
    case 'HEAD':   cmd = new HeadObjectCommand({ Bucket: BUCKET, Key: key }); break
    case 'DELETE': cmd = new DeleteObjectCommand({ Bucket: BUCKET, Key: key }); break
    case 'LIST':   cmd = new ListObjectsV2Command({
      Bucket: BUCKET,
      Prefix: opts?.listPrefix,
      Delimiter: opts?.listDelimiter,
      ContinuationToken: opts?.listContinuationToken,
    }); break
    case 'COPY':   cmd = new CopyObjectCommand({
      Bucket: BUCKET,
      Key: key,
      CopySource: `${BUCKET}/${opts?.copySource}`,
    }); break
  }
  res.json({ url: await getSignedUrl(client, cmd, { expiresIn: ttl }) })
})
```

<Warning>
SeaweedFS uses **path-style** URLs (`forcePathStyle: true`), virtual-hosted style requires extra DNS setup on a self-hosted gateway.
</Warning>

### 2. Browser: wire it up

```ts
import { SeaweedFSVFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const seaweedfs = new SeaweedFSVFS({
  bucket: 'my-bucket',
  endpoint: 'http://localhost:8333',
  presignedUrlProvider: async (path, op, opts) => {
    const r = await fetch('/presign/seaweedfs', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ path, op, opts }),
    })
    const { url } = await r.json()
    return url
  },
})

const ws = new Workspace({ '/bucket/': seaweedfs }, { mode: MountMode.READ })
```

<Tip>
`endpoint` on the browser config is only used for display/logging; the actual endpoint is baked into the presigned URLs your backend returns.
</Tip>

See the [SeaweedFS VFS](/python/vfs/seaweedfs) docs for the equivalent Python wiring.
