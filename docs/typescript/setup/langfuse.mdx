`LangfuseVFS` exposes Langfuse projects and traces as a read-only tree.

Setup steps for the public/secret keys live at [Langfuse Credentials](/home/setup/langfuse).

## Node

```bash
pnpm add @struktoai/mirage-node
```

```ts
import { LangfuseVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const lf = new LangfuseVFS({
  publicKey: process.env.LANGFUSE_PUBLIC_KEY!,
  secretKey: process.env.LANGFUSE_SECRET_KEY!,
  host: process.env.LANGFUSE_HOST,
})

const ws = new Workspace({ '/lf': lf }, { mode: MountMode.READ })
await ws.shell('ls /lf/traces/')
```

| <code style={{ whiteSpace: 'nowrap' }}>publicKey</code><br />required | Langfuse project public key. |

| <code style={{ whiteSpace: 'nowrap' }}>defaultTraceLimit</code><br />default `100` | The most traces one trace listing (`traces/` or a session's traces) shows. An older trace is still readable by its id. |
| <code style={{ whiteSpace: 'nowrap' }}>defaultFromTimestamp</code> | List only traces from this ISO 8601 timestamp on. Unset lists whatever the project holds, up to `defaultTraceLimit`. |
| <code style={{ whiteSpace: 'nowrap' }}>walkLimit</code><br />default `1000` | Most files one command walks under a folder: `grep -r`, `find` and other walks stop there, and a larger glob, `tar -c`, `cp -r` or `rm -r` is refused. `-1` lifts the limit. |

Fields marked secret are redacted in snapshots.
