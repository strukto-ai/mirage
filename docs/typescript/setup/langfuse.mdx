`LangfuseVFS` exposes Langfuse projects and traces as a read-only tree.

Setup steps for the public/secret keys live at [Langfuse Credentials](/home/setup/langfuse).

## Node

```bash
pnpm add @struktoai/mirage-node
```

```ts
import { LangfuseVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const lf = new LangfuseVFS({
  publicKey: process.env.LANGFUSE_PUBLIC_KEY!,
  secretKey: process.env.LANGFUSE_SECRET_KEY!,
  host: process.env.LANGFUSE_HOST,
})

const ws = new Workspace({ '/lf': lf }, { mode: MountMode.READ })
await ws.shell('ls /lf/traces/')
```

## Config

{/* generated: config-table langfuse start */}
| Field | Required | Default | Description |
| --- | --- | --- | --- |
| `publicKey` | yes |  | Langfuse project public key. |
| `secretKey` | yes |  | Langfuse project secret key. Redacted in snapshots. |
| `host` | no | `'https://cloud.langfuse.com'` | Langfuse API host; override for a self-hosted or regional instance. |
| `defaultTraceLimit` | no | `100` | The most traces one trace listing (`traces/` or a session's traces) shows. An older trace is still readable by its id. |
| `defaultFromTimestamp` | no |  | List only traces from this ISO 8601 timestamp on. Unset lists whatever the project holds, up to `defaultTraceLimit`. |
{/* generated: config-table langfuse end */}

## Mount mode

`read`.

For the layout and search behavior see the [Python Langfuse docs](/python/vfs/langfuse).
