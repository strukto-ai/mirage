`S3VFS` mounts one bucket: every object becomes a file and every `/` in a key a
folder. It works with Amazon S3 and any S3-compatible server, such as MinIO,
Ceph or SeaweedFS. Create the bucket and credentials as in [S3 setup](/home/setup/s3).

## Install

```bash
npm install @struktoai/mirage-node
```

## Configure

```ts
import { MountMode, S3VFS, Workspace } from '@struktoai/mirage-node'

const s3 = new S3VFS({
  bucket: process.env.AWS_S3_BUCKET!,
  region: process.env.AWS_DEFAULT_REGION!,
  accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
  secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
})
const ws = new Workspace({ '/s3': s3 }, { mode: MountMode.WRITE })

const result = await ws.shell("ls /s3 && find /s3 -name '*.csv'")
console.log(result.stdoutText)
await ws.close()
```

For MinIO or another S3-compatible server, add `endpoint` and, if the server
needs it, `forcePathStyle: true`. A mount takes `MountMode.READ`, `WRITE` or
`EXEC`.

## Authentication

Credentials come from `accessKeyId` and `secretAccessKey`, with `sessionToken`
for temporary credentials. Without them, the AWS SDK reads its own chain:
environment variables, `~/.aws/credentials`, then the instance or container
role.

The mount needs `s3:ListBucket` on the bucket, `s3:GetObject` to read, and
`s3:PutObject` and `s3:DeleteObject` to write. An object the credentials cannot
read answers `Permission denied`. Without `s3:ListBucket`, a missing file
answers `Permission denied` too, since S3 then hides which keys exist.

## Layout

```text
/s3/
  data/
    config.json
    file.txt
  reports/
    q1.csv
    q2.csv
```

`/s3/data/file.txt` is the key `data/file.txt`. Folders come from the `/` in
keys; S3 stores no folder objects.

## Behavior

- **Key prefix:** `keyPrefix: 'users/42/'` mounts only that part of the bucket,
  so `/s3/notes.md` is the key `users/42/notes.md`.

## Browser

The browser `S3VFS` from `@struktoai/mirage-browser` keeps credentials off the
page: a server signs a URL for each S3 call, and the browser fetches it.

```bash
npm install @struktoai/mirage-browser
```

```ts
import { MountMode, S3VFS, Workspace } from '@struktoai/mirage-browser'

const s3 = new S3VFS({
  bucket: 'my-bucket',
  presignedUrlProvider: async (path, op, opts) => {
    const r = await fetch('/presign', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ path, op, opts }),
    })
    return ((await r.json()) as { url: string }).url
  },
})
const ws = new Workspace({ '/s3': s3 }, { mode: MountMode.READ })
```

- The bucket's CORS rules must allow the page's origin, exactly as served.
- A browser mount cannot declare `write: conditional`, and any HTTP 403 from a
  signed URL, an expired one included, answers `Permission denied`.
- `keyPrefix` set in the browser is no security boundary: enforce the prefix in
  the signing server and its IAM policy.

An Express route that signs URLs:

```ts
import {
  CopyObjectCommand,
  DeleteObjectCommand,
  GetObjectCommand,
  HeadObjectCommand,
  ListObjectsV2Command,
  PutObjectCommand,
  S3Client,
} from '@aws-sdk/client-s3'
import { getSignedUrl } from '@aws-sdk/s3-request-presigner'

const client = new S3Client({ region: process.env.AWS_DEFAULT_REGION })
const BUCKET = process.env.AWS_S3_BUCKET!

app.post('/presign', async (req, res) => {
  const { path, op, opts } = req.body as {
    path: string
    op: 'GET' | 'PUT' | 'HEAD' | 'DELETE' | 'LIST' | 'COPY'
    opts?: Record<string, unknown>
  }
  const key = path.replace(/^\/+/, '')
  const ttl = typeof opts?.ttlSec === 'number' ? opts.ttlSec : 300
  let cmd
  switch (op) {
    case 'GET':    cmd = new GetObjectCommand({ Bucket: BUCKET, Key: key }); break
    case 'PUT':    cmd = new PutObjectCommand({ Bucket: BUCKET, Key: key, ContentType: opts?.contentType as string | undefined }); break
    case 'HEAD':   cmd = new HeadObjectCommand({ Bucket: BUCKET, Key: key }); break
    case 'DELETE': cmd = new DeleteObjectCommand({ Bucket: BUCKET, Key: key }); break
    case 'LIST':   cmd = new ListObjectsV2Command({
      Bucket: BUCKET,
      Prefix: opts?.listPrefix as string | undefined,
      Delimiter: opts?.listDelimiter as string | undefined,
      ContinuationToken: opts?.listContinuationToken as string | undefined,
    }); break
    case 'COPY':   cmd = new CopyObjectCommand({
      Bucket: BUCKET,
      Key: key,
      CopySource: `${BUCKET}/${opts?.copySource as string}`,
    }); break
  }
  const url = await getSignedUrl(client, cmd, { expiresIn: ttl })
  res.json({ url })
})
```

Sign only the operations the app needs: a viewer needs `GET`, `HEAD` and `LIST`.

## Integration

S3 answers these commands through its own API, so fewer objects are read. See
[Integration](/home/integration/overview).

- `md5sum`: the object's ETag, when it is the MD5 (a single-part upload,
  unencrypted or under SSE-S3).
- `find`: one recursive listing.
- `du`: one recursive listing.
- `ls -R` and `tree`: one recursive listing.
