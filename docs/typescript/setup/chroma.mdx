`ChromaVFS` exposes a ChromaDB collection as a read-only filesystem: the
directory tree comes from the collection's `__path_tree__` document, pages are
chunk sets joined in `chunk_index` order, and vector retrieval is the
`chroma-query` command. The TypeScript backend mirrors the
[Python one](/python/vfs/chroma) and returns identical results.

## Node

The `chromadb` client is an optional peer dependency; install it alongside
Mirage:

```bash
pnpm add @struktoai/mirage-node chromadb
```

```ts
import { ChromaVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const knowledge = new ChromaVFS({
  config: {
    host: 'localhost',
    port: 8000,
    collectionName: 'knowledge',
    // slugField: 'page_slug',      (default)
    // chunkIndexField: 'chunk_index', (default)
  },
})

const ws = new Workspace({ '/knowledge': knowledge }, { mode: MountMode.READ })

console.log(await (await ws.shell('tree /knowledge/')).stdoutStr())
console.log(await (await ws.shell('grep -r refund /knowledge/policies/')).stdoutStr())
console.log(
  await (await ws.shell('chroma-query "how am I throttled" /knowledge/')).stdoutStr(),
)
```

`grep` pushes `$contains` / `$regex` filters down to ChromaDB before fine
filtering locally, so recursive searches avoid fetching the whole collection.

## `/<path>` layout

```text
Chroma is mounted as a read-only virtual filesystem backed by a ChromaDB collection.

Use cat, head, tail, ls, find, tree, grep, and chroma-query to inspect indexed documents. Paths are document slugs from the collection path tree. Writes are not supported.
```

## Supported Unix Commands for VFS

Unix commands work on each path as on a local filesystem, as far as the path supports them:

| Path | Supported |
| --- | --- |
| `/<path>` | Commands that read files (`ls`, `cat`, `grep`, `find`, `jq` and the rest). `grep -r` and `rg` use `chroma` search. Also `chroma-query`. |

## Limitations of Unix Commands for VFS

Where a path differs from a local filesystem:

| Path | Limitations |
| --- | --- |
| `/<path>` | No command changes files. `grep -r`, `find` and `du` stop after 1000 files; a glob matching more, `tar -c`, `cp -r` and `rm -r` are refused. |

Run `man` to list every command, and `man <cmd>` or `<cmd> --help` for one command's usage.
