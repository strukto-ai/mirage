---
title: OneDrive
icon: microsoft
description: Mount OneDrive through Microsoft Graph from Node or the browser.
---

`OneDriveResource` exposes one Microsoft Graph drive as a read-write filesystem. It uses the same browser-safe core in the Node and browser packages.

```ts
import { MountMode, OneDriveResource, Workspace } from '@struktoai/mirage-node'

const drive = new OneDriveResource({
  accessToken: () => getMicrosoftGraphToken(),
  // Name at most one drive; none means /me/drive.
  // driveId: '...',       // explicit Graph drive ID
  // siteId: '...',        // a SharePoint site's default drive
  // groupId: '...',       // a Teams / Microsoft 365 group's library
  // userId: '...',        // another user's drive (app-only auth)
  // cloud: 'usgovhigh',   // national cloud; default 'global'
  // keyPrefix: 'Reports', // optional folder-scoped mount
})

const ws = new Workspace({ '/onedrive': drive }, { mode: MountMode.WRITE })
await ws.execute('ls /onedrive/')
```

Use `@struktoai/mirage-browser` for the same API in a browser. An access-token callback is recommended so a `401` can refresh the token and retry once.

| Field | Default | Notes |
| --- | --- | --- |
| `accessToken` | required | Token string or sync/async callback returning a token. Redacted in snapshots. |
| `driveId` | unset | Explicit Graph drive ID. |
| `siteId` | unset | Use the default drive for a Graph site. |
| `groupId` | unset | Use a Teams / Microsoft 365 group's document library. |
| `userId` | unset | Use another user's drive, by id or UPN (app-only auth). |
| `cloud` | `global` | National cloud: `global`, `usgovhigh`, `usgovdod`, `china`. |
| `graphBaseUrl` | unset | Full service root, overriding `cloud`. |
| `keyPrefix` | unset | Mount a folder subtree as the resource root. |
| `tenantHost` | unset | Tenant metadata retained for Graph-compatible configuration. |
| `timeout` | `30` | Request and copy-monitor timeout in seconds. |
| `maxRetries` | `5` | Retries for `429`, `503`, and `504`. |

`driveId`, `siteId`, `groupId` and `userId` are four ways of saying which drive
the mount is, so set at most one: setting two throws at construction rather
than silently addressing whichever came first. Setting none means `/me/drive`,
which is the only form an app-only token cannot use.

Each national cloud is network-isolated with its own service root, and a token
minted for one is rejected by the others, so `cloud` is a correctness setting,
not a performance one. Microsoft 365 GCC (moderate) is served by the worldwide
endpoint and therefore uses `global`; only GCC High and DoD have their own
hosts. `graphBaseUrl` is the escape hatch for a root the list cannot name (a
private endpoint, or a test server), given in full including the version
segment.

Reads, writes, resumable uploads, recursive copy, move, delete, directory creation, and version-pinned snapshot reads mirror the [Python OneDrive resource](/python/resource/onedrive).
