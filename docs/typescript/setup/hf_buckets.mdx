`HfBucketsVFS` mounts one
[Hugging Face Storage Bucket](https://huggingface.co/docs/hub/storage-buckets):
every file in it becomes a file and every `/` in its path a folder. The bucket
and token are set up on the [HF Buckets page](/home/setup/hf_buckets).

## Install

```bash
npm install @struktoai/mirage-node opendal
```

`opendal` is a native binding, so the mount runs in Node only, not in the
browser.

## Configure

```ts
import { HfBucketsVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const hf = new HfBucketsVFS({
  bucket: process.env.HF_BUCKET_NAME!,
  token: process.env.HF_TOKEN!,
})
const ws = new Workspace({ '/hf': hf }, { mode: MountMode.WRITE })

const result = await ws.shell("ls /hf && find /hf -name '*.json'")
console.log(result.stdoutText)
await ws.close()
```

`bucket` is the bucket's id, `<owner>/<name>`. `endpoint` points the mount at
a mirror or a self-hosted Hub. A mount takes `MountMode.READ`, `WRITE` or
`EXEC`.

## Authentication

`token` is a Hugging Face access token: **Read** for a read mount, **Write** to
upload. A fine-grained token needs read access, or write access to upload, on
the bucket's namespace. A bucket the token cannot reach, or one that does not
exist, answers `Permission denied`.

## Layout

```text
/hf/
  checkpoints/
    step-1000/
      config.json
    step-2000/
      config.json
  logs/
    train.log
```

`/hf/logs/train.log` is the file `logs/train.log` in the bucket. Folders come
from the `/` in file paths.

## Behavior

- **Key prefix:** `keyPrefix: 'users/42/'` mounts only that part of the bucket, so
  `/hf/notes.md` is the file `users/42/notes.md`. A leading `/` is dropped and
  a trailing `/` added.
- **Folders:** a folder exists only while it holds a file, so `mkdir` creates
  nothing.
- **No move:** `mv` and `rmdir` are not supported.
- **No history:** a bucket keeps no history, so a removed file is gone for
  good.

## Integration

HF Buckets answers these commands through its own API, so fewer files are read.
See [Integration](/home/integration/overview).

- `find`: one recursive listing.
- `du`: one recursive listing.
- `ls -R` and `tree`: one recursive listing.
