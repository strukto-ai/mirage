The Dify VFS exposes completed Dify Knowledge documents as text files
mounted at a prefix such as `/knowledge/`. Each file is assembled from the
document's completed, enabled segments.

For API key setup and dataset creation, see [Dify Setup](/home/setup/dify).
For Python, see the [Dify (Python)](/python/vfs/dify) documentation.

## Config

```typescript
import { MountMode, Workspace } from '@struktoai/mirage-node'
import { DifyVFS } from '@struktoai/mirage-core'

const vfs = new DifyVFS({
  apiKey: process.env.DIFY_API_KEY!,
  baseUrl: process.env.DIFY_BASE_URL ?? 'https://api.dify.ai/v1',
  datasetId: process.env.DIFY_DATASET_ID!,
  slugMetadataName: process.env.DIFY_SLUG_METADATA_NAME ?? 'slug',
})
const ws = new Workspace({ '/knowledge/': vfs }, { mode: MountMode.READ })
```

The VFS is read-only. Snapshots redact credentials, so `Workspace.load` needs
a live `DifyVFS` in its third argument for `/knowledge/` (e.g.
`Workspace.load(snapshot, {}, { '/knowledge/': freshDifyVfs })`).
Restored cache entries are served as saved and un-cached reads reach the live backend.

## Document metadata and paths

Mirage mounts documents using a slug metadata field when present (defaulting to
`slug`), falling back to the document name. Adding a `slug` metadata field to
your Dify Knowledge dataset allows you to organize virtual paths into a clean
nested directory structure:

| Dify document | `slug` metadata value | Virtual path |
| --- | --- | --- |
| Quickstart Guide | `guides/quickstart.md` | `/knowledge/guides/quickstart.md` |
| API Overview | `api/overview.md` | `/knowledge/api/overview.md` |

## Example

```typescript
import { MountMode, Workspace } from '@struktoai/mirage-node'
import { DifyVFS } from '@struktoai/mirage-core'

const vfs = new DifyVFS({
  apiKey: process.env.DIFY_API_KEY!,
  baseUrl: process.env.DIFY_BASE_URL ?? 'https://api.dify.ai/v1',
  datasetId: process.env.DIFY_DATASET_ID!,
})
const ws = new Workspace({ '/knowledge/': vfs }, { mode: MountMode.READ })

// List available knowledge documents
const ls = await ws.shell('ls -la /knowledge/')
console.log(await ls.stdoutStr())

// Read document contents
const content = await ws.shell('cat /knowledge/guides/quickstart.md')
console.log(await content.stdoutStr())

// Search for keywords
const grep = await ws.shell('shopt -s globstar; grep -i "authentication" /knowledge/**/*.md')
console.log(await grep.stdoutStr())
```
