DigitalOcean Spaces uses the S3 API with AWS Signature V4 against `https://<region>.digitaloceanspaces.com`. MIRAGE derives this endpoint from your region automatically.

Credentials (Spaces access key pair) are created the same way in both runtimes, see [DigitalOcean Credentials](/home/setup/digitalocean).

## Node (server-side)

```bash
pnpm add @struktoai/mirage-node
```

```ts
import { DigitalOceanVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const spaces = new DigitalOceanVFS({
  bucket: process.env.DO_SPACE!,
  region: process.env.DO_REGION!,
  accessKeyId: process.env.DO_ACCESS_KEY_ID!,
  secretAccessKey: process.env.DO_SECRET_ACCESS_KEY!,
})

const ws = new Workspace({ '/bucket/': spaces }, { mode: MountMode.READ })
const res = await ws.shell('ls /bucket/')
console.log(res.stdoutText)
```

## Browser (presigned URLs)

```bash
pnpm add @struktoai/mirage-browser
```

The browser `DigitalOceanVFS` is secret-free, your backend signs each operation using your Spaces keys and returns a URL. Spaces accepts AWS Signature V4, so `@aws-sdk/s3-request-presigner` works, pointed at the Spaces endpoint.

### Config

{/* generated: config-table browser/digitalocean start */}
| Field | Description |
| --- | --- |
| <code style={{ whiteSpace: 'nowrap' }}>bucket</code><br />required | Name of the bucket to mount. |
| <code style={{ whiteSpace: 'nowrap' }}>presignedUrlProvider</code><br />required, secret | Function `(path, operation, options)` that returns a signed URL for each S3 operation; your server signs it, so the browser holds no keys. |
| <code style={{ whiteSpace: 'nowrap' }}>region</code> | Region of the bucket. Most providers derive the endpoint from it; requests go to the host each presigned URL names. |
| <code style={{ whiteSpace: 'nowrap' }}>endpoint</code> | Endpoint URL that replaces the one the provider derives. Requests go to the host each presigned URL names; the mount uses it to name its storage location. |
| <code style={{ whiteSpace: 'nowrap' }}>defaultContentType</code><br />default `'application/octet-stream'` | `Content-Type` stored with every object the mount writes. |
| <code style={{ whiteSpace: 'nowrap' }}>keyPrefix</code> | Key prefix the mount treats as its root. The browser can change it before a URL is signed, so enforce the prefix on the signing server. |
| <code style={{ whiteSpace: 'nowrap' }}>fullScanLimit</code><br />default `1000` | Most files one command walks under a folder: `grep -r`, `find` and other walks stop there, and a larger glob, `tar -c`, `cp -r` or `rm -r` is refused. `-1` lifts the limit. |

Fields marked secret are redacted in snapshots.

### 1. Server: sign URLs with the Spaces endpoint

```ts
import {
  CopyObjectCommand,
  DeleteObjectCommand,
  GetObjectCommand,
  HeadObjectCommand,
  ListObjectsV2Command,
  PutObjectCommand,
  S3Client,
} from '@aws-sdk/client-s3'
import { getSignedUrl } from '@aws-sdk/s3-request-presigner'

const REGION = process.env.DO_REGION!

const client = new S3Client({
  region: REGION,
  endpoint: `https://${REGION}.digitaloceanspaces.com`,
  credentials: {
    accessKeyId: process.env.DO_ACCESS_KEY_ID!,
    secretAccessKey: process.env.DO_SECRET_ACCESS_KEY!,
  },
})
const BUCKET = process.env.DO_SPACE!

app.post('/presign/spaces', async (req, res) => {
  const { path, op, opts } = req.body
  const key = path.replace(/^\/+/, '')
  const ttl = typeof opts?.ttlSec === 'number' ? opts.ttlSec : 300
  let cmd
  switch (op) {
    case 'GET':    cmd = new GetObjectCommand({ Bucket: BUCKET, Key: key }); break
    case 'PUT':    cmd = new PutObjectCommand({ Bucket: BUCKET, Key: key, ContentType: opts?.contentType }); break
    case 'HEAD':   cmd = new HeadObjectCommand({ Bucket: BUCKET, Key: key }); break
    case 'DELETE': cmd = new DeleteObjectCommand({ Bucket: BUCKET, Key: key }); break
    case 'LIST':   cmd = new ListObjectsV2Command({
      Bucket: BUCKET,
      Prefix: opts?.listPrefix,
      Delimiter: opts?.listDelimiter,
      ContinuationToken: opts?.listContinuationToken,
    }); break
    case 'COPY':   cmd = new CopyObjectCommand({
      Bucket: BUCKET,
      Key: key,
      CopySource: `${BUCKET}/${opts?.copySource}`,
    }); break
  }
  res.json({ url: await getSignedUrl(client, cmd, { expiresIn: ttl }) })
})
```

### 2. Browser: wire it up

```ts
import { DigitalOceanVFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const spaces = new DigitalOceanVFS({
  bucket: 'my-space',
  region: 'nyc3',
  presignedUrlProvider: async (path, op, opts) => {
    const r = await fetch('/presign/spaces', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ path, op, opts }),
    })
    const { url } = await r.json()
    return url
  },
})

const ws = new Workspace({ '/bucket/': spaces }, { mode: MountMode.READ })
```

<Tip>
`region` on the browser config is only used for display/logging; the actual endpoint is baked into the presigned URLs your backend returns.
</Tip>

### 3. CORS

Spaces supports the S3 `PutBucketCors` call, so the AWS CLI works against the Spaces endpoint (you can also use the DigitalOcean control panel, Space -> Settings -> CORS Configurations):

```bash
aws s3api put-bucket-cors --bucket "$DO_SPACE" \
  --endpoint-url "https://$DO_REGION.digitaloceanspaces.com" \
  --cors-configuration '{"CORSRules":[{"AllowedOrigins":["http://localhost:5173","https://app.example.com"],"AllowedMethods":["GET","PUT","HEAD","DELETE","POST"],"AllowedHeaders":["*"],"ExposeHeaders":["ETag","Content-Length","Content-Type","Last-Modified"]}]}'
```

See the [DigitalOcean VFS](/python/vfs/digitalocean) docs for the equivalent Python wiring.

## Integration

What DigitalOcean Spaces answers through its own API, so fewer files are read, and the most files one command reads. [Integration](/home/integration/overview) explains each command.

| Command | On DigitalOcean Spaces |
| --- | --- |
| Full scan | `grep -r`, `find`, `du` and other walks stop after [`fullScanLimit`](/home/integration/search#full_scan_limit) files (default 1000); a glob matching more, `tar -c`, `cp -r` and `rm -r` are refused. `-1` for no limit |
| `md5sum` | The object's ETag, when it is the MD5: a single-part upload, unencrypted or under SSE-S3 |
| `find`, `du`, `ls -R`, `tree` | One recursive listing |
