`TrelloVFS` exposes a Trello workspace as a tree of boards, lists, and cards.

Setup steps for the API key/token live at [Trello Credentials](/home/setup/trello).

## Node

```bash
pnpm add @struktoai/mirage-node
```

```ts
import { MountMode, TrelloVFS, Workspace } from '@struktoai/mirage-node'

const trello = new TrelloVFS({
  apiKey: process.env.TRELLO_API_KEY!,
  apiToken: process.env.TRELLO_API_TOKEN!,
})

const ws = new Workspace({ '/trello': trello }, { mode: MountMode.READ })
await ws.shell('ls /trello/')
```

## Browser

## Config

{/* generated: config-table trello start */}
| Field | Description |
| --- | --- |
| <code style={{ whiteSpace: 'nowrap' }}>apiKey</code><br />required, secret | Trello API key. |
| <code style={{ whiteSpace: 'nowrap' }}>apiToken</code><br />required, secret | Trello API token. |
| <code style={{ whiteSpace: 'nowrap' }}>workspaceId</code> | Only this workspace and its boards are listed or readable. Unset shows every workspace of the token's member. |
| <code style={{ whiteSpace: 'nowrap' }}>boardIds</code> | Only these boards are listed or readable. Unset shows every open board of the shown workspaces. |
| <code style={{ whiteSpace: 'nowrap' }}>baseUrl</code><br />default `'https://api.trello.com/1'` | Trello API root; override to point at a fake or proxy. |
| <code style={{ whiteSpace: 'nowrap' }}>walkLimit</code><br />default `1000` | Most files one command walks under a folder: `grep -r`, `find` and other walks stop there, and a larger glob, `tar -c`, `cp -r` or `rm -r` is refused. `-1` lifts the limit and reads every file without asking Trello's search, which lags writes. |

Fields marked secret are redacted in snapshots.

## Mount mode

`read`.

For board/list/card layout see the [Python Trello docs](/python/vfs/trello).
Reads and writes by ID go through the [trello CLI](/typescript/cli/trello),
which takes `workspaceId` and `boardIds` in its own config.

## Integration

What Trello answers through its own API, so fewer files are read. [Integration](/home/integration/overview) explains each command.

| Command | On Trello |
| --- | --- |
| `grep -r`, `rg` | Trello search and the text the listing keeps, for whole words. It can miss recent writes. |

The [Python Trello docs](/python/vfs/trello#integration) list when each search answers and what it can miss.
