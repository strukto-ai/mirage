description: Mount SharePoint sites and document libraries through Microsoft Graph from Node or the browser.

`SharePointVFS` shares its file-operation backend with OneDrive. Its additional resolver maps SharePoint sites and document libraries onto the virtual tree.

```ts
import { MountMode, SharePointVFS, Workspace } from '@struktoai/mirage-node'

const sharepoint = new SharePointVFS({
  accessToken: () => getMicrosoftGraphToken(),
  tenantHost: 'contoso.sharepoint.com',
})

const ws = new Workspace({ '/sharepoint': sharepoint }, { mode: MountMode.WRITE })
await ws.shell('ls /sharepoint/')
await ws.shell('ls /sharepoint/Engineering/Documents/')
```

An unscoped mount uses `/site/library/path`. To hide the site and library levels, configure `site` and `drive` together; `keyPrefix` can narrow that drive further.

```ts
new SharePointVFS({
  accessToken,
  site: 'Engineering',
  drive: 'Documents',
  keyPrefix: 'Reports/2026',
})
```

| Field | Default | Notes |
| --- | --- | --- |
| `accessToken` | required | Token string or sync/async callback. Redacted in snapshots. |
| `tenantHost` | unset | Keep only sites whose `webUrl` belongs to this host. |
| `siteFilter` | `*` | Microsoft Graph site search expression. |
| `site`, `drive` | unset | Configure both to scope the mount to one library. |
| `keyPrefix` | unset | Folder subtree inside the scoped library. |
| `contentSearch` | `false` | Let `grep -w` and `rg -w` read only the files Graph search names; see [grep and rg](#grep-and-rg). |
| `timeout` | `30` | Request and copy-monitor timeout in seconds. |
| `maxRetries` | `5` | Retries for `429`, `503`, and `504`. |

## grep and rg

With `contentSearch: true`, `grep -rw` and `rg -w` read only the files Microsoft Graph search names, instead of every file under the directory. A directory above one document library is always read in full. It is off by default: Graph searches the text it extracted rather than the bytes `grep` reads, and indexes a write some time after it lands, so a file that holds the word can be left out. The [Python SharePoint docs](/python/vfs/sharepoint#grep-and-rg) list the cases.

Node and browser expose the same API. Filesystem behavior and snapshot version pinning mirror the [Python SharePoint VFS](/python/vfs/sharepoint).
