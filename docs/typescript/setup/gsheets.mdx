`GSheetsVFS` exposes Google Sheets as `.gsheet.json` files. Reads return cell values.

Setup steps for OAuth credentials live at [Google Workspace Credentials](/home/setup/google).

## Node

```bash
pnpm add @struktoai/mirage-node
```

```ts
import { GSheetsVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const sheets = new GSheetsVFS({
  clientId: process.env.GOOGLE_CLIENT_ID!,
  clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
  refreshToken: process.env.GOOGLE_REFRESH_TOKEN!,
})

const ws = new Workspace({ '/sheets': sheets }, { mode: MountMode.READ })
await ws.shell('ls /sheets/owned/')
```

## Browser

```bash
pnpm add @struktoai/mirage-browser
```

```ts
import { GSheetsVFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const sheets = new GSheetsVFS({
  clientId: GOOGLE_CLIENT_ID,
  clientSecret: GOOGLE_CLIENT_SECRET,
  refreshToken: localStorage.getItem('gsheets.refresh_token')!,
})
```

| <code style={{ whiteSpace: 'nowrap' }}>clientSecret</code><br />secret | Google OAuth client secret, sent with the refresh-token grant. Omit it for a PKCE client. |
| <code style={{ whiteSpace: 'nowrap' }}>refreshToken</code><br />secret | User's OAuth refresh token. Required with `clientId` when `accessToken` is unset. |
| <code style={{ whiteSpace: 'nowrap' }}>refreshFn</code><br />secret | Function that exchanges the refresh token for `{ accessToken, expiresIn }` instead of Google's token endpoint, so the client secret can stay on a backend. Still needs `clientId` and `refreshToken`. |
| <code style={{ whiteSpace: 'nowrap' }}>apiBase</code> | One base URL that replaces every Google API host and the OAuth token endpoint, such as a test server. Unset uses Google's hosts. |
| <code style={{ whiteSpace: 'nowrap' }}>walkLimit</code><br />default `1000` | Most files one command walks under a folder: `grep -r`, `find` and other walks stop there, and a larger glob, `tar -c`, `cp -r` or `rm -r` is refused. `-1` lifts the limit and reads every file without asking Drive full-text search, which searches a file's text, not the JSON the mount renders. |

## Mount mode

`read`. A `MountMode.WRITE` mount also allows `mv` (retitle) and `rm` (delete). Write cells with the [gws CLI](/typescript/cli/gws).

For the layout and sheet/tab structure see the [Python Sheets docs](/python/vfs/gsheets).

    #### `/<path>` layout

    ```text
    /<path>
      owned/
        <date>_<title>__<spreadsheet-id>.gsheet.json
      shared/
        <date>_<title>__<spreadsheet-id>.gsheet.json

      Filename: <YYYY-MM-DD>_<title>__<spreadsheet-id>.gsheet.json
        <YYYY-MM-DD>      modifiedTime, used for date-glob (e.g. 2026-05-*)
        <title>           sanitized: spaces->_, non-[A-Za-z0-9_.-]->_, <=100 chars
        <spreadsheet-id>  Google Sheets spreadsheet ID

      Buckets:
        owned/   sheets you created
        shared/  sheets shared with you by others
                 - does NOT include sheets you own and shared with others;
                   those are still in owned/.

      gsheet.json structure (matches the Google Sheets API spreadsheets.get response):
        {
          "spreadsheetId": "...",
          "spreadsheetUrl": "...",
          "properties": { "title": "...", "locale": "...", "timeZone": "..." },
          "sheets": [
            {                                      # one element per tab
              "properties": {
                "sheetId": 0, "title": "...", "index": 0,
                "gridProperties": { "rowCount": 1000, "columnCount": 26 }
              },
              "data": [
                {
                  "rowData": [
                    { "values": [
                        { "formattedValue": "...",
                          "userEnteredValue": {...},
                          "effectiveValue": {...} }
                    ]}    # an empty cell is {}, a trailing one absent
                  ]
                }
              ]
            }
          ],
          "namedRanges": [...]
        }

      Useful jq paths:
        .properties.title
        .sheets[].properties.title                              # tab names
        .sheets[0].data[0].rowData[].values[].formattedValue    # cell strings
        .namedRanges[]

      Delete, on a `write` path:
        rm /<path>/owned/<file>.gsheet.json     # permanent delete from Drive
        rm -f <path>                             # ignore if missing
        Only operates on .gsheet.json files; owned/ and shared/ themselves
        cannot be removed.

      Rename to a new title, on a `write` path:
        mv /<path>/owned/<date>_<old>__<id>.gsheet.json \
           /<path>/owned/<date>_<new>__<id>.gsheet.json
        Keep the folder, the date and the id, and spell the title the way
        the listing does (spaces->_); any other name is refused.
    ```

    #### Supported Unix Commands for VFS

    Unix commands work on each path as on a local filesystem, as far as the path supports them:

    | Path | Supported |
    | --- | --- |
    | `/<path>` | Commands that read files (`ls`, `cat`, `grep`, `find`, `jq` and the rest), and `mv`, `rm` and `unlink`. `grep -r` and `rg` with `-w` use `gsheets` search. |

    #### Limitations of Unix Commands for VFS

    Where a path differs from a local filesystem:

    | Path | Limitations |
    | --- | --- |
    | `/<path>` | Not supported: `>`, `>>`, `tee`, `tee -a`, `touch` of a new file, `cp`, `cp -r`, `mkdir`, `rm -r`, `rmdir`, `truncate`, `sed -i`. Without `-w`, `grep -r` and `rg` read every file. `grep -r`, `find` and `du` stop after 1000 files; a glob matching more, `tar -c`, `cp -r` and `rm -r` are refused. |

    Run `man` to list every command, and `man <cmd>` or `<cmd> --help` for one command's usage.

## Integration

What Google Sheets answers through its own API, so fewer files are read. [Integration](/home/integration/overview) explains each command.

| Command | On Google Sheets |
| --- | --- |
| `grep -r`, `rg` | Drive full-text search, for whole words. It can miss words only in non-text values (formulas, the time zone, sheet titles, links and ids). |

The [Python Google Sheets docs](/python/vfs/gsheets#integration) list when each search answers and what it can miss.
