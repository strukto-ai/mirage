`GSheetsVFS` mounts the Google Sheets an account can see: each spreadsheet
becomes a `.gsheet.json` file holding the Sheets API's JSON, split into the
spreadsheets it owns and those shared with it. Credentials are set up on the
[Google Workspace page](/home/setup/google).

## Install

```bash
npm install @struktoai/mirage-node
```

## Configure

```ts
import { GSheetsVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const sheets = new GSheetsVFS({
  clientId: process.env.GOOGLE_CLIENT_ID!,
  clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
  refreshToken: process.env.GOOGLE_REFRESH_TOKEN!,
})
const ws = new Workspace({ '/gsheets': sheets }, { mode: MountMode.READ })

const result = await ws.shell("ls /gsheets/owned && jq -r '.properties.title' /gsheets/owned/2026-*.gsheet.json")
console.log(result.stdoutText)
await ws.close()
```

`accessToken` replaces the client and refresh token with a token or a
function that returns one. A `MountMode.WRITE` mount also allows `mv` and `rm`.

## Authentication

Credentials come from the first of:

1. `accessToken`, a token or a function, sync or async, that returns one.
2. `clientId` and `refreshToken`, with `clientSecret` unless the client uses
   PKCE. Mirage trades the refresh token for access tokens on its own, or
   hands it to `refreshFn` when set, so the secret can stay on a backend.

The mount needs the Google Sheets API with the
`https://www.googleapis.com/auth/spreadsheets` scope, and the Drive API with the
`https://www.googleapis.com/auth/drive` scope, since the listing comes from
Drive. A read-only mount can use the `readonly` variants of both scopes.

## Layout

```text
/gsheets/
  owned/
    2026-11-14_Roadmap__1Xk9rT2bQ.gsheet.json
  shared/
    2026-10-02_Budget__1Pq7sV4mN.gsheet.json
```

- `owned/` holds the spreadsheets the account owns, shared or not; `shared/`
  holds those others shared with it.
- A file is named `<YYYY-MM-DD>_<title>__<spreadsheet-id>.gsheet.json`. The date
  is the last modified day and is left out when Drive gives none.
- A file holds the Sheets API's JSON for the spreadsheet: its properties and
  every sheet with its cell values.

## Behavior

- **Shared Drives:** a spreadsheet in a Shared Drive has no owner, so it is
  listed under `shared/`, as on the `gdrive` mount.
- **Date globs:** a glob on the date prefix, such as `2026-05-*`, asks Drive
  only for the spreadsheets modified on those days.
- **Incomplete listings:** Drive may skip part of the account's files and say
  so. The short listing is still shown, and the next `ls` lists again.
- **Rename:** on a `write` mount, `mv` to a new name in the same folder
  changes the title. The date and the id must stay, and the title is spelled
  as the listing spells it (spaces become `_`).
- **Delete:** on a `write` mount, `rm` deletes the spreadsheet for good, not to
  the trash. `owned/` and `shared/` cannot be removed.
- **Edits:** reading, writing and appending cell ranges, and raw API calls,
  go through the [`gws`](/typescript/cli/gws) CLI.

## Browser

The same `GSheetsVFS` comes from `@struktoai/mirage-browser`. In a page, an
`accessToken` function fetches a fresh token from a backend, so the client
secret never reaches the browser.

```bash
npm install @struktoai/mirage-browser
```

```ts
import { GSheetsVFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const sheets = new GSheetsVFS({
  accessToken: async () => (await fetch('/api/google-token')).text(),
})
const ws = new Workspace({ '/gsheets': sheets }, { mode: MountMode.READ })
```

- `/api/google-token` stands for a backend endpoint that returns an access
  token.
- A PKCE OAuth client needs no secret: `clientId` and `refreshToken` alone
  mount it.
- `refreshFn` sends each refresh to a backend instead of Google's token
  endpoint.

## Integration

Google Sheets answers these commands through its own API, so fewer files are
read. See [Integration](/home/integration/overview).

- `grep -r` and `rg` with `-w`: Drive full-text search names the
  spreadsheets to read. Every one is read when the search fails or finds
  nothing, and when the word may be in any spreadsheet's JSON whatever the
  text says: a word with a digit, a Sheets API name or value
  (`formattedValue`, `NUMBER`), or a word every spreadsheet carries (`https`,
  `arial`). Drive indexes a write some time after it lands and searches the
  spreadsheet's text, so it can leave out one whose JSON holds the word only
  in another value (a formula, the time zone, a sheet title, a link, an
  id). `walkLimit: -1` in the mount's
  `"@all"` [command limit](/home/limits#command-output) turns the search off and
  reads every file.
