`EmailVFS` reads messages over IMAP, exposing the mailbox as a tree of folders and messages; the [himalaya CLI](/typescript/cli/himalaya) sends through SMTP.

<Note>
  Node only. Requires `imapflow`, `mailparser`, and `nodemailer` peers. The browser cannot speak raw TCP for IMAP/SMTP.
</Note>

## Install

```bash
pnpm add @struktoai/mirage-node imapflow mailparser nodemailer
```

## Config

```ts
import { EmailVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const email = new EmailVFS({
  imapHost: 'imap.example.com',
  smtpHost: 'smtp.example.com',
  username: process.env.EMAIL_USERNAME!,
  password: process.env.EMAIL_PASSWORD!,
})

const ws = new Workspace({ '/mail': email }, { mode: MountMode.READ })
await ws.shell('ls /mail/INBOX/')
```

| Field | Default | Notes |
| --- | --- | --- |
| `imapHost` | required | IMAP server hostname. |
| `imapPort` | `993` | |
| `smtpHost` | required | SMTP server hostname. |
| `smtpPort` | `587` | |
| `username` | required | Mailbox login. |
| `password` | required | App password. Redacted in snapshots. |
| `useSsl` | `true` | Implicit TLS for IMAP. SMTP uses implicit TLS on port 465 and STARTTLS on any other port. |
| `maxMessages` | `200` | Hard ceiling per folder listing. |
| `contentSearch` | `false` | Narrow `grep -r` and `rg` with IMAP search ([below](#grep-and-rg)). |

## grep and rg

With `contentSearch: true` (YAML `content_search: true`), `grep -r` and `rg` read only the
messages IMAP `SEARCH TEXT` names in each folder or day they walk (from the
mount root, in every folder), and print what reading every message would. IMAP matches the headers and body in any
case; each hit's file is named from a header-only fetch. Attachments are always
read.

Every message is read when the text is a key of the message JSON or a flag
name, holds anything but ASCII letters and spaces, matches more than
`maxMessages` messages in a folder, or the search fails. It is
off by default: a server that answers `SEARCH` from a full-text index (Dovecot
with an FTS plugin, for one) matches words rather than substrings, so a
narrowed scan could miss a message there.

## Mount mode

`read`. Send mail through the [himalaya CLI](/typescript/cli/himalaya).

For mailbox layout, search behavior, and synthesized date directories see the [Python Email docs](/python/vfs/email).
