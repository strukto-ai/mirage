`Mem0VFS` is a browser-safe, read-only view of one Mem0 user, agent, or run scope. Every memory is rendered as `<memory-id>.json`; `search` performs semantic search in that same scope.

<Warning>
  Mem0 API keys are secrets. Use this VFS from Node or another trusted runtime; do not embed a Platform API key in a public browser bundle. Browser applications should call a server-side proxy instead.
</Warning>

```ts
import { Mem0VFS, MountMode, Workspace } from '@struktoai/mirage-node'

const memories = new Mem0VFS({
  apiKey: process.env.MEM0_API_KEY!,
  userId: 'alex',
})

const ws = new Workspace({ '/memories': memories }, { mode: MountMode.READ })
await ws.shell('ls /memories/')
await ws.shell('search --top-k 5 "quarterly planning" /memories/')
```

Exactly one of `userId`, `agentId`, or `runId` is required.

| <code style={{ whiteSpace: 'nowrap' }}>userId</code> | Mount this user's memories. Set exactly one of `userId`, `agentId` and `runId`. |
| <code style={{ whiteSpace: 'nowrap' }}>agentId</code> | Mount this agent's memories. Set exactly one of `userId`, `agentId` and `runId`. |
| <code style={{ whiteSpace: 'nowrap' }}>runId</code> | Mount this run's memories. Set exactly one of `userId`, `agentId` and `runId`. |
| <code style={{ whiteSpace: 'nowrap' }}>defaultPageSize</code><br />default `100` | Memories fetched per request while listing the scope. |
| <code style={{ whiteSpace: 'nowrap' }}>defaultSearchLimit</code><br />default `10` | How many results `search` returns unless the line sets `top_k`. |
| <code style={{ whiteSpace: 'nowrap' }}>walkLimit</code><br />default `1000` | Most files one command walks under a folder: `grep -r`, `find` and other walks stop there, and a larger glob, `tar -c`, `cp -r` or `rm -r` is refused. `-1` lifts the limit. |

Fields marked secret are redacted in snapshots.

The TypeScript VFS mirrors the [Python Mem0 VFS](/python/vfs/mem0), including pagination, JSON rendering, score formatting, path-limited search, and `--threshold`.

    Unix commands work on each path as on a local filesystem, as far as the path supports them:

    | Path | Supported |
    | --- | --- |
    | `/<path>` | Commands that read files (`ls`, `cat`, `grep`, `find`, `jq` and the rest). Also `search`. |

    #### Limitations of Unix Commands for VFS

    Where a path differs from a local filesystem:

    | Path | Limitations |
    | --- | --- |
    | `/<path>` | Read only: no command changes files. `grep -r`, `find` and `du` stop after 1000 files; a glob matching more, `tar -c`, `cp -r` and `rm -r` are refused. |
