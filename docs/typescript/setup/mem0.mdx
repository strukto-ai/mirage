`Mem0VFS` mounts the memories of one Mem0 scope, a user, an agent or a run,
read-only. Each memory is one `<memory-id>.json` file. The API key and the
scope are set up on the [Mem0 page](/home/setup/mem0).

## Install

```bash
npm install @struktoai/mirage-node
```

## Configure

```ts
import { Mem0VFS, MountMode, Workspace } from '@struktoai/mirage-node'

const memory = new Mem0VFS({
  apiKey: process.env.MEM0_API_KEY!,
  userId: process.env.MEM0_USER_ID!,
})
const ws = new Workspace({ '/memory': memory }, { mode: MountMode.READ })

const result = await ws.shell('ls /memory && grep -rl allergic /memory')
console.log(result.stdoutText)
await ws.close()
```

An agent or run scope sets `agentId` or `runId` instead of `userId`. `host`
(default `https://api.mem0.ai`) points at another Mem0 API host.

## Authentication

The mount sends a Mem0 Platform API key, created on the dashboard's **API
Keys** page; the organization and project come from the key. Exactly one of
`userId`, `agentId` and `runId` is set. A pair is refused: Mem0 splits a memory
added with both into separate memories, so a combined filter matches nothing.

## Layout

```text
/memory/
  6d1ba0fc-1f0c-495b-b5b1-9141b2674b37.json
  b52e7a19-0c4d-4a8e-9f3b-2d6c1e8a7f40.json
```

The tree is flat: one file per memory in the scope, named by memory id. A file
holds the full record: `memory`, `categories`, `metadata`, `created_at`,
`updated_at` and the rest.

## Behavior

- **Read-only:** no command changes the memories.
- **Times:** `stat` reports `updated_at`, or `created_at` when unset, as the
  modified time.
- **grep:** `grep` and `rg` search the JSON that `cat` prints, so a match can
  come from metadata such as categories and timestamps.
- **Freshness:** the first `ls` fetches every memory in the scope, and reads
  reuse it until the cache expires. `search` always asks Mem0.

### Search

The [`search` CLI](/typescript/cli/search) runs Mem0's semantic search in the
same scope. Register it on the workspace:

```ts
import { SEARCH } from '@struktoai/mirage-node'

ws.registerCli('search', SEARCH)
```

```bash
search --top-k 5 "quarterly planning" /memory/
```

`--top-k` defaults to `defaultSearchLimit` (10). `--threshold` is between 0 and
1. Each hit prints its file and score, then the memory, ranked by score.

## Browser

The same `Mem0VFS` runs in the browser from `@struktoai/mirage-browser`.

```bash
npm install @struktoai/mirage-browser
```

```ts
import { Mem0VFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const memory = new Mem0VFS({ apiKey: MEM0_API_KEY, userId: 'alex' })
const ws = new Workspace({ '/memory': memory }, { mode: MountMode.READ })
```

- A Mem0 API key is a secret. Never put a Platform key in a public browser
  bundle; a browser app calls a server-side proxy instead.
