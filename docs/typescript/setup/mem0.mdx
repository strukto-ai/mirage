`Mem0VFS` is a browser-safe, read-only view of one Mem0 user, agent, or run scope. Every memory is rendered as `<memory-id>.json`; `search` performs semantic search in that same scope.

<Warning>
  Mem0 API keys are secrets. Use this VFS from Node or another trusted runtime; do not embed a Platform API key in a public browser bundle. Browser applications should call a server-side proxy instead.
</Warning>

```ts
import { Mem0VFS, MountMode, Workspace } from '@struktoai/mirage-node'

const memories = new Mem0VFS({
  apiKey: process.env.MEM0_API_KEY!,
  userId: 'alex',
})

const ws = new Workspace({ '/memories': memories }, { mode: MountMode.READ })
await ws.shell('ls /memories/')
await ws.shell('search --top-k 5 "quarterly planning" /memories/')
```

Exactly one of `userId`, `agentId`, or `runId` is required.

{/* generated: config-table mem0 start */}
| Field | Required | Default | Description |
| --- | --- | --- | --- |
| `apiKey` | yes |  | Mem0 Platform API key. Redacted in snapshots. |
| `host` | no | `'https://api.mem0.ai'` | Mem0 API base URL. |
| `userId` | no |  | Mount this user's memories. Set exactly one of `userId`, `agentId` and `runId`. |
| `agentId` | no |  | Mount this agent's memories. Set exactly one of `userId`, `agentId` and `runId`. |
| `runId` | no |  | Mount this run's memories. Set exactly one of `userId`, `agentId` and `runId`. |
| `defaultPageSize` | no | `100` | Memories fetched per request while listing the scope. |
| `defaultSearchLimit` | no | `10` | How many results `search` returns unless the line sets `top_k`. |
{/* generated: config-table mem0 end */}

The TypeScript VFS mirrors the [Python Mem0 VFS](/python/vfs/mem0), including pagination, JSON rendering, score formatting, path-limited search, and `--threshold`.
