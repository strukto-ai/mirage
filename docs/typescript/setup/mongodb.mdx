`MongoDBVFS` exposes databases containing `collections/` and `views/` directories.
Each collection or view contains `schema.json` and `documents.jsonl`.

Setup steps for the connection URI live at [MongoDB Credentials](/home/setup/mongodb).

## Node

```bash
pnpm add @struktoai/mirage-node mongodb
```

```ts
import { MongoDBVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const mongo = new MongoDBVFS({
  uri: process.env.MONGODB_URI!,
  databases: ['app', 'analytics'],
})

const ws = new Workspace({ '/mongo': mongo }, { mode: MountMode.READ })
try {
  const result = await ws.shell('ls /mongo/app/collections/users/')
  console.log(result.stdoutText)
} finally {
  await ws.close()
}
```

## Browser

```bash
pnpm add @struktoai/mirage-browser
```

The browser VFS sends HTTP requests to a backend route, which keeps the MongoDB
connection URI on the server. This example expects `/api/mongo` on the same origin.
The repository's [Vite middleware](https://github.com/strukto-ai/mirage/blob/main/examples/browser/scripts/mongo_proxy.ts)
supports the database listing below for local development.

```ts
import { MongoDBVFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const mongo = new MongoDBVFS({ uri: '/api/mongo' })
const ws = new Workspace({ '/mongo': mongo }, { mode: MountMode.READ })

try {
  const result = await ws.shell('ls /mongo/')
  console.log(result.stdoutText)
} finally {
  await ws.close()
}
```

The development proxy does not yet support document streaming or schema reads.

## Config

{/* generated: config-table mongodb start */}
| Field | Required | Default | Description |
| --- | --- | --- | --- |
| `uri` | yes |  | MongoDB connection URI in Node; in the browser, the URL of a backend route that holds the connection URI. Redacted in snapshots. |
| `databases` | no |  | Databases to mount; others are hidden. Unset or empty mounts every database except `admin`, `config` and `local`. |
| `maxDocLimit` | no | `5000` | Most documents one `tail -n` read of `documents.jsonl` fetches; a larger count on a collection that holds more is refused (`File too large`). |
| `elideFields` | no | `{}` | Fields dropped from `documents.jsonl`, keyed by `<database>.<collection>` (a view's name works too); a dotted path such as `nested.path` drops a nested field. |
{/* generated: config-table mongodb end */}

## Mount mode

`read`.

For the database/collection/document layout see the [Python MongoDB docs](/python/vfs/mongodb).
