`PostgresVFS` turns a Postgres database into a read-only tree: every schema is a
folder of tables and views, and each one holds its column types, a summary of
what it means and its rows as JSON lines. Set up the connection string and a read-only role as in [Postgres setup](/home/setup/postgres).

## Install

```bash
npm install @struktoai/mirage-node pg
```

## Configure

```ts
import { MountMode, PostgresVFS, Workspace } from '@struktoai/mirage-node'

const pg = new PostgresVFS({
  dsn: process.env.DATABASE_URL!,
  schemas: ['public'],
})
const ws = new Workspace({ '/pg': pg }, { mode: MountMode.READ })

const result = await ws.shell('head -n 3 /pg/public/tables/customers/rows.jsonl')
console.log(result.stdoutText)
await ws.close()
```

`schemas` limits the tree to those schemas. `maxReadRows` and `maxReadBytes`
set how much one read of `rows.jsonl` may return.

## Authentication

The role in `dsn` needs `USAGE` on each schema the mount shows and `SELECT` on
its tables and views. Add `?sslmode=require` when the server needs TLS.

## Layout

```text
/pg/
  database.json
  public/
    tables/
      customers/
        schema.json
        semantic.json
        rows.jsonl
    views/
      paid_orders/
        schema.json
        semantic.json
        rows.jsonl
```

- `database.json`: every table with its estimated rows and size, and the
  relationships between them.
- `schema.json`: columns, keys and indexes.
- `semantic.json`: what a table means: dimensions, time dimensions and facts,
  comments, enum domains and example values.
- `rows.jsonl`: one row per line.

## Behavior

- **Read-only:** the mount only reads; no command changes the database.
- **Read limits:** a whole read of `rows.jsonl` past `maxReadRows` (counted on
  the rows the table really has) or `maxReadBytes` fails with `File too large`,
  and so does a `head -n` or `tail -n` count past it; `wc -l` counts past it.
  `defaultRowLimit` is what a windowed read with an offset but no limit
  returns.
- **File size:** `rows.jsonl` is rendered on demand, so `stat -c %s` and
  `ls -l` show `-` while its byte length is unknown. `wc -c rows.jsonl` counts
  it, within the read limits.
- **Snapshots:** the DSN is redacted. Hand the mount back at load (the third
  argument of `Workspace.load`, or a config over the server and CLI).

## Browser

The browser `PostgresVFS` from `@struktoai/mirage-browser` reaches the
database over Neon's HTTP transport, with the same fields.

```bash
npm install @struktoai/mirage-browser
```

```ts
import { MountMode, PostgresVFS, Workspace } from '@struktoai/mirage-browser'

const pg = new PostgresVFS({
  dsn: 'postgresql://mirage_reader:password@<endpoint>.neon.tech/app?sslmode=require',
  schemas: ['public'],
})
const ws = new Workspace({ '/pg': pg }, { mode: MountMode.READ })
```

- Anyone who opens the page can read the connection string. Use a read-only
  demo role on Neon, and keep private credentials in a Node backend.

## Integration

Postgres answers these commands through its own API, so fewer rows are read.
See [Integration](/home/integration/overview).

- `grep` and `rg` on one file: `LIKE` (`ILIKE` for `-i`) fetches only the rows
  that may match.
- `head -n N`: `LIMIT N`.
- `tail -n N`: the last N rows by one query.
- `wc -l`: `COUNT(*)`.
- `tail -f`: polls for rows past the last key, on a table with a primary key.

For one plain text in a `rows.jsonl`, grep and rg search the rows a `LIKE` over
each column returns, in the order a plain read returns them. A column is
searched through its cast when a line spells it the same way: text, an integer,
a boolean, a uuid, an enum, `jsonb`, `char(n)` for a text without a space, and
an array of text, integers or uuids. A number, date or time column is left out
when the text holds a character it never spells (`ada` in a `float8`). The file
is read as usual when another column type is present (`json`, `interval`,
`bytea`), when the text could lie inside one of those values, match a key,
`null` or the JSON between values, or when more than `maxReadRows` rows
match. A relation too large to read can still be searched when the output
shows no line numbers or context.
