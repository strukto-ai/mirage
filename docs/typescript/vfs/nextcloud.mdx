`NextcloudVFS` mounts a [WebDAV](http://www.webdav.org/specs/rfc4918.html)
server: Nextcloud, ownCloud, Hetzner Storage Share or any other WebDAV
endpoint. Its folders and files appear as they are, with their own names and
bytes. Set up the URL and app password as in [Nextcloud setup](/home/setup/nextcloud).

## Install

```bash
npm install @struktoai/mirage-node opendal
```

`opendal` is an optional peer package that only this mount needs.

## Configure

```ts
import { MountMode, NextcloudVFS, Workspace } from '@struktoai/mirage-node'

const nc = new NextcloudVFS({
  url: process.env.NEXTCLOUD_URL!,
  username: process.env.NEXTCLOUD_USERNAME!,
  password: process.env.NEXTCLOUD_PASSWORD!,
})
const ws = new Workspace({ '/nc': nc }, { mode: MountMode.WRITE })

const result = await ws.shell("ls /nc && find /nc -name '*.md'")
console.log(result.stdoutText)
await ws.close()
```

`url` is the WebDAV URL of the user's files, such as
`https://cloud.example.com/remote.php/dav/files/alice/`. `verifySsl` is
accepted but not applied: every request verifies the server's certificate.
