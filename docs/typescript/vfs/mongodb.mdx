`MongoDBVFS` turns MongoDB databases into a read-only tree: every collection
and view is a folder holding its sampled schema and its documents as JSON
lines. Set up the connection URI as in [MongoDB setup](/home/setup/mongodb).

## Install

```bash
npm install @struktoai/mirage-node mongodb
```

## Configure

```ts
import { MongoDBVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const mongo = new MongoDBVFS({
  uri: process.env.MONGODB_URI!,
  databases: ['sample_mflix'],
})
const ws = new Workspace({ '/mongodb': mongo }, { mode: MountMode.READ })

const result = await ws.shell('head -n 3 /mongodb/sample_mflix/collections/movies/documents.jsonl')
console.log(result.stdoutText)
await ws.close()
```

`databases` limits the tree to those databases.
`elideFields: { 'sample_mflix.movies': ['plot_embedding'] }` drops heavy
fields, such as embeddings, from what an agent reads.

## Behavior

- **Read-only:** the mount only reads; no command changes the database.
- **Streaming:** `cat`, `grep`, `jq` and `head` read documents in batches, and
  `head` stops after its count. Commands that need the whole input, such as
  `sort` or `jq -s`, still buffer it, so read a large collection in bounded
  slices.
- **Read limit:** `tail -n` with a count past `maxDocLimit` on a collection
  that long fails with `File too large` rather than printing fewer lines.
- **Elided fields:** fields under `elideFields` are dropped from
  `documents.jsonl`, for `cat` and `tail -f` alike, and keep their type in
  `schema.json`. Nested paths use dots, such as `metadata.embedding`.
- **File size:** `documents.jsonl` is rendered on demand, so `stat` and `ls -l`
  show `-` for its size and `du` counts `0`. `wc -c` measures the bytes and
  `wc -l` counts the documents; both may scan the collection. A nonempty
  `ls -l` prints `total ?`.
- **Following inserts:** `tail -f` prints the last lines, then follows new
  inserts through a change stream. That needs a replica set on MongoDB 5.0 or
  later, which Atlas is; on a standalone server, and on a view, it polls.

## Browser

The browser `MongoDBVFS` from `@struktoai/mirage-browser` sends HTTP requests
to a backend route, which keeps the connection URI on the server. Its `uri` is
that route.

```bash
npm install @struktoai/mirage-browser
```

```ts
import { MongoDBVFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const mongo = new MongoDBVFS({ uri: '/api/mongo' })
const ws = new Workspace({ '/mongodb': mongo }, { mode: MountMode.READ })
```

- The repository's
  [Vite middleware](https://github.com/strukto-ai/mirage/blob/main/examples/browser/scripts/mongo_proxy.ts)
  serves the database listing for local development. It does not yet serve
  document streams or schema reads.
