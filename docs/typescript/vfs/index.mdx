VFS types are the storage systems and services you mount into a Mirage
workspace. Browse them by category under VFS in the sidebar, or see the
[table of supported VFS](/home/setup/vfs#supported-vfs), which also shows where
each one runs.

Each VFS page covers the required configuration, mounted tree, and
VFS-specific behavior.

To implement another VFS, see [Adding a New VFS](/typescript/vfs/new).
