`LangfuseVFS` mounts one Langfuse project as read-only files: its traces with
their observations and scores, sessions, prompt versions and datasets. Set up the key pair as in [Langfuse setup](/home/setup/langfuse).

## Install

```bash
npm install @struktoai/mirage-node
```

## Configure

```ts
import { LangfuseVFS, MountMode, Workspace } from '@struktoai/mirage-node'

const langfuse = new LangfuseVFS({
  publicKey: process.env.LANGFUSE_PUBLIC_KEY!,
  secretKey: process.env.LANGFUSE_SECRET_KEY!,
  host: process.env.LANGFUSE_HOST!,
})
const ws = new Workspace({ '/langfuse': langfuse }, { mode: MountMode.READ })

const result = await ws.shell('ls /langfuse/traces && ls /langfuse/prompts')
console.log(result.stdoutText)
await ws.close()
```

`defaultTraceLimit` sets how many traces a listing shows, and
`defaultFromTimestamp` lists only traces from an ISO 8601 time on.

## Authentication

The mount reads with a project's key pair, the public key (`pk-lf-...`) and
the secret key (`sk-lf-...`), and sees only that project. `host` is the
project's region, such as `https://cloud.langfuse.com` (EU) or
`https://us.cloud.langfuse.com` (US), or a self-hosted URL. The mount reads
the Langfuse v4 API, so a self-hosted instance must run Langfuse v4.

## Layout

```text
/langfuse/
  traces/
    <trace-id>.json
  sessions/
    <session-id>/
      <trace-id>.json
  prompts/
    <prompt-name>/
      1.json
      2.json
  datasets/
    <dataset-name>/
      items.jsonl
      runs/
        <run-name>.jsonl
```

- **`traces/`:** one `.json` file per trace: the trace's root observation,
  with its other observations (spans, generations, events) in `observations`
  and its scores in `scores`. `input` and `output` are the strings Langfuse
  stores; `jq '.input | fromjson'` parses a JSON one.
- **`sessions/`:** the sessions of the traces `traces/` lists, each holding
  its own traces.
- **`prompts/`:** one folder per prompt name, one file per version (`1.json`,
  `2.json`) with the prompt content and metadata.
- **`datasets/`:** one folder per dataset, with `items.jsonl` (its items) and
  `runs/`, one `.jsonl` file per experiment run.

## Behavior

- **Read only:** no command changes Langfuse.
- **Trace limit:** `traces/` lists up to `defaultTraceLimit` traces (100),
  from `defaultFromTimestamp` on. The cap bounds the listing, not the tree:
  `stat` and `cat` still reach an older trace by its id, and
  `sessions/<id>/` serves only that session's traces.
- **Search:** `grep` and `rg` read each file as `cat` renders it. Langfuse has
  no content search, so `grep -r` over `traces/` reads every trace the listing
  returns.
- **No counts:** Langfuse has no count endpoint, so `wc -l traces/` is not
  supported.

## Browser

The browser `LangfuseVFS` from `@struktoai/mirage-browser` takes the same fields.

```bash
npm install @struktoai/mirage-browser
```

```ts
import { LangfuseVFS, MountMode, Workspace } from '@struktoai/mirage-browser'

const langfuse = new LangfuseVFS({
  publicKey: LANGFUSE_PUBLIC_KEY,
  secretKey: LANGFUSE_SECRET_KEY,
})
const ws = new Workspace({ '/langfuse': langfuse }, { mode: MountMode.READ })
```

- The secret key reaches the page, so anyone who loads it can read the project.
