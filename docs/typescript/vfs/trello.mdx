`TrelloVFS` mounts Trello as read-only JSON files: workspaces, boards, lists,
cards with their comments, members and labels. Set up the API key and token as in [Trello setup](/home/setup/trello).

## Install

```bash
npm install @struktoai/mirage-node
```

## Configure

```ts
import { MountMode, TrelloVFS, Workspace } from '@struktoai/mirage-node'

const trello = new TrelloVFS({
  apiKey: process.env.TRELLO_API_KEY!,
  apiToken: process.env.TRELLO_API_TOKEN!,
})
const ws = new Workspace({ '/trello': trello }, { mode: MountMode.READ })

const result = await ws.shell('tree -L 4 /trello/workspaces')
console.log(result.stdoutText)
await ws.close()
```

`workspaceId` or `boardIds` limits the mount to one workspace or some boards.
`baseUrl` points at a proxy.

## Behavior

- **Read only:** the mount cannot change cards. Use the
  [`trello`](/typescript/cli/trello) CLI to create, move, assign and comment on
  cards; the tree serves the same entities as JSON files. The CLI takes
  `workspaceId` and `boardIds` in its own config, so it covers the boards
  the mount lists only when both are configured alike.
- **Recent writes:** Trello indexes a write some time after it lands, so a
  search can miss a recent change. See Integration.

## Browser

The browser `TrelloVFS` from `@struktoai/mirage-browser` takes the same fields.

```bash
npm install @struktoai/mirage-browser
```

```ts
import { MountMode, TrelloVFS, Workspace } from '@struktoai/mirage-browser'

const trello = new TrelloVFS({
  apiKey: TRELLO_API_KEY,
  apiToken: TRELLO_API_TOKEN,
})
const ws = new Workspace({ '/trello': trello }, { mode: MountMode.READ })
```

- The key and token reach the page, so authorize the token with `scope=read`.
