## Installation

Use a [supported Node release](/typescript/install#quick-install), then install the runtime:

```bash
pnpm add @struktoai/mirage-node
pnpm add -D tsx typescript
```

`npm install @struktoai/mirage-node` and `yarn add @struktoai/mirage-node` work too.

## Create a Workspace

Start with the RAM VFS so you can try Mirage without credentials.

```ts quickstart.ts
import { MountMode, RAMVFS, Workspace } from '@struktoai/mirage-node'

async function main(): Promise<void> {
  const ws = new Workspace({ '/data': new RAMVFS() }, { mode: MountMode.WRITE })
  await ws.shell(`echo '{"name": "alice"}' > /data/user.json`)

  const files = await ws.shell('ls /data')
  process.stdout.write(files.stdoutText)

  const name = await ws.shell('jq -r ".name" /data/user.json')
  process.stdout.write(name.stdoutText)

  const match = await ws.shell('grep alice /data/user.json')
  process.stdout.write(match.stdoutText)

  await ws.close()
}

main()
```

Run it; it lists `user.json`, prints `alice`, then prints the matching JSON
document:

```bash
pnpm tsx quickstart.ts
```

Shell failures are returned in the result; check `exitCode` and `stderrText`
when needed. See the [in-app API reference](/typescript/access/in-app#session-shell).
