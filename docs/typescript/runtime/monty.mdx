Runs Python inside Mirage, supporting a subset of the language. Settings and notes: [Monty](/home/setup/runtime/monty).

## Install

```bash
pnpm add @pydantic/monty
```

## Usage

Declare an [`in_process`](/home/setup/machine/in_process) machine with
`runtime: monty` to run `python3` on Monty:

```typescript
import { MountMode, RAMVFS, Workspace } from '@struktoai/mirage-node'

const ws = new Workspace(
  { '/data': new RAMVFS() },
  { mode: MountMode.EXEC, machines: { py: { provider: 'in_process', runtime: 'monty' } } },
)
await ws.shell("python3 -c 'print(1 + 1)'")
```
