Runs JavaScript scripts and pipe transforms inside Mirage. Settings and notes: [QuickJS](/home/setup/runtime/quickjs).

## Install

Download `qjs-wasi.wasm` from a
[quickjs-ng release](https://github.com/quickjs-ng/quickjs/releases) and
point the runtime's `home`, or `MIRAGE_QUICKJS_HOME`, at its directory.

No package to add: each run executes in a worker. In a browser, `home`
is the URL of the folder holding `qjs-wasi.wasm`, and the page needs the
same [worker setup](/typescript/runtime/pyodide#worker-and-browser-setup)
as Pyodide.

QuickJS does not run on Cloudflare Workers: with no worker to stop it,
a script that never calls the host would hold the isolate, as the
[Cloudflare quickstart](/typescript/cloudflare-quickstart#run-a-workspace)
describes.

## Usage

Declare an `in_process` machine that runs QuickJS to run `node` on it once its engine is found:

```typescript
import { MountMode, RAMVFS, Workspace } from '@struktoai/mirage-node'

const ws = new Workspace(
  { '/data': new RAMVFS() },
  {
    mode: MountMode.EXEC,
    machines: { js: { provider: 'in_process', runtime: 'quickjs', home: '/path/to/quickjs' } },
  },
)
await ws.shell("node -e 'console.log(1 + 1)'")
```
