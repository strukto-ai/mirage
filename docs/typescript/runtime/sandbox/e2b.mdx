`E2BRuntime` connects to a live [E2B](https://e2b.dev) sandbox by id; create
it with E2B's CLI or SDK, and clean it up from your application. Programs
there see the workspace mounts at the host's paths once `mountType` serves
them, or a Mirage inside the sandbox does. See the
[Sandbox overview](/typescript/runtime/sandbox).

## Install

```bash
pnpm add e2b
```

## Configure

```yaml
runtimes:
  - name: e2b
    captures: ["python3", "pip"]
    config:
      sandbox_id: ${E2B_SANDBOX_ID}
      api_key: ${E2B_API_KEY}
      mount_type: ssh
  - workspace
```

```ts
import { E2BRuntime } from '@struktoai/mirage-node'

const runtime = new E2BRuntime({
  captures: ['python3', 'pip'],
  config: { sandboxId: 'sandbox-id', mountType: 'ssh' },
})
```

- In Node, `apiKey` falls back to `E2B_API_KEY`.
- The runtime connects on the first captured line and keeps the client until
  the workspace closes, which leaves the sandbox running.
- Commands run concurrently, each with its own stdin and output.
- Templates, sizing, networking and lifecycle stay E2B settings.

## Browsers

Import the runtime from core, which also registers `e2b` for workspace
configuration, and pass `apiKey`:

```ts
import { E2BRuntime } from '@struktoai/mirage-core/runtime/sandbox/e2b/runtime'
```

Keep account keys out of shared frontend bundles; have your backend
authenticate the app. Serving the workspace needs Node, so `mountType` `ssh`
and `both` are not available in a browser.

## Serving the workspace

With `mountType` set to `ssh` or `both` (see
[The workspace inside the sandbox](/typescript/runtime/sandbox#the-workspace-inside-the-sandbox)),
the sandbox needs only `sshfs`; on the default template,
`sudo apt-get install -y sshfs`. E2B's exec API reads output as text, so the
SFTP stream runs over a terminal.

## Standard input

Piped input goes to stdin, followed by EOF. Without input, stdin starts
closed.

<Warning>
  A timeout or cancellation tries to kill the E2B command and drops its
  output stream; descendant processes may survive. E2B also applies its SDK
  command timeout, 60 seconds by default, to every command. See
  [Resource limits](/typescript/runtime/sandbox#resource-limits).
</Warning>
