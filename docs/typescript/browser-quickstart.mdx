This quickstart runs Mirage entirely in the browser with an in-memory
filesystem. It needs no credentials or backend service.

## Create the app

This Vite starter needs Node 20.19+ on Node 20, or Node 22.12+:

```bash
npm create vite@7 mirage-browser -- --template vanilla-ts
cd mirage-browser
npm install
npm install @struktoai/mirage-browser
```

Replace `src/main.ts` with:

```ts src/main.ts
import { MountMode, RAMVFS, Workspace } from '@struktoai/mirage-browser'

async function main(): Promise<void> {
  const ws = new Workspace({ '/data': new RAMVFS() }, { mode: MountMode.WRITE })
  try {
    await ws.shell('echo "hello mirage" > /data/hello.txt')
    const result = await ws.shell('cat /data/hello.txt')
    document.querySelector<HTMLDivElement>('#app')!.textContent = result.stdoutText
  } finally {
    await ws.close()
  }
}

void main()
```

Start the development server:

```bash
npm run dev
```

Open the URL Vite prints. The page displays `hello mirage`.
