`@struktoai/mirage-browser` runs a workspace inside the page: the shell, the
commands and an in-memory filesystem, with no server and no credentials.

## Create the app

<Steps>
  <Step title="Start a Vite app">
    Vite needs Node 20.19+ or 22.12+:

    ```bash
    npm create vite@7 mirage-browser -- --template vanilla-ts
    cd mirage-browser
    npm install @struktoai/mirage-browser
    ```

    With pnpm, also add `@struktoai/mirage-core`: Vite's dev server finds
    Mirage's WebAssembly files through it.
  </Step>
  <Step title="Replace src/main.ts">
    ```ts src/main.ts
    import { MountMode, RAMVFS, Workspace } from '@struktoai/mirage-browser'

    async function main(): Promise<void> {
      const ws = new Workspace({ '/data': new RAMVFS() }, { mode: MountMode.WRITE })
      await ws.shell('echo "hello mirage" > /data/hello.txt')
      const result = await ws.shell('cat /data/hello.txt')
      document.querySelector<HTMLDivElement>('#app')!.textContent = result.stdoutText
      await ws.close()
    }

    void main()
    ```

    Mounts are read-only unless you set a mode. `MountMode.WRITE` lets the shell create and change files under `/data`.
  </Step>
  <Step title="Run it">
    ```bash
    npm run dev
    ```

    Open the URL Vite prints. The page shows `hello mirage`.
  </Step>
</Steps>
