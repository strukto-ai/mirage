Node installs ast-grep with its package. A browser page or a Worker carries the Rust parser only when it imports the CLI's entry, as below, and loads it on first use.

```typescript
import { AST_GREP } from '@struktoai/mirage-core/clis/ast_grep'

ws.registerCli('ast-grep', AST_GREP)
```

See [setup and shell examples](/home/setup/cli/ast-grep) for supported languages, rules and resource limits.
