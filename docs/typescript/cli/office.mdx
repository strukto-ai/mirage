Create, read and edit `.xlsx` workbooks, `.docx` documents and `.pptx`
decks on any mount. Mirage implements the commands below with
[OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)'s paths, output and
messages.

## Setup

`office` has no account config. It reads and writes files through
existing mounts.

```typescript
import { MountMode, OFFICE, RAMVFS, Workspace } from '@struktoai/mirage-node'

const ws = new Workspace({ '/data': new RAMVFS() }, { mode: MountMode.WRITE })
ws.registerCli('office', OFFICE)
```

For YAML registration, see the [CLI overview](/typescript/cli/index#register-a-cli).
