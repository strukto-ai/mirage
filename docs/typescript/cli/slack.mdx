Read and send Slack messages, share files, manage reactions and pins, and look up members or search messages. The action names follow [OpenClaw](https://github.com/openclaw/openclaw); `search` and `list-members` are Mirage extensions.

## Setup

Use the bot and user token scopes in [Slack setup](/home/setup/slack). The bot token handles ordinary actions; `search` needs `search_token` (`searchToken` in TypeScript).

```typescript
import { SLACK, Workspace } from '@struktoai/mirage-node'

const config = { token: 'xoxb-...', searchToken: 'xoxp-...' }
const ws = new Workspace({})
ws.registerCli('slack', SLACK, config)
```

No service mount is required. For YAML and multiple accounts, see the
[CLI overview](/typescript/cli/index#register-a-cli).
