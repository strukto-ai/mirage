Read and send Discord messages, edit or delete messages, add reactions, create threads and polls, and inspect guilds. The action names follow [OpenClaw](https://github.com/openclaw/openclaw); `members` and `server-info` are Mirage extensions.

## Setup

Configure a bot token and its permissions with [Discord setup](/home/setup/discord).

```typescript
import { DISCORD, Workspace } from '@struktoai/mirage-node'

const config = { token: 'bot-token' }
const ws = new Workspace({})
ws.registerCli('discord', DISCORD, config)
```

No service mount is required. For YAML and multiple accounts, see the
[CLI overview](/typescript/cli/index#register-a-cli).

## Supported commands

Run `discord <command> --help` for the supported flags and operands.
This list is generated from Mirage's registered command tree.

| Command | Description |
| --- | --- |
| `discord send` | Send a message to a channel |
| `discord read` | Read the most recent messages of a channel |
| `discord edit` | Edit a message the bot authored |
| `discord delete` | Delete a message |
| `discord react` | Add an emoji reaction to a message |
| `discord search` | Search a guild's messages by content |
| `discord thread-create` | Create a thread, standalone or from a message |
| `discord poll` | Post a poll message to a channel |
| `discord members` | List a guild's members, optionally filtered |
| `discord server-info` | Fetch a guild's metadata |
{/* END GENERATED CLI COMMANDS */}

## Messages

```bash
discord read --channel 1256522563555819574 --limit 20
discord send --channel 1256522563555819574 --text "Release is ready"
discord send --channel 1256522563555819574 --text "A reply" --reply-to 1489887688978075769
discord edit --channel 1256522563555819574 --message 1489887688978075769 --text "Updated"
discord delete --channel 1256522563555819574 --message 1489887688978075769
```

`edit` works only on messages authored by the bot. Channel, guild and message
arguments are Discord snowflake IDs, not workspace paths.

## Threads, polls and search

```bash
discord react --channel 1256522563555819574 --message 1489887688978075769 --emoji "👍"
discord thread-create --channel 1256522563555819574 --message 1489887688978075769 --name "Release review"
discord poll --channel 1256522563555819574 --question "Ship today?" --answer Yes --answer Tomorrow --duration 24
discord server-info --guild 1256522563555819574
discord members --guild 1256522563555819574 --query alice
discord search --guild 1256522563555819574 --query deploy --channel 1256522563555819574
```

Omit `--message` on `thread-create` to create a standalone thread. Repeat
`--answer` for each poll option; `--multiselect` allows multiple choices.
Responses are JSON.

## VFS and limits

The optional [Discord VFS](/typescript/discord) exposes the guild's
channels and messages as files. Use the IDs in its `name__id` path segments
with the CLI. Registration remains independent of the mount, and command
policy controls service writes.

Only the listed actions are implemented.
