What to install and a runnable TypeScript example. The settings, how the workspace connects and the notes are on [boxd](/home/setup/machine/boxd), shared by both SDKs.

## Install

```bash
pnpm add @boxd-sh/sdk
```

```typescript
import { Boxd } from '@boxd-sh/sdk'

const boxd = new Boxd({ region: 'fra' })
const machine = await boxd.machines.create({ name: 'mirage-box', isolated: true })
await boxd.machines.waitUntilReady(machine.id)
console.log(machine.id)
```

## Usage

`captures` defaults to [`@external`](/home/setup/machine/overview#captures):
every program Mirage does not have itself. Name `@python` to run
Python on the machine too.

```typescript
import { MountMode, RAMVFS, Workspace } from '@struktoai/mirage-node'

const ws = new Workspace(
  { '/data': new RAMVFS() },
  {
    mode: MountMode.EXEC,
    machines: {
      box: {
        provider: 'boxd',
        machineId: 'machine-id',
        region: 'fra',
        captures: ['@python', '@external'],
      },
    },
  },
)
await ws.shell("python3 -c 'print(1 + 1)'")
```
