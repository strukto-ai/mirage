What to install and a runnable TypeScript example. The settings, how the workspace connects and the notes are on [Kubernetes](/home/setup/machine/kubernetes), shared by both SDKs.

## Usage

`captures` defaults to [`@external`](/home/setup/machine/overview#captures):
every program Mirage does not have itself. Name `@python` to run
Python in the pod too.

```typescript
import { MountMode, RAMVFS, Workspace } from '@struktoai/mirage-node'

const ws = new Workspace(
  { '/data': new RAMVFS() },
  {
    mode: MountMode.EXEC,
    machines: { box: { provider: 'kubernetes', pod: 'mirage-box', captures: ['@python', '@external'] } },
  },
)
await ws.shell("python3 -c 'print(1 + 1)'")
```
