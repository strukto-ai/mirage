## Layout

```text
/gmail/
  INBOX/
    2026-11-16/
      Invoice_November__18c2f9a4b7e3d1a0.gmail.json
      Invoice_November__18c2f9a4b7e3d1a0/
        invoice.pdf
  SENT/
  STARRED/
  Receipts/
```

- System labels are named by their label ID (`INBOX`, `SENT`, `STARRED`);
  user labels by their name.
- Inside a label, one folder per day, the date each message was received.
- A message file is named `<subject>__<message-id>.gmail.json`, the subject
  sanitized and cut short when needed. `ls` the day rather than build the
  name.
- A message with attachments has a folder of the same name without
  `.gmail.json`, holding the decoded files.
- The part after `__` is the message id that `gws gmail read --id` and
  `gws gmail reply --message-id` take.
