## Integration

GridFS answers these commands through its own API, so fewer files are read.
See [Integration](/home/integration/overview).

- `find`: one recursive listing.
- `du`: one recursive listing.
- `ls -R` and `tree`: one recursive listing.
- `grep -r`, `rg` and `cp -r`: one `fs.files` query for the whole tree; see
  [Walks](/home/integration/walks).
