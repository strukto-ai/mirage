## Layout

```text
/gslides/
  owned/
    2026-11-14_QBR_Deck__1Xk9rT2bQ.gslide.json
  shared/
    2026-10-02_Launch_Plan__1Pq7sV4mN.gslide.json
```

- `owned/` holds the presentations the account owns, shared or not;
  `shared/` holds those others shared with it.
- A file is named `<YYYY-MM-DD>_<title>__<presentation-id>.gslide.json`. The date
  is the last modified day and is left out when Drive gives none.
- A file holds the Slides API's JSON for the presentation: its slides,
  layouts and text.
