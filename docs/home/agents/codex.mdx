## Install

<CodeGroup>
```bash uv
uv tool install 'mirage-ai[ssh]'
```
```bash npm
npm install -g @struktoai/mirage-cli
```
</CodeGroup>

Install [Codex](https://github.com/openai/codex) separately.

## Workspace

```yaml workspace.yaml
mounts:
  /:
    vfs: ram
    mode: write
```

```bash
mirage workspace create workspace.yaml --id demo
```

## SSH

Turn on the daemon's [SSH server](/home/access/ssh#set-up), then:

```toml ~/.codex/environments.toml
default = "mirage"
include_local = false

[[environments]]
id = "mirage"
program = "ssh"
args = ["-T", "-p", "2222", "demo@127.0.0.1", "-s", "codex-exec"]
```

```bash
codex -C /
```

## MCP

<CodeGroup>
```bash mirage mcp
codex mcp add mirage -- mirage mcp -w demo
```
```bash Plugin
codex plugin marketplace add strukto-ai/mirage
codex plugin add mirage@mirage
```
</CodeGroup>

The plugin serves its own workspace from `.mirage/workspace.yaml`, not `demo`.

## FUSE

Install a [FUSE driver](/home/setup/fuse), and with uv, `'mirage-ai[fuse]'`.

```yaml workspace.yaml
mounts:
  /:
    vfs: ram
    mode: write
    backend: fuse
    mountpoint: /tmp/mirage-demo
```

```bash
mirage workspace create workspace.yaml --id demo-fuse
cd /tmp/mirage-demo && codex
```

## Exec-server forward

For a remote harness such as the OpenAI Agents API ([Python](/python/agents/openai-agents-api), [TypeScript](/typescript/agents/openai-agents-api)):

```bash
npm install -g @openai/codex@alpha
mirage codex-exec demo --listen 127.0.0.1:8790
```

```bash
CODEX_API_KEY="$OPENAI_EXECUTOR_API_KEY" codex exec-server forward \
  --connect ws://127.0.0.1:8790 \
  --remote "$REMOTE_URL" \
  --environment-id "$ENVIRONMENT_ID"
```

`mirage codex-exec` accepts any local connection with the CLI's token, so keep it on loopback.
