## Install

<CodeGroup>
```bash uv
uv tool install mirage-ai
```
```bash npm
npm install -g @struktoai/mirage-cli
```
</CodeGroup>

Install [Claude Code](https://docs.claude.com/en/docs/claude-code/setup) separately.

## Workspace

```yaml workspace.yaml
mounts:
  /Users/me/project: { vfs: disk, mode: write, config: { root: /Users/me/project } }
  /tmp: { vfs: disk, mode: write, config: { root: /tmp } }
  /data: { vfs: ram, mode: write }
```

```bash
mirage workspace create workspace.yaml --id demo
```

The project and `/tmp` mounts keep Claude's paths and working directory the same inside the workspace.

## Shell

```json .claude/settings.json
{
  "env": {
    "CLAUDE_CODE_SHELL": "/Users/me/.local/bin/mirage-bash",
    "MIRAGE_WORKSPACE": "demo"
  }
}
```

Use the path `command -v mirage-bash` prints. Every command Claude's Bash tool runs now goes to the workspace.

## MCP

<CodeGroup>
```bash mirage mcp
claude mcp add mirage -- mirage mcp -w demo
```
```text Plugin
/plugin marketplace add strukto-ai/mirage
/plugin install mirage@mirage
```
</CodeGroup>

## FUSE

Install a [FUSE driver](/home/setup/fuse), and with uv, `'mirage-ai[fuse]'`.

```yaml workspace.yaml
mounts:
  /:
    vfs: ram
    mode: write
    backend: fuse
    mountpoint: /tmp/mirage-demo
```

```bash
mirage workspace create workspace.yaml --id demo-fuse
cd /tmp/mirage-demo && claude
```
