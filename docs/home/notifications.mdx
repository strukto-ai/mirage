title: Notifications
description: Tell agents when files or directories change in the virtual filesystem.

---

Notifications tell an agent when a file or directory changes in the virtual
filesystem: a teammate edits a report in Box, and the agent gets
`update /box/report.csv`.

1. The application receives a change from the service, or asks it for one.
2. It reports the change with `ws.notify()`, which also drops Mirage's cached
   copy of that path.
3. The agent receives it from `ws.events()`.

`ws.events()` alone watches nothing: the application connects the service, by
[push](#push) or [poll](#poll).

## Listen for changes

<CodeGroup>
```python Python
async for change in ws.events("/data"):
    print(f"{change.kind.value}: {change.path.virtual}")
```

```typescript TypeScript
for await (const change of ws.events('/data')) {
  console.log(`${change.kind}: ${change.path.virtual}`)
}
```
</CodeGroup>

```text
update: /data/report.csv
```

| Path | Receives |
| --- | --- |
| `/data` | every change under `/data` |
| `/data/*.csv` | changes to CSV files directly inside `/data` |
| `["/data/reports", "/data/config.json"]` | changes under `reports` or to `config.json` |

| Kind | Meaning |
| --- | --- |
| `create` | a file or directory was added |
| `update` | its contents or metadata changed |
| `delete` | it was removed |
| `move` | it was renamed or moved; the change also carries its previous path |
| `unknown` | something changed but the service gave no details; read the path again |

## Push

The service sends each change: a webhook, a stream or a file watcher. A hook
turns its payload into changes for `ws.notify()`:

<CodeGroup>
```python Python
from mirage.core.s3.events import S3EventHook
from mirage.types import PathSpec

hook = S3EventHook(vfs.accessor)
root = PathSpec.from_str_path("/s3", "")
for record in payload["Records"]:
    for change in await hook.to_events(root, record["eventName"], record):
        await ws.notify(change)
```

```typescript TypeScript
import { PathSpec } from '@struktoai/mirage-node'
import { S3EventHook } from '@struktoai/mirage-core/core/s3/events'

const hook = new S3EventHook(vfs.accessor)
const root = PathSpec.fromStrPath('/s3', '')
for (const record of payload.Records) {
  for (const change of await hook.toEvents(root, record.eventName, record)) {
    await ws.notify(change)
  }
}
```

## Poll

The VFS asks the service what changed since a checkpoint. The first `pull`,
with no checkpoint, returns none and records where to start:

<CodeGroup>
```python Python
import asyncio

from mirage.types import PathSpec

hook = vfs.delta_hook()
root = PathSpec.from_str_path("/box", "")
checkpoint = (await hook.pull(root, None)).checkpoint
while True:
    await asyncio.sleep(5)
    result = await hook.pull(root, checkpoint)
    for change in result.changes:
        await ws.notify(change)
    checkpoint = result.checkpoint
```

```typescript TypeScript
import { setTimeout as delay } from 'node:timers/promises'
import { PathSpec } from '@struktoai/mirage-node'

const hook = vfs.deltaHook()
const root = PathSpec.fromStrPath('/box', '')
let checkpoint = (await hook.pull(root, null)).checkpoint
for (;;) {
  await delay(5000)
  const result = await hook.pull(root, checkpoint)
  for (const change of result.changes) await ws.notify(change)
  checkpoint = result.checkpoint
}
```

The Disk example edits files behind Mirage, reports each change, and reads
again:

```text
$ cat /data/reports/q1.txt
first quarter
create: /data/reports/q3.txt
update: /data/reports/q1.txt
delete: /data/reports/q2.txt
$ cat /data/reports/q1.txt
first quarter, revised
$ ls /data/reports
q1.txt
q3.txt
```

The S3 and GitHub examples read a saved payload and start no webhook server.
Dropbox waits on a long poll; Box and Google Drive check every five seconds
until Ctrl-C.
