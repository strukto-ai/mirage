Mirage gives an agent a unified virtual terminal across different machines. The
agent types every command in the same terminal, and each one runs on the machine
that fits it, plain Python inside Mirage, numpy in a small container, data
processing on a CPU sandbox and training on a GPU, so the agent finishes its
tasks faster and at lower cost.

| Machine | Provider | Task |
| --- | --- | --- |
| `monty` | [In Process](/home/setup/machine/in_process) | Count page views, in plain Python |
| `cf` | [Cloudflare Container](/home/setup/machine/cloudflare_container), lite | Summarize the counts with numpy |
| `cpu` | [E2B](/home/setup/machine/e2b) | Build features with pandas |
| `gpu` | [SSH](/home/setup/machine/ssh) | Train a model with PyTorch |

## Routing

A policy script picks the machine for each Python command by the library its
code uses:

| When the code uses | It runs on |
| --- | --- |
| No packages | <img noZoom src="/images/pydantic-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />`monty`, inside Mirage |
| numpy | <img noZoom src="/images/cloudflare-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />`cf`, the Cloudflare lite container |
| pandas | <img noZoom src="/images/e2b-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />`cpu`, the E2B sandbox |
| PyTorch | <img noZoom src="/images/ec2-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />`gpu`, the EC2 GPU instance |

<Accordion title="route.py">
  ```python route.py
  MACHINES = (
      ("torch", "gpu", "PyTorch trains on the GPU"),
      ("pandas", "cpu", "pandas processes data on the E2B sandbox"),
      ("numpy", "cf", "numpy runs in the Cloudflare container"),
  )


  def source(ctx):
      code = " ".join(ctx["argv"])
      for path in ctx["paths"]:
          if not path.endswith(".py"):
              continue
          try:
              code += open(path).read()
          except OSError:
              pass
      return code


  def pre_command(ctx):
      if not ctx["command"].startswith("python"):
          return None
      code = source(ctx)
      for library, machine, reason in MACHINES:
          if library in code:
              return {"kind": "route", "machine": machine, "reason": reason}
  ```
</Accordion>

## Count Page Views

`/workspace/raw` holds a year of page views, one file a quarter. Mirage fans the
counting out to four Monty runs, lightweight Python sandboxes inside Mirage, one
per quarter, so they run in parallel with no container to start. Only the numpy
summary goes to the Cloudflare lite container, which then runs for seconds
instead of the whole task.

<MachineBenchmark kind="fanout" />

A lite container shares its 1/16 vCPU across every process in it, so counting
the quarters in parallel there is no faster, about 16 seconds against 11.7 one
after another. The four Monty runs take about 3.3 seconds, and the container
runs only for numpy.

### Monty: count each quarter in parallel

<Accordion title="jobs/count.py">
  ```python jobs/count.py
  name = argv[1].split("/")[-1].removesuffix(".csv")
  counts = {}
  with open(argv[1]) as views:
      next(views)
      for line in views:
          page = line.split(",")[1]
          counts[page] = counts.get(page, 0) + 1
  with open(f"/workspace/counts/{name}.txt", "w") as out:
      for page in sorted(counts):
          out.write(f"{counts[page]}\n")
  ```
</Accordion>

```bash
for f in /workspace/raw/*.csv; do
  python3 /workspace/jobs/count.py $f &
done
```

## Train a Model

The features and the model come from the same year of page views. pandas
builds the features on the E2B sandbox, and only the training goes to the GPU,
so the GPU is paid for the training alone.

<MachineBenchmark kind="gpu" />

pandas runs about as fast on the E2B sandbox as on the GPU machine's CPU, so the
two take about the same time. The GPU costs about 4.5 times as much a second, so
moving the features off it cuts the cost by about 44%. `python3 -P` keeps the
script's folder off Python's import path, so its imports do not search
`/workspace` over the network.

### E2B: build features

`build.py` turns the four quarters of page views into one row per user
with pandas, and writes them back to `/workspace`.

<Accordion title="jobs/build.py">
  ```python jobs/build.py
  from glob import glob

  import pandas as pd

  events = pd.concat(pd.read_csv(path) for path in sorted(glob("/workspace/raw/*.csv")))
  features = events.groupby("user").agg(visits=("page", "count"), spend=("amount", "sum")).reset_index()
  features["label"] = (features["spend"] > features["spend"].median()).astype(int)
  features.to_csv("/workspace/features.csv", index=False)
  print(f"{len(events)} events -> {len(features)} users")
  ```
</Accordion>

```bash
python3 -P /workspace/jobs/build.py
# 1111538 events -> 50 users
```

### GPU: train the model

`train.py` reads the features the E2B sandbox wrote, trains a small model
on the T4 and saves it next to them. Started as a background job, `ps` lists it
on the GPU by its real pid there, and `jobs`, `wait` and `kill` reach it the
same way.

<Accordion title="jobs/train.py">
  ```python jobs/train.py
  import csv

  import torch

  rows = list(csv.DictReader(open("/workspace/features.csv")))
  x = torch.tensor([[float(r["visits"]), float(r["spend"])] for r in rows], device="cuda")
  y = torch.tensor([float(r["label"]) for r in rows], device="cuda")
  x = (x - x.mean(0)) / (x.std(0) + 1e-6)
  model = torch.nn.Linear(2, 1).cuda()
  optimizer = torch.optim.SGD(model.parameters(), lr=0.5)
  for _ in range(200):
      loss = torch.nn.functional.binary_cross_entropy_with_logits(model(x).squeeze(1), y)
      optimizer.zero_grad()
      loss.backward()
      optimizer.step()
  torch.save(model.state_dict(), "/workspace/model.pt")
  print(f"trained on {torch.cuda.get_device_name(0)}, loss {loss.item():.3f}")
  ```
</Accordion>

```bash
python3 -P /workspace/jobs/train.py &
```
