## Python import errors

Run your script in the environment where Mirage is installed. For a uv
project, use `uv run python your_script.py`.

Some VFS types need an extra package:

```bash
uv add "mirage-ai[s3]"     # S3 and compatible stores
uv add "mirage-ai[redis]"  # Redis
```

See [Python installation](/python/install) for the available extras.

## TypeScript import errors

Use the package for your environment:

| Environment | Package |
| --- | --- |
| Node.js | `@struktoai/mirage-node` |
| Browser | `@struktoai/mirage-browser` |
| Shared types and primitives | `@struktoai/mirage-core` |

If a browser build complains about Node built-ins, check for imports from
`@struktoai/mirage-node`. Use the browser package and a
[browser-supported VFS](/home/setup/vfs#supported-vfs) instead.

For missing optional dependencies such as `redis` or `pg`, follow
[TypeScript installation](/typescript/install#optional-peer-dependencies).

## Credentials or connection errors

- Set credentials in the environment of the process running Mirage.
- Check the service URL, account permissions and required token scopes.
- Follow the setup guide for your [VFS](/home/setup/vfs#supported-vfs).

## Missing files or empty output

Start by inspecting the mounted paths:

```bash
mount
ls /
ls /your-mount/
stat /your-mount/path/to/file
```

Use the exact path shown by the listing. Confirm that the connected account
can access the file. In SDK code, inspect the command's exit code and stderr
as well as stdout.

## Writes are refused

Check that the VFS supports the operation and that the mount has `write` or
`exec` mode. A read-only backend stays read-only even on a writable mount.
Session [policies](/home/policy/overview) can also restrict access.

## FUSE does not mount

FUSE is optional; `ws.shell(...)` works without an OS mount. If you need a
mounted folder, follow the [macOS](/home/setup/macos) or
[Linux](/home/setup/linux) setup, then install the binding for your SDK:

- Python: `uv add "mirage-ai[fuse]"`.
- TypeScript: follow the [FUSE setup](/typescript/setup/fuse), including its
  native dependency installation steps.

## Still stuck?

[Open an issue](https://github.com/strukto-ai/mirage/issues) with your Mirage
version, operating system, SDK, error message and a minimal example. Remove
credentials from logs and configuration before sharing them.
