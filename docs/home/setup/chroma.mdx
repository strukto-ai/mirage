A ChromaDB collection becomes a tree of text files. Each file is its chunks
joined in order.

## Setup

Run a Chroma server (it listens on port 8000 by default) and store the
collection in the shape the mount reads: one path tree document plus chunk
documents that name their file.

<AccordionGroup>
  <Accordion title="1. Add the path tree document">
    Store one document with the ID `__path_tree__`. Its content is a JSON
    object, plain or gzip-compressed and base64-encoded, whose keys are file
    paths below the mount:

    ```json
    {
      "README.md": {"size": 1024, "created_at": "2026-01-01T00:00:00Z"},
      "guides/quickstart.md": {"size": 4096, "updated_at": "2026-01-03T00:00:00Z"}
    }
    ```

    - Forward slashes make folders.
    - No empty path, and no `.`, `..` or empty segment.
    - Every path stays unique after leading and trailing slashes are trimmed.
    - A path is never both a file and a folder prefix: `guides` and
      `guides/quickstart.md` cannot both be files.
    - `size`, `created_at` and `updated_at` are optional and used when present.
  </Accordion>
  <Accordion title="2. Tag every chunk">
    Each chunk document names its file and its place in that file:

    ```json
    {"page_slug": "guides/quickstart.md", "chunk_index": 0}
    ```

    The keys default to `page_slug` and `chunk_index`. A collection with other
    names sets `slug_field` and `chunk_index_field` in the config.
  </Accordion>
  <Accordion title="3. Check the collection">
    Confirm the tree document and at least one chunk for a path:

    ```python
    import chromadb

    client = chromadb.HttpClient(host="localhost", port=8000)
    collection = client.get_collection("knowledge")

    tree = collection.get(ids=["__path_tree__"])
    chunks = collection.get(where={"page_slug": "guides/quickstart.md"})

    print(tree["documents"][0])
    print(len(chunks["documents"]))
    ```
  </Accordion>
</AccordionGroup>

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /knowledge:
        vfs: chroma
        mode: read
        config:
          host: localhost
          port: 8000
          collection_name: knowledge
    ```

    ```bash
    mirage workspace create workspace.yaml --id kb
    mirage shell -w kb -c 'ls /knowledge'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import MountMode, Workspace
    from mirage.vfs.chroma import ChromaConfig, ChromaVFS

    config = ChromaConfig(host="localhost", port=8000, collection_name="knowledge")
    ws = Workspace({"/knowledge": ChromaVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /knowledge")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { ChromaVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      {
        '/knowledge': new ChromaVFS({
          host: 'localhost',
          port: 8000,
          collectionName: 'knowledge',
        }),
      },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /knowledge')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/knowledge/
  README.md
  guides/
    api.md
    quickstart.md
  policies/
    refunds.md
```

- Paths come from the `__path_tree__` document; `ssl: true` reaches the server
  over HTTPS.
- A file is its chunks sorted by chunk index and joined by line breaks, so no
  `grep` match spans two chunks.
- The `search` CLI ranks chunks by meaning with Chroma's
  vector query.

## Sample runs

```bash
$ ls /knowledge
README.md
guides
policies
```

```bash
$ cat /knowledge/guides/quickstart.md
# Quickstart
Create an API key in Settings.
Send the key in the Authorization header.
```

```bash
$ grep -rn Authorization /knowledge
/knowledge/guides/quickstart.md:3:Send the key in the Authorization header.
```

The mount is read-only. `grep -r` reads only the files Chroma finds the text
in; Chroma matches case, so `grep -ri` reads every file.
