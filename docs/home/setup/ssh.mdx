A directory on a remote server becomes a local-looking tree of files, read
and written over SFTP. It works from Python and Node.

## Setup

The server needs SFTP turned on and an SSH account with access to the
directory. Create a key and install it on the server, then check that SFTP
answers:

```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519
ssh-copy-id -i ~/.ssh/id_ed25519.pub deploy@server.example.com
sftp -i ~/.ssh/id_ed25519 deploy@server.example.com
```

- `private_key` takes the key's own text in place of `identity_file`'s path,
  so a [credential pointer](/home/service-credentials#pointer-fields) can read
  it from a secret store.
- Without `identity_file` or `private_key`, the SSH agent and the default keys
  in `~/.ssh` are tried. `password` works too, but a key is preferred.

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /remote:
        vfs: ssh
        mode: read
        config:
          host: server.example.com
          username: deploy
          identity_file: ~/.ssh/id_ed25519
          root: /srv/data
    ```

    ```bash
    mirage workspace create workspace.yaml --id remote
    mirage shell -w remote -c 'ls /remote'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import MountMode, Workspace
    from mirage.vfs.ssh import SSHConfig, SSHVFS

    config = SSHConfig(
        host="server.example.com",
        username="deploy",
        identity_file="~/.ssh/id_ed25519",
        root="/srv/data",
    )
    ws = Workspace({"/remote": SSHVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /remote")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { MountMode, SSHVFS, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      {
        '/remote': new SSHVFS({
          host: 'server.example.com',
          username: 'deploy',
          identityFile: '~/.ssh/id_ed25519',
          root: '/srv/data',
        }),
      },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /remote')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/remote/
  logs/
    app.log
  reports/
    2026-11.csv
```

- `/remote/logs/app.log` is `/srv/data/logs/app.log` on the server.
- In Python, `host` also matches a `~/.ssh/config` alias, and its settings
  apply.
- Host keys are checked only in Python with `known_hosts` set; the TypeScript
  VFS does not verify them.

## Sample runs

```bash
$ ls /remote
logs
reports
```

```bash
$ tail -n 2 /remote/logs/app.log
2026-11-16T09:14:02Z INFO request served path=/health
2026-11-16T09:14:05Z WARN slow query took=1.8s
```

```bash
$ head -n 2 /remote/reports/2026-11.csv
day,orders
2026-11-01,412
```

`mode: write` allows changes, as far as the SSH account's permissions allow.
To run programs on the server, use the [SSH machine](/home/setup/machine/ssh).
