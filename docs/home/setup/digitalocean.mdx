Every object in a DigitalOcean Space becomes a file, and every `/` in a key becomes a folder.



## Setup

Create a Spaces access key in the [DigitalOcean control panel](https://cloud.digitalocean.com/), then export it.

<AccordionGroup>
  <Accordion title="Create a Spaces access key">

1. Click **Spaces Object Storage** in the left menu, open the **Access Keys**
   tab and click **Create Access Key**.
1. Pick **Limited Access** and grant the Space **Read**, or
   **Read/Write/Delete** for a write mount. **Full Access** reaches every
   Space.
1. Name and create the key, then copy the **Access Key ID** and
   **Secret Key**. The secret key is shown only once.
1. Note the Space's name (the bucket) and its region, for example `nyc3`.

  </Accordion>
</AccordionGroup>

```bash
export DO_SPACE=my-space
export DO_REGION=nyc3
export DO_ACCESS_KEY_ID=...
export DO_SECRET_ACCESS_KEY=...
```

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /spaces:
        vfs: digitalocean
        mode: read
        config:
          bucket: ${DO_SPACE}
          region: ${DO_REGION}
          access_key_id: ${DO_ACCESS_KEY_ID}
          secret_access_key: ${DO_SECRET_ACCESS_KEY}
    ```

    ```bash
    mirage workspace create workspace.yaml --id spaces
    mirage shell -w spaces -c 'ls /spaces'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.digitalocean import DigitalOceanConfig, DigitalOceanVFS

    config = DigitalOceanConfig(
        bucket=os.environ["DO_SPACE"],
        region=os.environ["DO_REGION"],
        access_key_id=os.environ["DO_ACCESS_KEY_ID"],
        secret_access_key=os.environ["DO_SECRET_ACCESS_KEY"],
    )
    ws = Workspace({"/spaces": DigitalOceanVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /spaces")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { DigitalOceanVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      {
        '/spaces': new DigitalOceanVFS({
          bucket: process.env.DO_SPACE!,
          region: process.env.DO_REGION!,
          accessKeyId: process.env.DO_ACCESS_KEY_ID!,
          secretAccessKey: process.env.DO_SECRET_ACCESS_KEY!,
        }),
      },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /spaces')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/spaces/
  README.md
  logs/
    app-2026-11-15.log
    app-2026-11-16.log
  reports/
    2026-q3.csv
    2026-q4.csv
```

- The endpoint comes from `region`: `<region>.digitaloceanspaces.com`.
  `endpoint_url` (`endpoint` in TypeScript) overrides it.
- `key_prefix` (`keyPrefix` in TypeScript) mounts one folder of the bucket as
  the root.
- `grep -r`, `find` and `du` stop after 1000 files; a glob matching more,
  `tar -c`, `cp -r` and `rm -r` are refused.

## Sample runs

```bash
$ ls /spaces
README.md
logs
reports
```

```bash
$ find /spaces -name '*.csv'
/spaces/reports/2026-q3.csv
/spaces/reports/2026-q4.csv
```

```bash
$ grep -r ERROR /spaces/logs
/spaces/logs/app-2026-11-15.log:2026-11-15T08:01:13Z ERROR timeout reaching db
/spaces/logs/app-2026-11-16.log:2026-11-16T09:12:40Z ERROR timeout reaching db
```

On a `write` mount, `cp`, `mv`, `rm` and `>` change objects in the bucket. For
`write: conditional`, see [S3-compatible VFSes](/home/setup/s3#s3-compatible-vfses).
