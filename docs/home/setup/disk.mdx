Disk mounts a host directory at a workspace path. Available in Python and
Node; for browser storage, use [OPFS](/home/setup/opfs).

## Configuration

Replace `root` with the directory you want to access:

```yaml
mounts:
  /data:
    vfs: disk
    mode: read
    config:
      root: /path/to/files
```

`ls /data` lists that directory. Set `mode: write` to allow changes to its
files through Mirage.

A second disk mount whose `root` resolves to a folder already mounted is
refused; a folder inside one is fine.
