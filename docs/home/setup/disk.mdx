Disk mounts a host directory at a workspace path. Its files and folders show
up as they are on disk.

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /data:
        vfs: disk
        mode: read
        config:
          root: /srv/files
    ```

    ```bash
    mirage workspace create workspace.yaml --id files
    mirage shell -w files -c 'ls /data'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import MountMode, Workspace
    from mirage.vfs.disk import DiskVFS

    ws = Workspace({"/data": DiskVFS(root="/srv/files")}, mode=MountMode.READ)
    result = await ws.shell("ls /data")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { DiskVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      { '/data': new DiskVFS({ root: '/srv/files' }) },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /data')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/data/
  config.json
  notes.md
  reports/
    q1.csv
    q2.csv
```

- The mount mirrors `root`; a path such as `../../etc/passwd` never leaves it.
- A second disk mount whose `root` resolves to a folder already mounted is
  refused; a folder inside one is fine.
- Python and Node only. In a browser, use [OPFS](/home/setup/opfs).

## Sample runs

```bash
$ tree /data
/data
|-- config.json
|-- notes.md
`-- reports
    |-- q1.csv
    `-- q2.csv

2 directories, 4 files
```

```bash
$ grep -r west /data/reports
/data/reports/q1.csv:west,120
/data/reports/q2.csv:west,140
```

```bash
$ jq -r .region /data/config.json
us-east-1
```

Set `mode: write` to let commands change the directory's files. Add
`capacity: 1GB` under `config` to cap the bytes it holds; see
[capacity](/home/setup/vfs#mount-capacity).
