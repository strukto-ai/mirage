One OAuth client and refresh token cover every Google mount and the `gws` CLI.
Drive becomes its folder tree, Docs, Sheets and Slides become JSON files, and
Gmail becomes folders of labels and days.
[Google Calendar](/home/setup/gcal) uses the same credentials.

## Setup

Create a Google Cloud project, turn on the APIs, configure the consent screen,
create a Desktop OAuth client and trade one sign-in for a refresh token.

<AccordionGroup>
  <Accordion title="1. Create a Google Cloud project">
    1. Open the [Google Cloud console](https://console.cloud.google.com/).
    1. Open the project selector and click **New Project**.
    1. Name it (for example "Mirage") and click **Create**.
    1. Select the new project in the selector.
  </Accordion>
  <Accordion title="2. Enable the APIs">
    In the [API Library](https://console.cloud.google.com/apis/library), enable
    the API for each service in use:

    | Service | API to enable | Scope for read and write commands |
    | --- | --- | --- |
    | Drive | Google Drive API | `https://www.googleapis.com/auth/drive` |
    | Docs | Google Docs API | `https://www.googleapis.com/auth/documents` |
    | Sheets | Google Sheets API | `https://www.googleapis.com/auth/spreadsheets` |
    | Slides | Google Slides API | `https://www.googleapis.com/auth/presentations` |
    | Gmail | Gmail API | `https://www.googleapis.com/auth/gmail.modify` |
    | Calendar | Google Calendar API | `https://www.googleapis.com/auth/calendar` |

    - Keep the Drive API and scope for every Google file mount.
    - The `gws` create commands also need Drive to place new files inside a
      configured folder.
    - For read-only use, pick the matching read-only scopes.
  </Accordion>
  <Accordion title="3. Configure Google Auth Platform">
    The OAuth settings live under **Google Auth Platform** in the console
    sidebar ([overview](https://console.cloud.google.com/auth/overview)).

    1. **Branding**: enter an app name (for example "Mirage"), a support
       email and a developer contact email, then save.
    1. **Audience**: set the user type to **External** and add the Google
       account that will sign in as a **test user**, then save.
    1. **Data Access**: click **Add or Remove Scopes**, add the scopes from
       step 2, then save.
  </Accordion>
  <Accordion title="4. Create an OAuth client">
    1. Open **Clients** in the sidebar (or **Create OAuth client** on the
       Overview page).
    1. Set the application type to **Desktop app**.
    1. Name it and click **Create**.
    1. Copy the **Client ID** and **Client Secret**.
  </Accordion>
  <Accordion title="5. Get the refresh token">
    Open this URL in a browser. Replace `YOUR_CLIENT_ID` and put the scopes
    from step 2 in `scope`, separated by `%20`. This one asks for Drive and
    Docs:

    ```text
    https://accounts.google.com/o/oauth2/v2/auth?client_id=YOUR_CLIENT_ID&redirect_uri=http://localhost:1&response_type=code&scope=https://www.googleapis.com/auth/drive%20https://www.googleapis.com/auth/documents&access_type=offline&prompt=consent
    ```

    - `access_type=offline` asks for a refresh token.
    - `prompt=consent` issues a new refresh token on every sign-in.

    Sign in, click through the "unverified app" warning and grant access. The
    browser then goes to `http://localhost:1/?code=4/0A...`, a page that does
    not load. Copy the `code` value from the address bar and exchange it
    right away:

    ```bash
    curl -X POST https://oauth2.googleapis.com/token \
      -d "client_id=YOUR_CLIENT_ID" \
      -d "client_secret=YOUR_CLIENT_SECRET" \
      -d "code=THE_CODE" \
      -d "grant_type=authorization_code" \
      -d "redirect_uri=http://localhost:1"
    ```

    The JSON reply holds `refresh_token`. Save it.
  </Accordion>
  <Accordion title="Token lifetime">
    | Publishing status | Refresh token |
    | --- | --- |
    | Testing (default) | Expires after 7 days for External users, unless only basic profile scopes are requested |
    | In production | Lasts while the grant stays valid |

    - Setup works in Testing. To publish, open **Audience** and click
      **Publish App**.
    - Mirage trades the refresh token for short-lived access tokens on its
      own.
    - A refresh token can still be revoked or expire; sign in again when that
      happens. See
      [Google's token expiration notes](https://developers.google.com/identity/protocols/oauth2#expiration).
  </Accordion>
  <Accordion title="Troubleshooting">
    | Issue | Fix |
    | --- | --- |
    | 403 during the OAuth flow | Add the account as a test user under **Audience** |
    | No `refresh_token` in the reply | Keep `access_type=offline` and `prompt=consent` in the URL |
    | Token exchange fails | `redirect_uri` must match exactly in the URL and the `curl` |
    | Refresh token stops after 7 days | Publish the app under **Audience**, or sign in again while testing |
    | The code fails a second time | Codes are single-use: sign in again |
  </Accordion>
</AccordionGroup>

export GOOGLE_CLIENT_ID=123456789-abc.apps.googleusercontent.com
export GOOGLE_CLIENT_SECRET=GOCSPX-...
export GOOGLE_REFRESH_TOKEN=1//0...

  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.gdocs import GDocsConfig, GDocsVFS
    from mirage.vfs.gdrive import GoogleDriveConfig, GoogleDriveVFS
    from mirage.vfs.gmail import GmailConfig, GmailVFS
    from mirage.vfs.gsheets import GSheetsConfig, GSheetsVFS
    from mirage.vfs.gslides import GSlidesConfig, GSlidesVFS

    creds = dict(
        client_id=os.environ["GOOGLE_CLIENT_ID"],
        client_secret=os.environ["GOOGLE_CLIENT_SECRET"],
        refresh_token=os.environ["GOOGLE_REFRESH_TOKEN"],
    )
    ws = Workspace(
        {
            "/gdrive": GoogleDriveVFS(GoogleDriveConfig(**creds)),
            "/gdocs": GDocsVFS(GDocsConfig(**creds)),
            "/gsheets": GSheetsVFS(GSheetsConfig(**creds)),
            "/gslides": GSlidesVFS(GSlidesConfig(**creds)),
            "/gmail": GmailVFS(GmailConfig(**creds)),
        },
        mode=MountMode.READ,
    )
    result = await ws.shell("ls /gdocs/owned")
    print(await result.stdout_str())
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import {
      GDocsVFS,
      GmailVFS,
      GoogleDriveVFS,
      GSheetsVFS,
      GSlidesVFS,
      MountMode,
      Workspace,
    } from '@struktoai/mirage-node'

    const creds = {
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
      refreshToken: process.env.GOOGLE_REFRESH_TOKEN!,
    }
    const ws = new Workspace(
      {
        '/gdrive': new GoogleDriveVFS(creds),
        '/gdocs': new GDocsVFS(creds),
        '/gsheets': new GSheetsVFS(creds),
        '/gslides': new GSlidesVFS(creds),
        '/gmail': new GmailVFS(creds),
      },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /gdocs/owned')
    console.log(result.stdoutText)
    ```

## Layout

```text
/gdrive/
  Projects/
    roadmap.gsheet.json
    spec.pdf
  Engineering/
/gdocs/
  owned/
    2026-11-14_Meeting_Notes__1Xk9rT2bQ.gdoc.json
  shared/
/gsheets/
  owned/
  shared/
/gslides/
  owned/
  shared/
/gmail/
  INBOX/
    2026-11-16/
      Invoice_November__18c2f9a4b7e3d1a0.gmail.json
      Invoice_November__18c2f9a4b7e3d1a0/
        invoice.pdf
```

- `/gdrive` mirrors My Drive plus one folder per Shared Drive. Docs, Sheets
  and Slides there read as `.gdoc.json`, `.gsheet.json` and `.gslide.json`.
- `/gdocs`, `/gsheets` and `/gslides` split files into `owned/` and `shared/`,
  named `<date>_<title>__<id>`, holding the API's JSON.
- `/gmail` is read only: one folder per label and day, a `.gmail.json` per
  message and a folder of its attachments.

## Sample runs

```bash
$ ls /gdrive/Projects
roadmap.gsheet.json
spec.pdf
```

```bash
$ jq -r '.sheets[].properties.title' /gdrive/Projects/roadmap.gsheet.json
Q4
Backlog
```

```bash
$ jq -r '.from.email, .subject' /gmail/INBOX/2026-11-16/Invoice_November__18c2f9a4b7e3d1a0.gmail.json
billing@example.com
Invoice November
```

On a `write` mount, Drive takes `cp`, `mv`, `rm`, `mkdir` and `tee` on regular
files; a Docs, Sheets or Slides file is read only as bytes, and `/gdocs`,
`/gsheets` and `/gslides` take `mv` (rename) and `rm`. Edit their content with
the [`gws`](/home/setup/cli/gws) CLI, which also covers Forms.
