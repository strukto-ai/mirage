Every IMAP folder becomes a folder of days, with one JSON file per message and
a folder of its attachments. Sending goes through SMTP with the `himalaya` CLI.

## Setup

The mailbox needs password-authenticated IMAP (reading) and SMTP (sending).
Most providers want an app password instead of the account password.

<Warning>
Microsoft 365 is unsupported: it requires OAuth for IMAP, and the Email VFS
accepts only passwords.
</Warning>

| Provider | IMAP host | IMAP port | SMTP host | SMTP port |
| --- | --- | --- | --- | --- |
| Yahoo | `imap.mail.yahoo.com` | 993 | `smtp.mail.yahoo.com` | 587 |
| Fastmail | `imap.fastmail.com` | 993 | `smtp.fastmail.com` | 587 |
| iCloud | `imap.mail.me.com` | 993 | `smtp.mail.me.com` | 587 |
| ProtonMail | `127.0.0.1` | 1143 | `127.0.0.1` | 1025 |
| Self-hosted | the server's hostname | 993 | the server's hostname | 587 |

<AccordionGroup>
  <Accordion title="Create an app password">
    **Yahoo:** open [Account Security](https://login.yahoo.com/account/security),
    select **Create app password** under **External connections**, name it
    (for example `Mirage`), select **Generate password** and copy it.

    **Fastmail:** open **Settings**, **Privacy & Security**, then
    **Manage app passwords and access** and **New app password**. Keep the
    **Mail, Contacts & Calendars** access, select **Generate password** and copy
    it. Fastmail Basic plans have no IMAP or SMTP access.

    **iCloud:** sign in at [account.apple.com](https://account.apple.com), open
    **Sign-In and Security**, **App-Specific Passwords**, select
    **Generate an app-specific password** and copy it. The Apple Account needs
    two-factor authentication.

    **ProtonMail:** run [Proton Mail Bridge](https://proton.me/mail/bridge)
    locally and use the credentials it shows.

    **Self-hosted or other:** use the mail account's password, or whatever the
    server requires.
  </Accordion>
</AccordionGroup>

```bash
export IMAP_HOST=imap.fastmail.com
export SMTP_HOST=smtp.fastmail.com
export EMAIL_USERNAME=alice@fastmail.com
export EMAIL_PASSWORD=...
```

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /email:
        vfs: email
        mode: read
        config:
          imap_host: ${IMAP_HOST}
          smtp_host: ${SMTP_HOST}
          username: ${EMAIL_USERNAME}
          password: ${EMAIL_PASSWORD}
    ```

    ```bash
    mirage workspace create workspace.yaml --id mail
    mirage shell -w mail -c 'ls /email'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.email import EmailConfig, EmailVFS

    config = EmailConfig(
        imap_host=os.environ["IMAP_HOST"],
        smtp_host=os.environ["SMTP_HOST"],
        username=os.environ["EMAIL_USERNAME"],
        password=os.environ["EMAIL_PASSWORD"],
    )
    ws = Workspace({"/email": EmailVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /email")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { EmailVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      {
        '/email': new EmailVFS({
          imapHost: process.env.IMAP_HOST!,
          smtpHost: process.env.SMTP_HOST!,
          username: process.env.EMAIL_USERNAME!,
          password: process.env.EMAIL_PASSWORD!,
        }),
      },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /email')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/email/
  INBOX/
    2026-11-16/
      Q4_planning_agenda__4812.email.json
      Q4_planning_agenda__4812/
        agenda.pdf
  Sent/
    2026-11-16/
      ...
```

- A folder keeps its IMAP name; a day comes from the message's `Date` header.
- A message file is `<subject>__<uid>.email.json` with a sanitized subject, so
  `ls` the day rather than build the name.
- Each folder lists its newest 200 messages; `max_messages` changes that.

```bash
$ ls /email
Drafts
INBOX
Sent
Trash
```

```bash
$ ls /email/INBOX/2026-11-16

```

```bash
$ jq -r '.from.email, .subject' /email/INBOX/2026-11-16/Q4_planning_agenda__4812.email.json
bob@example.com
Q4 planning: agenda
```

The mount is read-only. Send, reply and forward with the
[`himalaya`](/home/setup/cli/himalaya) CLI, which uses the SMTP settings.

## Troubleshooting

- **Authentication failed:** check that the provider accepts passwords for
  IMAP and SMTP, and whether it requires an app password.
- **Connection refused:** check the host and port; some networks block 993 or
  587. For ProtonMail, make sure Bridge is running.
- **SSL handshake failed:** check the host and the implicit-TLS IMAP port
  (commonly 993). `use_ssl: false` opens a plain connection with no STARTTLS
  upgrade.
