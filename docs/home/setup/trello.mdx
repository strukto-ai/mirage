Every workspace the token's member belongs to becomes a folder of boards. A
board holds its members, labels and lists; each card is a folder with
`card.json` and its comments as `comments.jsonl`.

## Setup

Get an API key from a Power-Up, authorize a token for it, and export both:

<AccordionGroup>
  <Accordion title="Get the API key and token">
    1. Open the [Power-Up admin portal](https://trello.com/apps/admin) and
       create a Power-Up, or open an existing one.
    2. On its **Trello Auth** tab, click **Generate a new API Key** and copy
       the key.
    3. Click the **Token** link next to the key, or open this URL with the
       key filled in:

       ```text
       https://trello.com/1/authorize?expiration=never&scope=read,write&response_type=token&key=YOUR_API_KEY
       ```

    4. Click **Allow** and copy the token. Keep it secret: with the key it
       reaches the whole account.

    `scope=read` is enough for the mount; the [`trello`](/home/setup/cli/trello)
    CLI needs `write`. `expiration` also takes `1hour`, `1day` or `30days`.
  </Accordion>
</AccordionGroup>

```bash
export TRELLO_API_KEY=...
export TRELLO_API_TOKEN=...
```

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /trello:
        vfs: trello
        mode: read
        config:
          api_key: ${TRELLO_API_KEY}
          api_token: ${TRELLO_API_TOKEN}
    ```

    ```bash
    mirage workspace create workspace.yaml --id trello
    mirage shell -w trello -c 'ls /trello/workspaces'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.trello import TrelloConfig, TrelloVFS

    config = TrelloConfig(
        api_key=os.environ["TRELLO_API_KEY"],
        api_token=os.environ["TRELLO_API_TOKEN"],
    )
    ws = Workspace({"/trello": TrelloVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /trello/workspaces")
    print(await result.stdout_str())
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { MountMode, TrelloVFS, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      {
        '/trello': new TrelloVFS({
          apiKey: process.env.TRELLO_API_KEY!,
          apiToken: process.env.TRELLO_API_TOKEN!,
        }),
      },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /trello/workspaces')
    console.log(result.stdoutText)
    ```
  </Tab>
</Tabs>

## Layout

```text
/trello/
  workspaces/
    Acme_Product__<workspace-id>/
      workspace.json
      boards/
        Sprint_Board__<board-id>/
          board.json
          members/
            Alice_Chen__<member-id>.json
          labels/
            bug__<label-id>.json
          lists/
            Doing__<list-id>/
              list.json
              cards/
                Fix_login_redirect__<card-id>/
                  card.json
                  comments.jsonl
```

- Names are sanitized and end in `__<id>`; `ls` the parent to find them.
- `workspace_id` or `board_ids` limits the mount to one workspace or some
  boards.
- The same key and token register the [`trello`](/home/setup/cli/trello) CLI.

[`trello`](/home/setup/cli/trello) CLI.
