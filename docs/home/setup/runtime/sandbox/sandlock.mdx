Sandlock confines native processes with Landlock and seccomp. It is
available in the Python and TypeScript/Node SDKs on Linux. Install the `sandlock` CLI
on `PATH`; Mirage needs no extra package.

Continue with [Sandlock setup](/python/runtime/sandbox/sandlock).
