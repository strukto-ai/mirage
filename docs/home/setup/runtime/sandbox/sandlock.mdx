Sandlock confines native processes on Linux with Landlock and seccomp, in
the Python SDK and `@struktoai/mirage-node`. Install the `sandlock` CLI on
`PATH`; Mirage needs no extra package. Details:
[Python](/python/runtime/sandbox/sandlock) ·
[TypeScript](/typescript/runtime/sandbox/sandlock).
