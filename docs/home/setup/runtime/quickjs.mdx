QuickJS is the default runtime for `node` and `js` in both SDKs. It supports
ES2023 for small scripts and pipe transforms, with access to workspace files
under the same permissions as shell commands. Despite the command name,
it does not provide Node.js APIs, npm packages or network access.

Both SDKs run the same engine, the WASI build of
[quickjs-ng](https://github.com/quickjs-ng/quickjs), so a script answers
the same in either.

## Installation

Download `qjs-wasi.wasm` from a
[quickjs-ng release](https://github.com/quickjs-ng/quickjs/releases) and
point the runtime's `home`, or `MIRAGE_QUICKJS_HOME`, at its directory.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```bash
    pip install 'mirage-ai[quickjs]'
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    No package to add: each run executes in a worker. In a browser, `home`
    is the URL of the folder holding `qjs-wasi.wasm`, and the page needs the
    same [worker setup](/typescript/runtime/python#worker-and-browser-setup)
    as Pyodide.
  </Tab>
</Tabs>

## Usage

QuickJS is in the default runtimes, so `node` works once its engine is found.
To list it yourself:

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import RAMVFS, MountMode, Workspace
    from mirage.runtime.js import QuickJsRuntime

    ws = Workspace(
        {"/data": RAMVFS()},
        mode=MountMode.EXEC,
        runtimes=[QuickJsRuntime(config={"home": "/path/to/quickjs"})],
    )
    await ws.shell("node -e 'console.log(1 + 1)'")
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { buildRuntime, MountMode, RAMVFS, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      { '/data': new RAMVFS() },
      {
        mode: MountMode.EXEC,
        runtimes: [buildRuntime('quickjs', { config: { home: '/path/to/quickjs' } })],
      },
    )
    await ws.shell("node -e 'console.log(1 + 1)'")
    ```
  </Tab>
  <Tab title="YAML" icon="file-code">
    ```yaml
    mode: exec
    runtimes:
      - name: quickjs
        config:
          home: /path/to/quickjs
    mounts:
      /data:
        vfs: ram
    ```
  </Tab>
</Tabs>

## JavaScript compatibility

`std` and `os` are globals, as `qjs --std` gives them. Examples assume a
writable `/data` mount. Mount modes and permissions still apply.

### `std.open()`

`std.open(path, mode, errorObj)` returns `null` on failure and sets
`errorObj.errno`. A read-only mount refuses modes that write. The modes are
`r`, `w`, `a` and `x`, with the `b` and `+` modifiers; for example, `rb`
combines `r` and `b`.

<AccordionGroup>
  <Accordion title="Example: append to a workspace file" id="std-open-example">
    ```javascript
    const error = {};
    const file = std.open("/data/log.txt", "a", error);
    if (file === null) {
      throw new Error("Open failed: " + error.errno);
    }
    try {
      file.puts("Job completed.\n");
    } finally {
      file.close();
    }
    ```
  </Accordion>
  <Accordion title="Limitations" id="std-open-limitations">
    | API or behavior | Limitation |
    | --- | --- |
    | `x` | Exclusive-creation modifier: use `wx` or `ax`; `x` alone is not a valid mode. |
    | Write modes | A read-only mount refuses modes that write. |
  </Accordion>
</AccordionGroup>

### File objects

`readAsString()`, `read()`, `getline()`, `seek()`, `tell()`, `tello()`,
`eof()`, `puts()`, `write()`, `printf()`, `flush()` and `close()`.

<AccordionGroup>
  <Accordion title="Example: write, seek and read a file" id="file-objects-example">
    ```javascript
    const file = std.open("/data/example.txt", "w+");
    if (file === null) {
      throw new Error("Could not open example.txt");
    }
    try {
      file.puts("hello\n");
      file.seek(0, std.SEEK_SET);
      print(file.readAsString());
    } finally {
      file.close();
    }
    ```
  </Accordion>
  <Accordion title="Limitations" id="file-objects-limitations">
    | API or behavior | Limitation |
    | --- | --- |
    | `file.puts()`, `file.write()`, `file.flush()` | Reach the mount at `close`, or when the run ends; a write the mount refuses fails the `close`. |
  </Accordion>
</AccordionGroup>

### `std`

`getenv()`, `setenv()`, `getenviron()`, `exit()`, `loadFile()`,
`writeFile()`, `printf()`, `fdopen()`, `strerror()` and `Error`. Environment
variables come from the Mirage session. `std.loadFile()` returns `null` when
reading fails.

<AccordionGroup>
  <Accordion title="Example: read a session environment variable" id="std-example">
    ```javascript
    const jobId = std.getenv("JOB_ID");
    std.printf("Job: %s\n", jobId === undefined ? "unknown" : jobId);
    ```
  </Accordion>
  <Accordion title="Limitations" id="std-limitations">
    | API or behavior | Limitation |
    | --- | --- |
    | `std.popen()` | ✗ |
    | `std.tmpfile()` | ✗ |
  </Accordion>
</AccordionGroup>

### Standard streams

`std.in` receives the command's piped input as it arrives, and `std.in`,
`std.out` and `std.err` are descriptors 0 to 2.

<AccordionGroup>
  <Accordion title="Example: forward piped input" id="standard-streams-example">
    ```javascript
    const input = std.in.readAsString();
    std.out.puts(input);
    std.err.puts("Input forwarded.\n");
    ```
  </Accordion>
  <Accordion title="Limitations" id="standard-streams-limitations">
    | API or behavior | Limitation |
    | --- | --- |
    | `std.out.printf()`, `std.err.printf()` | C format; return the UTF-8 bytes written. Unlike `printf` on an opened FILE. |
  </Accordion>
</AccordionGroup>

### `os`

`readdir()`, `stat()`, `mkdir()`, `remove()`, `utimes()`, `rename()`,
`getcwd()`, `chdir()`, `open()`, `read()`, `write()`, `seek()`, `close()`,
`sleep()`, `setTimeout()` and `platform`.

<AccordionGroup>
  <Accordion title="Example: list a workspace directory" id="os-example">
    ```javascript
    const [names, errno] = os.readdir("/data");
    if (errno !== 0) {
      throw new Error("Read directory failed: " + errno);
    }
    console.log(names);
    ```
  </Accordion>
  <Accordion title="Limitations" id="os-limitations">
    | API or behavior | Limitation |
    | --- | --- |
    | `os.lstat()` | ✗ |
    | `os.symlink()` | ✗ |
    | `os.readlink()` | ✗ |
    | `os.realpath()` | ✗ |
    | `os.exec()` | ✗ |
    | `os.readdir()`, `os.stat()` | Return `[value, errno]`. `mode` from `os.stat()` has only the file type bits. |
    | `os.remove()` | `os.remove` also removes an empty directory. |
    | `os.rename()` | `-75` (`EXDEV`) across mounts. |
    | `os.getcwd()`, `os.chdir()` | The shell's working directory; a change lasts for the run. |
    | `os.platform` | `wasi`. |
  </Accordion>
</AccordionGroup>

### Runtime globals

`scriptArgs`, the invocation name and arguments, and `atob()`, `btoa()` and
`queueMicrotask()`.

<Accordion title="Example: read arguments and encode text" id="globals-example">
  ```javascript

  const encoded = btoa("hello");
  print(encoded);
  print(atob(encoded));
  ```

## Notes

- `-e <code>` runs the argument, a file runs a mounted script, and with
  neither, piped input is the program. A `.mjs` file runs as an ES module;
  `.js` and `-e` run as classic scripts, and `-m` forces module mode.
- `console.log` and `print` add a newline; `std.out.puts` and `std.err.puts`
  write raw.
- An error in async code fails the run.
- QuickJS cannot reach host files or the network. `command_limits` bound its
  time and output. Run untrusted or heavy code in a
  [sandbox](/home/setup/runtime/sandbox).
