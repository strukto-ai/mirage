A runtime is the interpreter that runs `python3` and `node` when a line has no
installed one to call. Every line runs on a [machine](/home/setup/machine/overview),
and who answers `python3 app.py` depends on which:

| Machine | What runs `python3 app.py` |
| --- | --- |
| [`host`](/home/setup/machine/host) | the host's own `python3` |
| a [container or sandbox](/home/setup/machine/overview#providers), such as Docker or E2B | the `python3` installed in it |
| [`in_process`](/home/setup/machine/in_process), the Mirage process itself | a runtime, an interpreter Mirage embeds |

The machine is where a program runs; the runtime is what runs it when that
place is Mirage. Its file calls reach the workspace's mounts directly, under
the same mount modes, permissions and policies as `cat`.

Mirage ships these:

| Runtime | Runs | SDK |
| --- | --- | --- |
| <img noZoom src="/images/pydantic-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[Monty](/home/setup/runtime/monty) | `python3`, a Python subset | both |
| <img noZoom src="/images/webassembly-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[WASI](/home/setup/runtime/wasi) | `python3`, CPython in WebAssembly | Python |
| <Icon icon="python" size={14} /> [Pyodide](/home/setup/runtime/pyodide) | `python3`, CPython with packages such as numpy | TypeScript |
| <Icon icon="js" size={14} /> [QuickJS](/home/setup/runtime/quickjs) | `node` and `js`, with Node.js's common APIs | both, not on Cloudflare Workers |

Name the runtime on an `in_process` entry:

```yaml
machines:
  py:
    provider: in_process
    runtime: monty
  js:
    provider: in_process
    runtime: quickjs
```

A runtime takes only its own interpreter's names (`@python` or `@js` by
default); see [Captures](/home/setup/machine/overview#captures). A
[`host`](/home/setup/machine/host) or a
[provider](/home/setup/machine/overview#providers) takes no runtime: it runs
the `python3` or `node` installed on it.

## Script CLIs

A [script CLI](/home/configuration/workspace#cli-entries) names its
`machine`, `in_process` or `host`, and may name a runtime there. It runs on
the first entry of that machine that runs its language, or on the runtime it
names, whichever machine a line's `python3` goes to.

```yaml
clis:
  pager:
    script: pager.py
    machine: in_process
  report:
    script: report.js
    machine: in_process
    runtime: quickjs
```

A script whose machine has no entry for its language exits 127 and names the
workspace's machines: `pager: no in_process machine runs python scripts
(workspace machines: 'js')`.
