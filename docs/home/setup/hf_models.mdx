A [Hugging Face model](https://huggingface.co/models) repo becomes a read-only
folder of its files. Configs, tokenizers and cards read at once; weights stream
only when a command reads them.

## Setup

Public models need no token. A gated or private model needs a Hugging Face
access token:

1. For a gated model, open its page on the Hub, accept the conditions and wait
   for access to be granted.
1. At [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens),
   click **New token** and create a `read` token, or a fine-grained token with
   read access to that model.
1. Add `token: ${HF_TOKEN}` to the YAML config.

```bash
export HF_TOKEN=hf_...
```

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /model:
        vfs: hf_models
        mode: read
        config:
          repo_id: sapientinc/HRM-Text-1B
    ```

    ```bash
    mirage workspace create workspace.yaml --id model
    mirage shell -w model -c 'ls /model'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.hf_models import HfModelsConfig, HfModelsVFS

    config = HfModelsConfig(
        repo_id="sapientinc/HRM-Text-1B",
        token=os.environ.get("HF_TOKEN"),
    )
    ws = Workspace({"/model": HfModelsVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /model")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { HfModelsVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      {
        '/model': new HfModelsVFS({
          repoId: 'sapientinc/HRM-Text-1B',
          token: process.env.HF_TOKEN,
        }),
      },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /model')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/model/
  LICENSE
  README.md
  banner.jpg
  benchmark_scatter.png
  config.json
  model.safetensors
  tokenizer.json
  tokenizer_config.json
```

- Files keep their repo paths. `repo_id` is `namespace/name`, or a bare name
  under the token's owner.
- `revision` pins a branch, tag or commit (default `main`); `key_prefix` mounts
  one folder of the repo.
- `ls` and `stat` never download a file; `sha256sum` on an LFS file answers with
  the hash the Hub keeps.

## Sample runs

```bash
$ ls -lh /model
total ?
-rw-r--r-- 1 - -  12K May 18  2026 LICENSE
-rw-r--r-- 1 - - 7.6K May 21 05:57 README.md
-rw-r--r-- 1 - - 865K Sep  4 08:30 banner.jpg
-rw-r--r-- 1 - - 404K May 18  2026 benchmark_scatter.png
-rw-r--r-- 1 - -  619 May 21 05:57 config.json
-rw-r--r-- 1 - - 2.3G May 18  2026 model.safetensors
-rw-r--r-- 1 - - 4.6M May 18  2026 tokenizer.json
-rw-r--r-- 1 - -  326 May 18  2026 tokenizer_config.json
```

```bash
$ jq -r '.architectures[0], .hidden_size' /model/config.json
HrmTextForCausalLM
1536
```

```bash
$ stat -c '%n %s' /model/model.safetensors
/model/model.safetensors 2365606568
```

The mount is read-only: a Hub write is a commit, so `echo >`, `rm`, `cp` and
`mv` are refused. The [`hf` CLI](/home/setup/cli/hf) downloads a copy and
uploads changes back as one commit.
