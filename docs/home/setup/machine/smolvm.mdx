The `smolvm` machine provider reaches a running
[smolvm](https://smolmachines.com) microVM, by name, and the `remote` runtime
runs captured programs in it. Each machine has its own guest kernel, on macOS, Linux and
Windows. You create and start the machine; Mirage only runs programs in it.
Python SDK and Node.

## Installation

Install the `smolvm` CLI. Create and start a machine from an image that
has what [connecting the workspace](#connecting-the-workspace) needs:

```bash
smolvm machine create --net --name mirage-box --image my-mirage-image
smolvm machine start --name mirage-box
```

## Usage

`captures` defaults to [`@external`](/home/setup/runtime/overview#captures):
every program Mirage does not have itself. Name `@python` to run
Python in the machine too.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import RAMVFS, MountMode, Workspace
    from mirage.runtime.machine import RemoteRuntime

    ws = Workspace(
        {"/data": RAMVFS()},
        mode=MountMode.EXEC,
        machines={"box": {"provider": "smolvm", "machine": "mirage-box"}},
        runtimes=[RemoteRuntime(["@python", "@external"], machine="box")],
    )
    await ws.shell("python3 -c 'print(1 + 1)'")
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { MountMode, RemoteRuntime, RAMVFS, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      { '/data': new RAMVFS() },
      {
        mode: MountMode.EXEC,
        machines: { box: { provider: 'smolvm', machine: 'mirage-box' } },
        runtimes: [new RemoteRuntime({ captures: ['@python', '@external'], machine: 'box' })],
      },
    )
    await ws.shell("python3 -c 'print(1 + 1)'")
    ```
  </Tab>
  <Tab title="YAML" icon="file-code">
    ```yaml
    mode: exec
    machines:
      box:
        provider: smolvm
        machine: mirage-box
    runtimes:
      - name: remote
        captures: ["@python", "@external"]
        machine: box
    mounts:
      /data:
        vfs: ram
    ```
  </Tab>
</Tabs>

## Connecting the workspace

Pick a [`mount_type`](/home/setup/machine/overview#connecting-the-workspace). With `ssh`, the guest needs `sshfs`. With `fuse`,
put `sandbox.yaml` in the machine, in its image or a directory passed with
`--volume`, and start Mirage:

```bash
smolvm machine exec --name mirage-box -- mirage workspace create /tmp/sandbox.yaml
```

## Notes

- Host files reach the machine only through directories passed with
  `--volume` at boot.
- The machine must be `running`. Start a `stopped` or `created` machine,
  or clone a `frozen` machine before using it. Mirage cannot run commands
  while a machine is `unreachable`.
- Lines sent to one machine share its files and processes. Give each tenant
  its own machine.
