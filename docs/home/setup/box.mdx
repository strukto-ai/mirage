A Box account, or one folder of it, becomes a folder tree of its real files,
served as raw bytes.

## Setup

Box takes a developer token (quickest), an OAuth refresh token (long-running),
a PKCE refresh token (browsers) or client credentials (a service account).

### Quick Start: Developer Token (60 minutes, no OAuth)

1. In the [Developer Console](https://app.box.com/developers/console), click
   **New App**, pick the **User** type (OAuth 2.0) and click **Create**.
1. On the **Configuration** tab, under **Developer Token**, click **Generate
   Developer Token** and copy it.

The token lasts 60 minutes and cannot be renewed by code: generate a new one
by hand, or use a refresh token below for long runs.

```bash
export BOX_DEVELOPER_TOKEN=...
```

<AccordionGroup>
  <Accordion title="OAuth refresh token (long-running)">
    1. Create a **User** app as above. On its **Configuration** tab:
       - Under **OAuth 2.0 Redirect URIs**, add `http://localhost:1` (and any
         browser or production callback).
       - Under **Application Scopes**, check **Read all files and folders
         stored in Box**, plus **Write all files and folders stored in Box**
         for a write mount.
       - Copy the **Client ID** and **Client Secret**, then **Save Changes**.
    1. In an enterprise, a Box admin may have to enable the app before it
       issues tokens. Personal accounts skip this.
    1. Open this URL with `YOUR_CLIENT_ID` replaced, sign in and click **Grant
       access**:

       ```text
       https://account.box.com/api/oauth2/authorize?response_type=code&client_id=YOUR_CLIENT_ID&redirect_uri=http://localhost:1
       ```

    1. The browser goes to `http://localhost:1/?code=...`, a page that does
       not load. The code is valid for 30 seconds, so exchange it at once:

       ```bash
       curl https://api.box.com/oauth2/token \
         -d "code=THE_CODE" \
         -d "grant_type=authorization_code" \
         -d "client_id=YOUR_CLIENT_ID" \
         -d "client_secret=YOUR_CLIENT_SECRET" \
         -d "redirect_uri=http://localhost:1"
       ```

    The reply holds `refresh_token`. Set `client_id`, `client_secret` and
    `refresh_token` (`BOX_CLIENT_ID`, `BOX_CLIENT_SECRET`, `BOX_REFRESH_TOKEN`).
  </Accordion>
  <Accordion title="Service account (client credentials)">
    1. In the Developer Console, click **New App**, pick the **Server** type
       and keep **Client Credentials Grant**.
    1. A Box admin authorizes it in the
       [Admin Console](https://app.box.com/master/settings/custom) under
       **Platform** > **Platform Apps**, adding it by Client ID. Free developer
       accounts are authorized on creation.
    1. Set `client_id`, `client_secret` and `enterprise_id`
       (`BOX_CLIENT_ID`, `BOX_CLIENT_SECRET`, `BOX_ENTERPRISE_ID`).

    Tokens are minted for the app's service account and fetched again on
    expiry, with no refresh token. The service account starts with an empty
    root: share folders with its email address to see them.
  </Accordion>
  <Accordion title="Browser sign-in with PKCE (no client secret)">
    The TypeScript `BoxVFS` from `@struktoai/mirage-browser` takes `clientId`
    and `refreshToken` with no secret.

    1. Add `http://localhost:5173/vfs/box/box_pkce.html` to **OAuth 2.0
       Redirect URIs** and `http://localhost:5173` to the CORS origins below.
    1. Set only `BOX_CLIENT_ID` in `.env.development`.
    1. Run `pnpm dev` in `examples/browser/` and open that URL.
    1. Click **Connect Box**.

    The example saves each rotated refresh token to `localStorage` through
    `onRefreshTokenRotated`, so a reload needs no new sign-in.
  </Accordion>
  <Accordion title="Token lifetime and troubleshooting">
    | Token | Lifetime |
    | --- | --- |
    | Developer token | 60 minutes, no refresh |
    | Access token | About 60 minutes, renewed 5 minutes before it expires |
    | Refresh token | Single use, valid 60 days; each refresh returns a new one |

    | Issue | Fix |
    | --- | --- |
    | `400 invalid_grant` on the exchange | The code is single-use and lasts 30 seconds: sign in again |
    | `403 access_denied` | A Box admin has not enabled the app |
    | `401` after a restart | The refresh token was rotated: persist the new one |
    | Browser CORS error | The origin must match exactly (no trailing slash, `http` vs `https`) |
    | `not_found` on a nested path | `ls` the parent first and use a name from the list |
  </Accordion>
</AccordionGroup>

Box rotates the refresh token on every refresh. Mirage keeps the newest one in
memory; pass `on_refresh_token_rotated` (TypeScript `onRefreshTokenRotated`)
to persist it across restarts.

### CORS notes

A browser can call Box only from origins listed under **CORS Domains** (some
consoles say **Allowed Origins**) on the app's **Configuration** tab. Each
origin must match exactly: no trailing slash, and the protocol counts.

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /box:
        vfs: box
        mode: read
        config:
          access_token: ${BOX_DEVELOPER_TOKEN}
    ```

    ```bash
    mirage workspace create workspace.yaml --id box
    mirage shell -w box -c 'ls /box'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.box import BoxConfig, BoxVFS

    config = BoxConfig(access_token=os.environ["BOX_DEVELOPER_TOKEN"])
    ws = Workspace({"/box": BoxVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /box")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { BoxVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      { '/box': new BoxVFS({ accessToken: process.env.BOX_DEVELOPER_TOKEN! }) },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /box')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/box/
  Contracts/
    2026_MSA.pdf
  Roadmap.gdoc
  Team Notes.boxnote
  data.csv
```

- Every item keeps its name and raw bytes. `.boxnote` and `.boxcanvas` are
  JSON; `.gdoc`, `.gsheet` and `.gslides` are the Office zips Box stores (mount
  [Google Drive](/home/setup/google) for an editable view).
- Box addresses items by numeric ID; the mount resolves each path one folder
  level at a time and caches the result.
- `root_folder_id` (from `box.com/folder/<id>`) mounts one folder and survives
  renames and moves.

## Sample runs

```bash
$ ls /box
Contracts
Roadmap.gdoc
Team Notes.boxnote
data.csv
```

```bash
$ jq -r '.. | .text? // empty' "/box/Team Notes.boxnote"
Weekly sync
Ship the importer by Friday.
```

```bash
$ head -n 2 /box/data.csv
date,region,revenue
2026-11-01,us-east,1250
```

On a `write` mount, `tee`, `cp`, `mv`, `rm` and `mkdir` change Box; the app
needs the **Write all files and folders stored in Box** scope.
