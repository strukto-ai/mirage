Each service a Jaeger query service knows becomes a folder with its operations
and one JSON file per trace. Point `host` at an existing query service's base
URL, such as `http://localhost:16686`; it needs no credentials.

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /jaeger:
        vfs: jaeger
        mode: read
        config:
          host: http://localhost:16686
    ```

    ```bash
    mirage workspace create workspace.yaml --id jg
    mirage shell -w jg -c 'ls /jaeger/services'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import MountMode, Workspace
    from mirage.vfs.jaeger import JaegerConfig, JaegerVFS

    config = JaegerConfig(host="http://localhost:16686")
    ws = Workspace({"/jaeger": JaegerVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /jaeger/services")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { JaegerVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      { '/jaeger': new JaegerVFS({ host: 'http://localhost:16686' }) },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /jaeger/services')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/jaeger/
  services/
    <service>/
      operations.json
      traces/
        <trace-id>.json
```

- `traces/` lists the newest 100 traces of the service; change it with
  `default_trace_limit` in Python or YAML, or `defaultTraceLimit` in
  TypeScript. An older trace is still readable by its id.
- `default_from_timestamp` and `default_to_timestamp` bound the listing.
- A trace file is the trace document Jaeger returns, with `traceID`, `spans`,
  `processes` and `warnings`.

## Sample runs

```bash
$ ls /jaeger/services
checkout
```

```bash
$ jq -c '.[]' /jaeger/services/checkout/operations.json
{"name":"SELECT carts","spanKind":"client"}
{"name":"POST /cart","spanKind":"server"}
{"name":"GET /cart","spanKind":"server"}
```

```bash
$ jq -r '.spans[] | "\(.operationName) \(.duration)"' /jaeger/services/checkout/traces/58ca65951c47a64c90af3c8cfabc6e96.json
POST /cart 42000
SELECT carts 7000
```

The mount is read-only.
