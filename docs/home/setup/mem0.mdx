The memories of one [Mem0 Platform](https://docs.mem0.ai) scope become a flat
folder with one JSON file per memory.

## Setup

1. Sign in to the [Mem0 dashboard](https://app.mem0.ai) and open the **API
   Keys** page under **Settings**.
1. Create a key and copy it. The organization and project come from the key.
1. Pick the scope to mount: one `user_id`, `agent_id` or `run_id`.

```bash
export MEM0_API_KEY=m0-...
export MEM0_USER_ID=alex
```

- Set exactly one scope. A pair such as `user_id` and `agent_id` is refused:
  Mem0 splits a memory added with both into separate memories, so a combined
  filter matches nothing.
- An agent or run scope sets `agent_id` or `run_id` instead of `user_id`.
- `host` (default `https://api.mem0.ai`) points at another Mem0 API host.
- Keep the key out of public browser bundles; call Mem0 from a server instead.

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /memory:
        vfs: mem0
        mode: read
        config:
          api_key: ${MEM0_API_KEY}
          user_id: ${MEM0_USER_ID}
    ```

    ```bash
    mirage workspace create workspace.yaml --id mem
    mirage shell -w mem -c 'ls /memory'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.mem0 import Mem0Config, Mem0VFS

    config = Mem0Config(
        api_key=os.environ["MEM0_API_KEY"],
        user_id=os.environ["MEM0_USER_ID"],
    )
    ws = Workspace({"/memory": Mem0VFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /memory")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { Mem0VFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      {
        '/memory': new Mem0VFS({
          apiKey: process.env.MEM0_API_KEY!,
          userId: process.env.MEM0_USER_ID!,
        }),
      },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /memory')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/memory/
  6d1ba0fc-1f0c-495b-b5b1-9141b2674b37.json
  b52e7a19-0c4d-4a8e-9f3b-2d6c1e8a7f40.json
```

- A file holds the memory's full record: `memory`, `categories`, `metadata`,
  `created_at`, `updated_at` and the rest.
- `stat` reports `updated_at`, or `created_at` when unset, as the modified time.
- The [`search` CLI](/python/cli/search) runs Mem0's semantic search in the same
  scope.

## Sample runs

```bash
$ ls /memory
6d1ba0fc-1f0c-495b-b5b1-9141b2674b37.json
b52e7a19-0c4d-4a8e-9f3b-2d6c1e8a7f40.json
```

```bash
$ jq -r '.memory, .categories[0]' /memory/6d1ba0fc-1f0c-495b-b5b1-9141b2674b37.json
User's name is Alex, follows a vegetarian diet, allergic to nuts
personal_details
```

```bash
$ grep -rl allergic /memory
/memory/6d1ba0fc-1f0c-495b-b5b1-9141b2674b37.json
```

The mount is read-only.
