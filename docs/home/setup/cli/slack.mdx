Create tokens in [Slack setup](/home/setup/slack), then register them on an
existing `ws`.

Reaction commands need `reactions:read`/`reactions:write`, pin commands need
`pins:read`/`pins:write`, and `emoji-list` needs `emoji:read`. Reinstall the app
after changing scopes.

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    clis:
      slack:
        cli: slack
        machine: in_process
        config:
          token: ${SLACK_BOT_TOKEN}
          search_token: ${SLACK_USER_TOKEN}
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage.commands.cli.builtin.slack import SLACK
    from mirage.core.slack.config import SlackConfig

    config = SlackConfig(token="xoxb-...", search_token="xoxp-...")
    ws.register_cli("slack", SLACK, config)
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { SLACK } from '@struktoai/mirage-node'

    const config = { token: 'xoxb-...', searchToken: 'xoxp-...' }
    ws.registerCli('slack', SLACK, config)
    ```
  </Tab>
</Tabs>
