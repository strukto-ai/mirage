Mirage implements the [Tavily CLI](https://github.com/tavily-ai/cli) (`tvly`)
over the [Tavily API](https://docs.tavily.com): web search, page extraction,
site crawls and maps, and deep research, printed the way `tvly` prints to a
pipe.

Create an API key in the [Tavily dashboard](https://app.tavily.com), then
register it on an existing `ws`. Without a key, `search` and `extract` run
keyless within Tavily's rate-limit cap; `crawl`, `map` and `research` need one.

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    clis:
      tvly:
        cli: tvly
        machine: in_process
        config:
          api_key: ${TAVILY_API_KEY}
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage.commands.cli.builtin.tvly import TVLY
    from mirage.core.tavily.config import TavilyConfig

    config = TavilyConfig(api_key="tvly-...")
    ws.register_cli("tvly", TVLY, config)
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { TVLY } from '@struktoai/mirage-node'

    const config = { apiKey: 'tvly-...' }
    ws.registerCli('tvly', TVLY, config)
    ```
  </Tab>
</Tabs>
