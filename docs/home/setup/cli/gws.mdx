Mirage implements a subset of the [Google Workspace CLI (`gws`)](https://github.com/googleworkspace/cli).

Create OAuth credentials in [Google Workspace setup](/home/setup/google), then
register them on an existing `ws`.

Forms is CLI-only. Enable the Google Forms API and grant
`https://www.googleapis.com/auth/forms.body` to create or edit forms. Reading
responses needs `https://www.googleapis.com/auth/forms.responses.readonly`.
Creating forms inside a configured folder also needs the Drive API and scope.

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    clis:
      gws:
        cli: gws
        machine: in_process
        config:
          client_id: ${GOOGLE_CLIENT_ID}
          client_secret: ${GOOGLE_CLIENT_SECRET}
          refresh_token: ${GOOGLE_REFRESH_TOKEN}
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage.commands.cli.builtin.gws import GWS
    from mirage.core.google.config import GoogleConfig

    config = GoogleConfig(
        client_id="...", client_secret="...", refresh_token="..."
    )
    ws.register_cli("gws", GWS, config)
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { GWS } from '@struktoai/mirage-node'

    const config = { clientId: '...', clientSecret: '...', refreshToken: '...' }
    ws.registerCli('gws', GWS, config)
    ```
