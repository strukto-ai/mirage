Create a bot token in [Discord setup](/home/setup/discord), then register it on
an existing `ws`.

Grant Send Messages for `send`/`edit`/`poll` and Send Polls for `poll`.
Add Reactions is needed for `react`, Create Public Threads for `thread-create`,
and Manage Messages when deleting others' messages.

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    clis:
      discord:
        cli: discord
        machine: in_process
        config:
          token: ${DISCORD_BOT_TOKEN}
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage.commands.cli.builtin.discord import DISCORD
    from mirage.core.discord.config import DiscordConfig

    config = DiscordConfig(token="bot-token")
    ws.register_cli("discord", DISCORD, config)
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { DISCORD } from '@struktoai/mirage-node'

    const config = { token: 'bot-token' }
    ws.registerCli('discord', DISCORD, config)
    ```
  </Tab>
</Tabs>
