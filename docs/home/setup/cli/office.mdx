description: Set up the credential-free office CLI for Excel, Word and PowerPoint files with Python or TypeScript.
---

Mirage implements [OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)'s
`create`, `get`, `query`, `set`, `remove` and `batch` on `.xlsx` workbooks, and
`get` and `query` on `.docx` documents and `.pptx` decks, with OfficeCLI's
paths, selectors, `--prop` values and `--json` output. An edit
rewrites only what it changes; charts, styles, named ranges and validations stay
as they were.

`office` needs no account config and reads workbooks through existing mounts.
Register it on `ws`. Commands: [Python](/python/cli/office) ·
[TypeScript](/typescript/cli/office).

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage.commands.cli.builtin.office import OFFICE

    ws.register_cli("office", OFFICE)
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { OFFICE } from '@struktoai/mirage-node'

    ws.registerCli('office', OFFICE)
    ```
  </Tab>
</Tabs>
