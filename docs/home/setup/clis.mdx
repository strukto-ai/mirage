Mirage bundles ten command-line programs for its workspace shell. The
[host `mirage` CLI](/home/access/cli) connects to a workspace; these programs
run inside it. Each setup page includes Python and TypeScript registration.

Account CLIs use their own validated config and can run without a service
mount. Credentials can be reused with the corresponding VFS; mounting a
service does not register its CLI. `git` needs no account config and uses
repositories on workspace mounts.

All ten are available in Python and TypeScript on Node. TypeScript exports
`hf` and `himalaya` from `@struktoai/mirage-node`, and the other eight from
`@struktoai/mirage-core`.

Use `<program> --help` for its groups, `<program> <command> --help` for flags,
and `man <program>` for its manual. The [Python](/python/cli/index) and
[TypeScript](/typescript/cli/index) references list the implemented commands
and explain how CLI file arguments use the VFS.

## Compatibility and licenses

implemented subset. Compatibility covers the documented commands, flags,
output and behavior; it does not promise every upstream feature. Git also
names its actual runtime dependencies: Dulwich in Python and isomorphic-git
in TypeScript.
