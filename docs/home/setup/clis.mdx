A CLI is a program an agent runs in the workspace shell, such as
`gh issue list` or `pdftotext report.pdf -`. Account CLIs carry their own
credentials and need no mount; `git`, `office`, `pdfinfo` and `pdftotext`
work on the files in the workspace's mounts. The
[host `mirage` CLI](/home/access/cli) is a different program: it connects to
a workspace from outside.

## Example: gh

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /:
        vfs: ram
    clis:
      gh:
        cli: gh
        machine: in_process
        config:
          token: ${GITHUB_TOKEN}
          repo: acme/tools
    ```

    ```bash
    mirage workspace create workspace.yaml --id dev
    mirage shell -w dev -c 'gh issue list --limit 5'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import Workspace
    from mirage.commands.cli.builtin.gh import GH
    from mirage.core.github.config import GhConfig

    ws = Workspace({})
    ws.register_cli(
        "gh", GH, GhConfig(token=os.environ["GITHUB_TOKEN"], repo="acme/tools")
    )
    result = await ws.shell("gh issue list --limit 5")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { GH, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace({})
    ws.registerCli('gh', GH, { token: process.env.GITHUB_TOKEN!, repo: 'acme/tools' })
    const result = await ws.shell('gh issue list --limit 5')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

- A CLI never reads a mount's credentials, and mounting a service does not
  install its CLI. One token can serve both.
- `gh --help` lists a program's groups, `gh issue list --help` its flags and
  `man gh` its manual.
- A CLI is a program a host adds to its terminal, so a browser page or a
  Worker installs each one by importing its entry before the workspace
  loads, and carries only the CLIs it imports. Python and Node install all
  of them.

  ```typescript
  import '@struktoai/mirage-cloudflare/clis/slack' // or @struktoai/mirage-browser/clis/slack
  import '@struktoai/mirage-cloudflare/clis/gh'
  import '@struktoai/mirage-cloudflare/clis/ast_grep'
  import '@struktoai/mirage-cloudflare/clis/pdf' // pdfinfo and pdftotext
  ```

  An entry takes its CLI's name (`clis/git`, `clis/tvly`), except
  `clis/ast_grep` for ast-grep and `clis/pdf` for pdfinfo and pdftotext.
  A config naming one its host did not import fails with the import to add.

## Compatibility and licenses

implemented subset. Compatibility covers the documented commands, flags,
output and behavior; it does not promise every upstream feature. Git also
names its actual runtime dependencies: Dulwich in Python and isomorphic-git
in TypeScript.
