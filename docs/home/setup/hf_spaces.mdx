A Space repository becomes its file tree: the app code, README, Dockerfile and
requirements, at one revision.

## Setup

Note the Space's full `namespace/space-name` from its URL on
[huggingface.co/spaces](https://huggingface.co/spaces). A public Space needs
no token. For a private one, create a token at
[Access Tokens](https://huggingface.co/settings/tokens) with **New token**:
a **Read** token, or a **Fine-grained** one with read access to that Space's
repository.

```bash
export HF_SPACE_REPO=HuggingFaceBio/carbon-demo
export HF_TOKEN=hf_...
```

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /space:
        vfs: hf_spaces
        mode: read
        config:
          repo_id: ${HF_SPACE_REPO}
    ```

    ```bash
    mirage workspace create workspace.yaml --id space
    mirage shell -w space -c 'ls /space'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.hf_spaces import HfSpacesConfig, HfSpacesVFS

    config = HfSpacesConfig(
        repo_id=os.environ["HF_SPACE_REPO"],
        token=os.environ.get("HF_TOKEN"),
    )
    ws = Workspace({"/space": HfSpacesVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /space")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { HfSpacesVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      {
        '/space': new HfSpacesVFS({
          repoId: process.env.HF_SPACE_REPO!,
          token: process.env.HF_TOKEN,
        }),
      },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /space')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/space/
  Dockerfile
  README.md
  app.py
  requirements.txt
  scripts/
    precompute.py
```

- The tree mirrors the repository at `revision`, `main` when unset.
- Add `token: ${HF_TOKEN}` to the YAML config for a private Space.
- In TypeScript the class ships in `@struktoai/mirage-node`, not
  `@struktoai/mirage-browser`.

The mount is read-only: a Hub write is a commit, so `echo >`, `rm`, `cp` and
`mv` are refused. Download, edit and upload as one commit with the
[`hf`](/home/setup/cli/hf) CLI.
