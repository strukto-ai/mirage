Windows has no native FUSE. Mirage's Python FUSE mounts run on
[WinFsp](https://winfsp.dev/), a Windows file system driver with a FUSE layer.
Support is experimental, and the TypeScript SDK has no Windows FUSE support.

<Steps>
  <Step title="Install WinFsp">
    Needs Windows 10 (1809 or later) or Windows 11. No restart is needed.

    <Tabs>
      <Tab title="winget">
        ```powershell
        winget install -e --id WinFsp.WinFsp
        ```
      </Tab>
      <Tab title="Chocolatey">
        ```powershell
        choco install winfsp -y
        ```
      </Tab>
      <Tab title="Installer">
        Download the MSI from the [WinFsp releases page](https://winfsp.dev/rel/)
        and run it.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Verify">
    ```powershell
    pip install "mirage-ai[fuse]"
    python -c "import mfusepy; print('WinFsp FUSE loaded')"
    ```
    If the import succeeds, the driver is reachable.
  </Step>
</Steps>

## How it differs

| | Windows | macOS and Linux |
| --- | --- | --- |
| Unmount | When the process exits; closing the workspace does not unmount | Closing the workspace unmounts |
| File owner | The user who mounted it, for every file | The backend's owner, where it has one |
| A file whose size is unknown | Size fetched on its first `stat` | Size 0 until first opened |
| Mounts per process | Several | Several on Linux, one on macOS |
