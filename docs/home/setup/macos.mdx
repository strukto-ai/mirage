---
title: macOS
icon: apple
description: Install macFUSE for Mirage's FUSE mounts.
---

<Steps>
  <Step title="Install macFUSE">
    ```bash
    brew install --cask macfuse
    ```
  </Step>
  <Step title="Allow the System Extension">
    Open **System Settings → Privacy & Security**. At the bottom, next to
    "System software from developer 'Benjamin Fleischer' was blocked from
    loading", click **Allow**.
  </Step>
  <Step title="Restart">
    macOS loads the extension after a restart.
  </Step>
  <Step title="Verify">
    ```bash
    ls /Library/Filesystems/macfuse.fs
    ```
    The folder exists when macFUSE is installed.
  </Step>
</Steps>

<Accordion title="No Allow Button on Apple Silicon">
  <Steps>
    <Step title="Shut Down">
      Shut down your Mac completely.
    </Step>
    <Step title="Open Recovery">
      Hold the power button until "Loading startup options" appears, then
      click **Options → Continue**.
    </Step>
    <Step title="Allow Kernel Extensions">
      Open **Utilities → Startup Security Utility**, set **Reduced Security**
      and check **Allow user management of kernel extensions**.
    </Step>
    <Step title="Restart">
      Restart, then allow the extension in **System Settings → Privacy & Security**.
    </Step>
  </Steps>
</Accordion>
