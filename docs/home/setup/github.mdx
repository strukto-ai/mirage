A repository becomes its file tree at one ref, read through GitHub's REST API.
Owner, repo and ref are set at mount time, so paths start at the repository
root.

## Setup

Create a fine-grained personal access token with read-only **Contents** on
the repository, then export it:

<AccordionGroup>
  <Accordion title="Create the token">
    1. Open [Fine-grained tokens](https://github.com/settings/personal-access-tokens/new)
       (Settings, Developer settings, Personal access tokens, Fine-grained
       tokens) and click **Generate new token**.
    2. Pick the resource owner that holds the repository, then under
       **Repository access** choose **Only select repositories** and pick it.
    3. Under **Permissions**, set **Contents** to **Read-only**.
    4. Click **Generate token** and copy it. An organization that requires
       approval keeps the token pending until an admin approves it.

    A classic token (Tokens (classic)) also works: select the `repo` scope for
    private repositories. That broad scope includes write access, so prefer a
    fine-grained token for tighter permissions. A public repository still
    needs a token; one with no scopes reads it.
  </Accordion>
</AccordionGroup>

```bash
export GITHUB_TOKEN=github_pat_...
```

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /github:
        vfs: github
        mode: read
        config:
          token: ${GITHUB_TOKEN}
          owner: strukto-ai
          repo: mirage
          ref: main
    ```

    ```bash
    mirage workspace create workspace.yaml --id gh
    mirage shell -w gh -c 'ls /github'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.github import GitHubConfig, GitHubVFS

    config = GitHubConfig(
        token=os.environ["GITHUB_TOKEN"],
        owner="strukto-ai",
        repo="mirage",
        ref="main",
    )
    ws = Workspace({"/github": GitHubVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /github")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { GitHubVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const github = await GitHubVFS.create({
      token: process.env.GITHUB_TOKEN!,
      owner: 'strukto-ai',
      repo: 'mirage',
      ref: 'main',
    })
    const ws = new Workspace({ '/github': github }, { mode: MountMode.READ })
    const result = await ws.shell('ls /github')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/github/
  README.md
  python/
    pyproject.toml
    mirage/
      ...
  typescript/
    ...
```

- The tree mirrors the repository at `ref`; unset `ref` follows the default
  branch.
- `stat` shows each file's git blob SHA.
- A GitHub App installation can replace the token; the SDK guides show the
  `app` block.
