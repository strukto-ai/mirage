## Credentials

### 1. Create a Personal Access Token

1. Go to https://github.com/settings/tokens
1. **Generate new token (classic)** or **Fine-grained token**
1. For classic tokens, select scopes:
   - `repo` for private repositories. This broad scope includes write access;
     prefer a fine-grained token when you need tighter permissions.
1. For fine-grained tokens:
   - **Repository access**: select the repos you need
   - **Permissions**: Contents -> Read-only
1. Copy the token

### 2. Set Environment Variables

```bash
# .env.development
GITHUB_TOKEN=ghp_xxxx...
```
