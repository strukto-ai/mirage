Every server the bot is in becomes a folder of channels, each a folder of days
with a `chat.jsonl` of that day's messages and the files shared in it. Members
become one JSON profile each.

## Setup

Create a Discord application with a bot, turn on its intents and add it to
the server.

<AccordionGroup>
  <Accordion title="Create the bot and invite it">
    1. Open the [Discord Developer Portal](https://discord.com/developers/applications),
       click **New Application** and name it (for example `Mirage`).
    2. Under **Bot**, click **Reset Token** and copy the bot token.
    3. On the same page, under **Privileged Gateway Intents**, turn on
       **Message Content Intent**; without it, message text and attachments
       come back empty. Turn on **Server Members Intent** for the `members/`
       folder and for `discord members` without `--query`.
    4. Under **OAuth2**, **URL Generator**, select the `bot` scope and the
       **View Channels** and **Read Message History** permissions. Add
       **Send Messages** for the CLI's writes and **Attach Files** for
       `send --file`.
    5. Open the generated URL in a browser and add the bot to the server.
  </Accordion>
</AccordionGroup>

```bash
export DISCORD_BOT_TOKEN=MTIx...
```

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /discord:
        vfs: discord
        mode: read
        config:
          token: ${DISCORD_BOT_TOKEN}
    ```

    ```bash
    mirage workspace create workspace.yaml --id discord
    mirage shell -w discord -c 'ls /discord'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.discord import DiscordConfig, DiscordVFS

    config = DiscordConfig(token=os.environ["DISCORD_BOT_TOKEN"])
    ws = Workspace({"/discord": DiscordVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /discord")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { DiscordVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      { '/discord': new DiscordVFS({ token: process.env.DISCORD_BOT_TOKEN! }) },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /discord')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/discord/
  Acme Labs__1098765432101234567/
    channels/
      general__1098765432101234570/
        2026-11-16/
          chat.jsonl
          files/
            diagram__1174567890123456789.png
    members/
      alice__1012345678901234567.json
```

- A name is `<display-name>__<id>`, spaces and emoji kept; quote it in the
  shell.
- Each channel lists one folder per day for the 30 days up to its newest
  message; `start_time` and `end_time` set another range.
- A `chat.jsonl` line is one message as Discord's API returns it, with
  `.content`, `.author.username` and `.attachments`.

## Sample runs

```bash
$ ls /discord
Acme Labs__1098765432101234567
```

```bash
$ ls "/discord/Acme Labs__1098765432101234567/channels"
announcements__1098765432101234571
general__1098765432101234570
```

```bash
$ jq -r '.author.username + ": " + .content' "/discord/Acme Labs__1098765432101234567/channels/general__1098765432101234570/2026-11-16/chat.jsonl"
alice: Build 412 is green
bob: Deploying after lunch
```

The mount is read-only. Send messages with the
[`discord`](/home/setup/cli/discord) CLI.
