RAM stores files in memory. Use it for scratch files, tests and trying Mirage.
Files are lost when the application exits. Available in Python, Node and browsers.

## Configuration

```yaml
mounts:
  /data:
    vfs: ram
    mode: write
```

The mount starts empty. In Mirage's shell, create and read a file:

```bash
echo "hello" > /data/note.txt
cat /data/note.txt
```

Add `capacity: 100MB` under `config` to cap the bytes it holds. See
[capacity](/home/configuration#capacity).
