Redis stores workspace files in a Redis database. Available in Python, Node
and browsers. File persistence depends on the database's configuration.

## Configuration

For Python or Node, set `url` to your Redis connection URL. Use `key_prefix`
to keep this workspace's files separate from other data:

```yaml
mounts:
  /data:
    vfs: redis
    mode: write
    config:
      url: redis://localhost:6379/0
      key_prefix: "mirage:fs:"
```

Add `capacity: 100MB` under `config` to cap the bytes the files hold. See
[capacity](/home/configuration#capacity).

Browsers connect through a compatible HTTP endpoint, such as Upstash REST.
See [browser Redis setup](/typescript/setup/redis#browser) for configuration.
