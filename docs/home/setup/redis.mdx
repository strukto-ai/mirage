Redis keeps workspace files as keys in a Redis database, under one key prefix.
The files last as long as the database keeps its data.

## Setup

Start a local server (`redis-server` listens on `redis://localhost:6379/0`,
the default) or use a managed one. For Redis Cloud, the endpoint is in the
database's **Configuration** tab and the password of the `default` user under
**Security** (Pro) or **Default user > Configure** (Essentials). Use
`rediss://` when the server needs TLS.

```bash
export REDIS_URL=redis://default:<password>@<host>:<port>/0
```

Python needs `pip install "mirage-ai[redis]"`; Node needs the `redis@^5` peer
dependency (`pnpm add @struktoai/mirage-node redis`).

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /redis:
        vfs: redis
        mode: write
        config:
          url: ${REDIS_URL}
          key_prefix: "mirage:fs:"
    ```

    ```bash
    mirage workspace create workspace.yaml --id kv
    mirage shell -w kv -c 'ls /redis'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.redis import RedisVFS

    vfs = RedisVFS(url=os.environ["REDIS_URL"], key_prefix="mirage:fs:")
    ws = Workspace({"/redis": vfs}, mode=MountMode.WRITE)
    result = await ws.shell("ls /redis")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { MountMode, RedisVFS, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      {
        '/redis': new RedisVFS({
          url: process.env.REDIS_URL!,
          keyPrefix: 'mirage:fs:',
        }),
      },
      { mode: MountMode.WRITE },
    )
    const result = await ws.shell('ls /redis')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/redis/
  config.json
  cache/
    session-abc.json
  logs/
    app.log
```

- The tree is whatever commands write. Each file is a `<prefix>file:<path>`
  key; a different `key_prefix` keeps a workspace apart from other data.
- Runs in Python, Node and Cloudflare Workers over the Redis protocol.
- A browser has no socket, so it mounts Redis through the Upstash REST API;
  see [browser Redis setup](/typescript/setup/redis#browser).

## Sample runs

```bash
$ tree /redis
/redis
|-- cache
|   `-- session-abc.json
|-- config.json
`-- logs
    `-- app.log

3 directories, 3 files
```

```bash
$ grep -rn retry /redis/logs
/redis/logs/app.log:2:retry 1
```

```bash
$ cat /redis/config.json
{"theme": "dark"}
```

Every command that writes works on a `write` mount. Add `capacity: 100MB`
under `config` to cap the bytes the files hold; see
[capacity](/home/setup/vfs#mount-capacity).
