Every team the API key can reach becomes a folder of members, issues,
projects, cycles and documents, one JSON file each, with an issue's comments
as one JSONL file.

## Setup

Create a personal API key in Linear under **Settings**, **Account**,
**Security & Access**, in the **Personal API keys** section. The **Read**
permission is enough for the mount; the [`linear`](/home/setup/cli/linear) CLI
needs **Write** or the create permissions to change issues. A key can also be
limited to some teams. Admins can always create keys; members can when an
admin allows it under **Administration**, **API**. Copy the key when it is
shown.

```bash
export LINEAR_API_KEY=lin_api_...
```

## Connect

<Tabs>
  <Tab title="YAML" icon="file-code">
    ```yaml workspace.yaml
    mounts:
      /linear:
        vfs: linear
        mode: read
        config:
          api_key: ${LINEAR_API_KEY}
    ```

    ```bash
    mirage workspace create workspace.yaml --id lin
    mirage shell -w lin -c 'ls /linear/teams'
    ```
  </Tab>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.linear import LinearConfig, LinearVFS

    config = LinearConfig(api_key=os.environ["LINEAR_API_KEY"])
    ws = Workspace({"/linear": LinearVFS(config)}, mode=MountMode.READ)
    result = await ws.shell("ls /linear/teams")
    print(await result.stdout_str())
    await ws.close()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { LinearVFS, MountMode, Workspace } from '@struktoai/mirage-node'

    const ws = new Workspace(
      { '/linear': new LinearVFS({ apiKey: process.env.LINEAR_API_KEY! }) },
      { mode: MountMode.READ },
    )
    const result = await ws.shell('ls /linear/teams')
    console.log(result.stdoutText)
    await ws.close()
    ```
  </Tab>
</Tabs>

## Layout

```text
/linear/
  teams/
    ENG__Engineering__<team-id>/
      team.json
      members/
        Alice_Chen__<user-id>.json
      issues/
        ENG-142__<issue-id>/
          issue.json
          comments.jsonl
      projects/
        Q4_Launch__<project-id>.json
      cycles/
        Cycle_12__<cycle-id>.json
      documents/
        Roadmap_2027__<document-id>.json
```

- Every name ends in `__<id>`; the readable part is sanitized, so `ls` the
  parent instead of building it.
- Files hold Mirage's normalized JSON with snake_case keys, not Linear's raw
  GraphQL response.
- `team_ids` limits the mount to some teams.


```bash
$ jq -r '.issue_key, .state_name, .assignee_name' /linear/teams/ENG__Engineering__9f3a2c71-8d4e-4b6a-a1f0-6e2d5c7b9a04/issues/ENG-142__7d1b4e9c-0a3f-4e52-8c6d-b9f2a5e7c018/issue.json
```

The mount is read-only. Create, update, assign and comment on issues with the
[`linear`](/home/setup/cli/linear) CLI.
