---
title: Linux
icon: linux
description: Install FUSE 3 for Mirage's FUSE mounts.
---

<Steps>
  <Step title="Install FUSE 3">
    <Tabs>
      <Tab title="Ubuntu / Debian">
        ```bash
        sudo apt-get install fuse3 libfuse3-dev
        ```
      </Tab>
      <Tab title="Fedora / RHEL">
        ```bash
        sudo dnf install fuse3 fuse3-devel
        ```
      </Tab>
      <Tab title="Arch Linux">
        ```bash
        sudo pacman -S fuse3
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step title="Verify">
    ```bash
    fusermount3 --version
    ```
  </Step>
</Steps>

Mirage needs only `fusermount3`, so it works where the older `fusermount` is
missing, as on Fedora, RHEL, Amazon Linux 2023, openSUSE and Alpine.
