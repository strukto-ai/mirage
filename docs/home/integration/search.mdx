`grep` and `rg` can ask your VFS which files or lines may hold the text,
instead of reading every file. Mirage still matches each line itself, so the
output is the same. Return `None` (TypeScript: `null`) when your search cannot
answer, and Mirage reads the file.

For example, with [Chroma](/python/vfs/chroma) at `/knowledge/`,
`grep -r refund /knowledge/` asks Chroma which documents contain `refund` and
reads only those.

## When grep and rg call these methods

Only when every match contains a plain text of 3 or more characters, such as
`refund` in `grep 'refund.*2026'`, or a `-w` or `-x` word of any length.

They never call them with these flags, and read every file instead:

`grep` and `rg`:

- `-v`: print lines that do not match
- `-f FILE`: read patterns from a file
- `-i`, when the text has a non-ASCII letter, or in a UTF-8 locale an `i`, `k`
  or `s`

`rg` only:

- `--passthru`: print every line
- `--files-without-match`: list files with no match
- `--json`: print JSON
- `--stats`: print statistics
- `-z`: search compressed files
- `-L`: follow symlinks
- `--pre COMMAND`: preprocess each file
- `-E ENCODING`: read files in an encoding
- `-c` or `--count-matches`, with `--include-zero`

## `files_containing`

Which files under a folder may contain a text.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    async def files_containing(
        self, path: PathSpec, text: str, *, whole_word: bool, ignore_case: bool
    ) -> list[PathSpec] | None: ...
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    filesContaining(
      path: PathSpec,
      text: string,
      opts: { wholeWord: boolean; ignoreCase: boolean },
    ): Promise<PathSpec[] | null>
    ```
  </Tab>
</Tabs>

| Argument | Meaning |
| --- | --- |
| `path` | The folder `grep -r` or `rg` walks. |
| `text` | A text every match contains. Asked once per text, so `grep -r -e refund -e order` asks twice. |
| `whole_word` | `True` for `-w` or `-x`: `text` must match as a whole word. |
| `ignore_case` | `True` for `-i`. |

| Return | Mirage then |
| --- | --- |
| The files that may contain `text` | Reads only these files; the others have no match. Include every file that could match. |
| An empty list | Reads no file under `path`. |
| `None` | Reads every file. |

These commands call `files_containing`:

- `grep -r`, `grep -R`, `grep -d recurse`
- `rg` on a folder

A file named on the line is always read.

This example extends `NotesVFS` from [Custom VFS](/home/setup/custom-vfs#example-a-read-only-vfs):

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import PathSpec
    from mirage.utils.key_prefix import mounted_path

    from notes import NotesVFS


    class SearchableNotesVFS(NotesVFS):
        async def files_containing(
            self, path: PathSpec, text: str, *, whole_word: bool, ignore_case: bool
        ) -> list[PathSpec] | None:
            if ignore_case:
                return None
            return [
                mounted_path(path, name)
                for name, page in self.pages.items()
                if text in page
            ]
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { PathSpec } from '@struktoai/mirage-node'
    import { mountedPath } from '@struktoai/mirage-core/utils/key_prefix'
    import { NotesVFS } from './notes.ts'

    export class SearchableNotesVFS extends NotesVFS {
      override async filesContaining(
        path: PathSpec,
        text: string,
        opts: { wholeWord: boolean; ignoreCase: boolean },
      ): Promise<PathSpec[] | null> {
        if (opts.ignoreCase) return null
        return Object.entries(this.pages)
          .filter(([, page]) => page.includes(text))
          .map(([name]) => mountedPath(path, name))
      }
    }
    ```
  </Tab>
</Tabs>

`grep -rn mirage /notes` then reads only the pages that contain `mirage`.
`mounted_path` turns a name below the mount into a path.

## `lines_containing`

Which lines of one file may contain a text.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    async def lines_containing(
        self, path: PathSpec, text: str, *, ignore_case: bool
    ) -> bytes | None: ...
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    linesContaining(
      path: PathSpec,
      text: string,
      opts: { ignoreCase: boolean },
    ): Promise<Uint8Array | null>
    ```
  </Tab>
</Tabs>

| Argument | Meaning |
| --- | --- |
| `path` | The file `grep` or `rg` would read. |
| `text` | A text every match contains. Asked once per text. |
| `ignore_case` | `True` for `-i`. |

| Return | Mirage then |
| --- | --- |
| The lines that may contain `text`, in their order | Matches them instead of reading the file, or reads the file if they hold a match. See the lists below. |
| Empty bytes | The file has no match. It is not read. |
| `None` | Reads the file. Return it for a file that may hold a NUL byte. |

Mirage matches your lines instead of reading the file for `grep` and `rg` with
no flag, or with:

- `-c`: count matching lines
- `-l`: list files with a match
- `-q`: print nothing, exit 0 on a match
- `-o`: print only the matched text
- `-m N`: stop after N matches
- `-i`: ignore case
- `-w`: match whole words
- `-x`: match whole lines
- `-F`: match the text literally
- `-r`: search folders
- `-L`: list files with no match (`grep` only)

Mirage reads the file only if your lines hold a match, and skips it if not, for
`grep` and `rg` with:

- `-n`: print line numbers
- `-b`: print byte offsets
- `-A N`, `-B N`, `-C N`: print lines around each match
- more than one pattern, such as `-e a -e b` or `'a|b'`
- `-z`: lines end with NUL (`grep` only; `--null-data` in `rg`)
- `--column`: print column numbers (`rg` only)
- `--vimgrep`: print every match with its position (`rg` only)
- `-U`: match across lines (`rg` only)

This example extends the same `NotesVFS`:

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import PathSpec

    from notes import NotesVFS


    class LineSearchNotesVFS(NotesVFS):
        async def lines_containing(
            self, path: PathSpec, text: str, *, ignore_case: bool
        ) -> bytes | None:
            if ignore_case:
                return None
            lines = self.page(path).splitlines(keepends=True)
            return "".join(line for line in lines if text in line).encode()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class LineSearchNotesVFS extends NotesVFS {
      override async linesContaining(
        path: PathSpec,
        text: string,
        opts: { ignoreCase: boolean },
      ): Promise<Uint8Array | null> {
        if (opts.ignoreCase) return null
        const lines = this.page(path).split(/(?<=\n)/).filter((line) => line.includes(text))
        return new TextEncoder().encode(lines.join(''))
      }
    }
    ```
  </Tab>
</Tabs>

`grep mirage /notes/todo.txt` and `grep -c mirage /notes/todo.txt` then read
nothing. `grep -n mirage /notes/todo.txt` reads the page, since it holds a
match.

## Turn on a service's search

These built-in VFSs keep their service's search off until you set
`content_search: true`, because the service's index can miss a match: it
lags recent writes, or searches other text than the file `grep` reads:

- Box
- Dropbox
- Email (IMAP)
- Gmail
- Google Calendar, Docs, Drive, Sheets and Slides
- Linear
- OneDrive
- SharePoint
- Slack
- Trello

Gmail and Email ask their service for any text; the others only for `-w`.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import os

    from mirage import MountMode, Workspace
    from mirage.vfs.slack import SlackConfig, SlackVFS

    slack = SlackVFS(
        config=SlackConfig(
            token=os.environ["SLACK_BOT_TOKEN"],
            search_token=os.environ["SLACK_USER_TOKEN"],
            content_search=True,
        )
    )
    ws = Workspace({"/slack": slack}, mode=MountMode.READ)
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { MountMode, SlackVFS, Workspace } from '@struktoai/mirage-node'

    const slack = new SlackVFS({
      token: process.env.SLACK_BOT_TOKEN!,
      searchToken: process.env.SLACK_USER_TOKEN,
      contentSearch: true,
    })
    const ws = new Workspace({ '/slack': slack }, { mode: MountMode.READ })
    ```
  </Tab>
  <Tab title="YAML" icon="file-code">
    ```yaml
    mounts:
      /slack:
        vfs: slack
        mode: read
        config:
          token: ${SLACK_BOT_TOKEN}
          search_token: ${SLACK_USER_TOKEN}
          content_search: true
    ```
  </Tab>
</Tabs>

`grep -rw refund /slack/channels/` then asks Slack's search which days mention
`refund` and reads only those.
