Lines lets a VFS answer line commands without reading a whole file. Override
`first_lines`, `last_lines`, `line_count` and `follow` to make `head`, `tail`,
`wc -l` and `tail -f` cheaper.

## Supported commands

These commands ask the VFS for lines or a count. The others read the file as
usual.

| Command | What happens |
| --- | --- |
| `head`, `head -n N`, `head -N` | Asks for the first lines. The file is not read. |
| `tail`, `tail -n N`, `tail -N` | Asks for the last lines. The file is not read. |
| `wc -l` | Asks for the line count. The file is not read. |
| `tail -f`, `tail -f -n N` on one file | Asks for the last lines and then each new line, instead of reading the file every `interval` seconds (`tail -s`, 1 by default). If the stream ends, `tail -f` exits 1 with `tail: no files remaining`. |
| `head -c N`, `head -n -N`, `head -z` | Reads the file. |
| `tail -c N`, `tail -n +N` | Reads the file. |
| `wc` with another count (`-c`, `-w`, `-m` or `-L`) | Reads the file. |
| `tail -F`, `tail --follow=name`, `tail -f -c N`, `tail -f -n +N`, `tail -f` on more than one file | Reads the file every `interval` seconds. |
| Any of these reading standard input | Never asks. |

## For VFS authors

A custom VFS overrides the methods its service can answer. Each method returns
exactly what a read would hold, or `None` (TypeScript: `null`) and Mirage
reads the file. TypeScript names methods in camelCase (`first_lines` is
`firstLines`) and returns `Uint8Array` for `bytes`. The examples extend
`NotesVFS` from
[Adding a New VFS](/home/setup/vfs/new#write-one).

### `first_lines`

The first lines of one file, for `head`.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import io

    from mirage import PathSpec

    from notes import NotesVFS


    class LinesNotesVFS(NotesVFS):
        async def first_lines(self, path: PathSpec, n: int) -> bytes | None:
            lines = io.StringIO(self.page(path), newline="\n").readlines()
            return "".join(lines[:n]).encode()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class LinesNotesVFS extends NotesVFS {
      override async firstLines(path: PathSpec, n: number): Promise<Uint8Array | null> {
        const lines = this.page(path).split(/(?<=\n)/)
        return new TextEncoder().encode(lines.slice(0, n).join(''))
      }
    }
    ```
  </Tab>
</Tabs>

`path` is the file. `n` is how many lines, 1 or more, and 10 for plain `head`.
Return the first `n` lines, or all of them if the file is shorter. With this
example, `head -n 1` on a page reads nothing, and `head -c 3` still reads it.

### `last_lines`

The last lines of one file, for `tail`.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import io

    from mirage import PathSpec

    from notes import NotesVFS


    class LinesNotesVFS(NotesVFS):
        async def last_lines(self, path: PathSpec, n: int) -> bytes | None:
            lines = io.StringIO(self.page(path), newline="\n").readlines()
            return "".join(lines[max(len(lines) - n, 0) :]).encode()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class LinesNotesVFS extends NotesVFS {
      override async lastLines(path: PathSpec, n: number): Promise<Uint8Array | null> {
        const lines = this.page(path).split(/(?<=\n)/)
        return new TextEncoder().encode(lines.slice(Math.max(lines.length - n, 0)).join(''))
      }
    }
    ```
  </Tab>
</Tabs>

`path` is the file. `n` is how many lines, 1 or more, and 10 for plain `tail`.
Return the last `n` lines, or all of them if the file is shorter.

### `line_count`

The number of lines in one file, for `wc -l`.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import PathSpec

    from notes import NotesVFS


    class LinesNotesVFS(NotesVFS):
        async def line_count(self, path: PathSpec) -> int | None:
            return self.page(path).count("\n")
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class LinesNotesVFS extends NotesVFS {
      override async lineCount(path: PathSpec): Promise<number | null> {
        return this.page(path).split('\n').length - 1
      }
    }
    ```
  </Tab>

`path` is the file. Return the number of newline characters in it.

### `follow`

The last lines of one file, then each new line as it arrives, for `tail -f`.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import asyncio
    import io
    from collections.abc import AsyncIterator

    from mirage import PathSpec

    from notes import NotesVFS


    class FollowNotesVFS(NotesVFS):
        async def follow(
            self, path: PathSpec, n: int, interval: float
        ) -> AsyncIterator[bytes] | None:
            async def lines() -> AsyncIterator[bytes]:
                seen = self.page(path)
                old = io.StringIO(seen, newline="\n").readlines()
                yield "".join(old[max(len(old) - n, 0) :]).encode()
                while True:
                    await asyncio.sleep(interval)
                    page = self.page(path)
                    if len(page) < len(seen):
                        seen = ""
                    yield page[len(seen) :].encode()
                    seen = page

            return lines()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class FollowNotesVFS extends NotesVFS {
      override async follow(
        path: PathSpec,
        n: number,
        interval: number,
      ): Promise<AsyncIterable<Uint8Array> | null> {
        const page = (): string => this.page(path)
        async function* lines(): AsyncGenerator<Uint8Array> {
          let seen = page()
          const old = seen.split(/(?<=\n)/)
          yield new TextEncoder().encode(old.slice(Math.max(old.length - n, 0)).join(''))
          for (;;) {
            await new Promise((resolve) => setTimeout(resolve, interval * 1000))
            const now = page()
            if (now.length < seen.length) seen = ''
            yield new TextEncoder().encode(now.slice(seen.length))
            seen = now
          }
        }
        return lines()
      }
    }
    ```
  </Tab>
</Tabs>

`path` is the file. `n` is how many of its last lines come first, 0 for none.
`interval` is the seconds between two checks for new lines (`tail -s`, 1 by
default). A service that pushes new lines can ignore it.

Return a stream that yields the last `n` lines, then each new whole line in
order, and never ends on its own. Mirage prints it until `tail -f` is stopped.
If the stream ends, `tail -f` exits 1 with `tail: no files remaining`.

A real service would push new lines over a stream. This example checks the
dictionary every `interval` seconds instead. It yields on every check, an
empty chunk when nothing is new, so a stopped `tail -f` closes it within one
interval. It starts over when the page shrinks.
