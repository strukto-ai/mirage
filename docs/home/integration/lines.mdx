Lines lets a VFS answer `head`, `tail`, `wc -l` and `tail -f` without reading
the whole file. [Built-in VFSs](/home/integration/overview#lines) lists which
VFSs support it.

## VFS and Lines Integration

A VFS overrides the methods its service can answer. Each method returns
exactly what a read would hold, or `None` (TypeScript: `null`) when it cannot
answer, and Mirage reads the file instead. TypeScript names methods in
camelCase (`first_lines` is `firstLines`) and returns `Uint8Array` for
`bytes`. A command reading standard input never asks. The examples extend
`NotesVFS` from [Adding a New VFS](/home/setup/vfs/new#write-one), mounted at
`/notes`.

### `first_lines`

The first lines of one file.

**Commands:** `head`, `head -n N` and `head -N`. `head -c N`, `head -n -N` and
`head -z` read the file without asking.

<ParamField body="path" type="PathSpec" required>
The file, on this mount.
</ParamField>

<ParamField body="n" type="int" required>
How many lines to return, 1 or more.
</ParamField>

**Examples:**

| Command | `path` | `n` |
| --- | --- | --- |
| `head /notes/todo.txt` | `/notes/todo.txt` | `10` |
| `head -n 3 /notes/todo.txt` | `/notes/todo.txt` | `3` |

<ResponseField name="returns" type="bytes | None">

| Return | What happens |
| --- | --- |
| The first `n` lines, or the whole file if it is shorter | `head` prints them, and the file is not read. |
| `None` | The file is read. |

</ResponseField>

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import io

    from mirage import PathSpec

    from notes import NotesVFS


    class LinesNotesVFS(NotesVFS):
        async def first_lines(self, path: PathSpec, n: int) -> bytes | None:
            lines = io.StringIO(self.page(path), newline="\n").readlines()
            return "".join(lines[:n]).encode()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class LinesNotesVFS extends NotesVFS {
      override async firstLines(path: PathSpec, n: number): Promise<Uint8Array | null> {
        const lines = this.page(path).split(/(?<=\n)/)
        return new TextEncoder().encode(lines.slice(0, n).join(''))
      }
    }
    ```
  </Tab>
</Tabs>

With this example, `head -n 1` on a page reads nothing, and `head -c 3` still
reads it.

### `last_lines`

The last lines of one file.

**Commands:** `tail`, `tail -n N` and `tail -N`. `tail -c N` and `tail -n +N`
read the file without asking.

<ParamField body="path" type="PathSpec" required>
The file, on this mount.
</ParamField>

<ParamField body="n" type="int" required>
How many lines to return, 1 or more.
</ParamField>

**Examples:**

| Command | `path` | `n` |
| --- | --- | --- |
| `tail /notes/todo.txt` | `/notes/todo.txt` | `10` |
| `tail -n 5 /notes/todo.txt` | `/notes/todo.txt` | `5` |

<ResponseField name="returns" type="bytes | None">

| Return | What happens |
| --- | --- |
| The last `n` lines, or the whole file if it is shorter | `tail` prints them, and the file is not read. |
| `None` | The file is read. |

</ResponseField>

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import io

    from mirage import PathSpec

    from notes import NotesVFS


    class LinesNotesVFS(NotesVFS):
        async def last_lines(self, path: PathSpec, n: int) -> bytes | None:
            lines = io.StringIO(self.page(path), newline="\n").readlines()
            return "".join(lines[max(len(lines) - n, 0) :]).encode()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { PathSpec } from '@struktoai/mirage-node'

      }
    }
    ```

### `line_count`

The number of lines in one file.

**Commands:** `wc -l`. `wc` with another count (`-c`, `-w`, `-m` or `-L`)
reads the file without asking.

<ParamField body="path" type="PathSpec" required>
The file, on this mount.
</ParamField>

**Examples:**

| Command | `path` |
| --- | --- |
| `wc -l /notes/todo.txt` | `/notes/todo.txt` |

<ResponseField name="returns" type="int | None">

| Return | What happens |
| --- | --- |
| The number of newline characters in the file | `wc -l` prints it, and the file is not read. |
| `None` | The file is read. |

</ResponseField>

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import PathSpec

    from notes import NotesVFS


    class LinesNotesVFS(NotesVFS):
        async def line_count(self, path: PathSpec) -> int | None:
            return self.page(path).count("\n")
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class LinesNotesVFS extends NotesVFS {
      override async lineCount(path: PathSpec): Promise<number | null> {
        return this.page(path).split('\n').length - 1
      }
    }
    ```
  </Tab>
</Tabs>

### `follow`

The last lines of one file, then each new line as it arrives.

**Commands:** `tail -f` and `tail -f -n N` on one file. `tail -F`,
`tail --follow=name`, `tail -f -c N`, `tail -f -n +N` and `tail -f` on more
than one file read the file every `interval` seconds without asking.

<ParamField body="path" type="PathSpec" required>
The file, on this mount.
</ParamField>

<ParamField body="n" type="int" required>
How many of the file's last lines to send first, 0 for none.
</ParamField>

<ParamField body="interval" type="float" required>
The seconds between two checks for new lines. A service that pushes new lines can ignore it.
</ParamField>

**Examples:**

| Command | `path` | `n` | `interval` |
| --- | --- | --- | --- |
| `tail -f /notes/log.txt` | `/notes/log.txt` | `10` | `1.0` |
| `tail -f -n 0 -s 5 /notes/log.txt` | `/notes/log.txt` | `0` | `5.0` |

<ResponseField name="returns" type="AsyncIterator[bytes] | None">

| Return | What happens |
| --- | --- |
| A stream that yields the last `n` lines, then each new whole line in order, and never ends on its own | `tail -f` prints it until it is stopped. If the stream ends, `tail -f` exits 1 with `tail: no files remaining`. |
| `None` | The file is read every `interval` seconds. |

</ResponseField>

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import asyncio
    import io
    from collections.abc import AsyncIterator

    from mirage import PathSpec

    from notes import NotesVFS


    class FollowNotesVFS(NotesVFS):
        async def follow(
            self, path: PathSpec, n: int, interval: float
        ) -> AsyncIterator[bytes] | None:
            async def lines() -> AsyncIterator[bytes]:
                seen = self.page(path)
                old = io.StringIO(seen, newline="\n").readlines()
                yield "".join(old[max(len(old) - n, 0) :]).encode()
                while True:
                    await asyncio.sleep(interval)
                    page = self.page(path)
                    if len(page) < len(seen):
                        seen = ""
                    yield page[len(seen) :].encode()
                    seen = page

            return lines()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class FollowNotesVFS extends NotesVFS {
      override async follow(
        path: PathSpec,
        n: number,
        interval: number,
      ): Promise<AsyncIterable<Uint8Array> | null> {
        const page = (): string => this.page(path)
        async function* lines(): AsyncGenerator<Uint8Array> {
          let seen = page()
          const old = seen.split(/(?<=\n)/)
          yield new TextEncoder().encode(old.slice(Math.max(old.length - n, 0)).join(''))
          for (;;) {
            await new Promise((resolve) => setTimeout(resolve, interval * 1000))
            const now = page()
            if (now.length < seen.length) seen = ''
            yield new TextEncoder().encode(now.slice(seen.length))
            seen = now
          }
        }
        return lines()
      }
    }
    ```
  </Tab>
</Tabs>

A real service would push new lines over a stream. This example checks the
dictionary every `interval` seconds instead. It yields on every check, an
empty chunk when nothing is new, so a stopped `tail -f` closes it within one
interval. It starts over when the page shrinks.
