Checksums lets a VFS answer hash commands from a hash its service already
stores, without reading the file. Override `checksum` to make `md5sum`,
`sha256sum` and the other hash commands cheaper.

## Supported commands

These commands ask the VFS for a stored hash. When the VFS has none for that
hash, the command reads and hashes the file as usual.

| Command | What happens |
| --- | --- |
| `md5sum`, `md5` | Asks for the `md5` hash. |
| `sha1sum`, `sha224sum`, `sha256sum`, `sha384sum`, `sha512sum` | Asks for the `sha1`, `sha224`, `sha256`, `sha384` or `sha512` hash. |
| `b2sum` | Asks for the `blake2b` hash. |
| `b2sum -l N` | Asks for the `blake2b-N` hash, BLAKE2b at N bits. |
| Any of these with `-c`, which checks the hashes listed in a file | Reads the files. |

## For VFS authors

A custom VFS overrides `checksum` when its service stores hashes.

### `checksum`

The hash of one file. A real service returns the hash it stores. This example
extends `NotesVFS` from
[Adding a New VFS](/home/setup/custom-vfs#example-a-read-only-vfs), computes
MD5 and leaves the others to Mirage.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import hashlib

    from mirage import PathSpec

    from notes import NotesVFS


    class HashedNotesVFS(NotesVFS):
        async def checksum(self, path: PathSpec, algorithm: str) -> str | None:
            if algorithm != "md5":
                return None
            return hashlib.md5(self.page(path).encode()).hexdigest()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { createHash } from 'node:crypto'
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class HashedNotesVFS extends NotesVFS {
      override async checksum(path: PathSpec, algorithm: string): Promise<string | null> {
        if (algorithm !== 'md5') return null
        return createHash('md5').update(this.page(path)).digest('hex')
      }
    }
    ```
  </Tab>
</Tabs>

`path` is the file. `algorithm` is the hash name from
[Supported commands](#supported-commands): `md5`, `sha1` to `sha512`,
`blake2b` or `blake2b-N`.

Return the lowercase hex hash of exactly the bytes a read returns. Mirage
prints it and reads nothing. Return `None` (TypeScript: `null`) and Mirage
reads and hashes the file. With this example, `md5sum /notes/hello.txt` reads
nothing, and `sha256sum` still reads the page.
