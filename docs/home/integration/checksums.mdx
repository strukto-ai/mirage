`md5sum`, `sha256sum` and the other hash commands can ask your VFS for a hash
it already stores, instead of reading and hashing the file. Return `None`
(TypeScript: `null`) and Mirage hashes the file.

For example, [Google Drive](/python/vfs/gdrive) answers `md5sum`, `sha1sum`
and `sha256sum` from the hashes Drive stores.

## `checksum`

The hash of one file.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    async def checksum(self, path: PathSpec, algorithm: str) -> str | None: ...
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    checksum(path: PathSpec, algorithm: string): Promise<string | null>
    ```
  </Tab>
</Tabs>

| Argument | Meaning |
| --- | --- |
| `path` | The file. |
| `algorithm` | `md5`, `sha1`, `sha224`, `sha256`, `sha384`, `sha512`, `blake2b`, or `blake2b-N` for BLAKE2b at N bits. |

| Return | Mirage then |
| --- | --- |
| The lowercase hex hash of exactly the bytes a read returns | Prints it. The file is not read. |
| `None` | Reads the file and hashes it. |

These commands call `checksum`, with this `algorithm`:

- `md5sum`, `md5`: `md5`
- `sha1sum`: `sha1`
- `sha224sum`: `sha224`
- `sha256sum`: `sha256`
- `sha384sum`: `sha384`
- `sha512sum`: `sha512`
- `b2sum`: `blake2b`, or `blake2b-N` with `-l N`

This reads the file instead:

- `-c`: check hashes listed in a file

## Example

This example extends `NotesVFS` from [Custom VFS](/home/setup/custom-vfs#example-a-read-only-vfs).
A real service returns the hash it stores; this one computes MD5 and leaves the
others to Mirage:

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import hashlib

    from mirage import PathSpec

    from notes import NotesVFS


    class HashedNotesVFS(NotesVFS):
        async def checksum(self, path: PathSpec, algorithm: str) -> str | None:
            if algorithm != "md5":
                return None
            return hashlib.md5(self.page(path).encode()).hexdigest()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { createHash } from 'node:crypto'
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class HashedNotesVFS extends NotesVFS {
      override async checksum(path: PathSpec, algorithm: string): Promise<string | null> {
        if (algorithm !== 'md5') return null
        return createHash('md5').update(this.page(path)).digest('hex')
      }
    }
    ```
  </Tab>
</Tabs>

`md5sum /notes/hello.txt` then reads nothing. `sha256sum` still reads the page.
