Checksums lets a VFS answer hash commands from a hash its service already
stores, without reading the file.
[Built-in VFSs](/home/integration/overview#checksums) lists which VFSs support
it.

## VFS and Checksums Integration

A VFS overrides `checksum` when its service stores hashes. It returns `None`
(TypeScript: `null`) when it has no stored hash, and Mirage reads and hashes
the file instead. The example extends `NotesVFS` from
[Adding a New VFS](/home/setup/vfs/new#write-one), mounted at `/notes`.

### `checksum`

The stored hash of one file.

**Commands:** `md5sum`, `md5`, `sha1sum`, `sha224sum`, `sha256sum`,
`sha384sum`, `sha512sum` and `b2sum`. With `-c`, which checks the hashes
listed in a file, they read the files without asking.

<ParamField body="path" type="PathSpec" required>
The file, on this mount.
</ParamField>

<ParamField body="algorithm" type="str" required>
The hash to return: `md5`, `sha1`, `sha224`, `sha256`, `sha384`, `sha512`, `blake2b`, or `blake2b-N` for BLAKE2b at N bits.
</ParamField>

**Examples:**

| Command | `path` | `algorithm` |
| --- | --- | --- |
| `md5sum /notes/hello.txt` | `/notes/hello.txt` | `md5` |
| `sha256sum /notes/hello.txt` | `/notes/hello.txt` | `sha256` |
| `b2sum /notes/hello.txt` | `/notes/hello.txt` | `blake2b` |
| `b2sum -l 256 /notes/hello.txt` | `/notes/hello.txt` | `blake2b-256` |

<ResponseField name="returns" type="str | None">

| Return | What happens |
| --- | --- |
| The lowercase hex hash of exactly the bytes a read returns | The command prints it, and the file is not read. |
| `None` | The file is read and hashed. |

</ResponseField>

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    import hashlib

    from mirage import PathSpec

    from notes import NotesVFS


    class HashedNotesVFS(NotesVFS):
        async def checksum(self, path: PathSpec, algorithm: str) -> str | None:
            if algorithm != "md5":
                return None
            return hashlib.md5(self.page(path).encode()).hexdigest()
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import { createHash } from 'node:crypto'
    import type { PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class HashedNotesVFS extends NotesVFS {
      override async checksum(path: PathSpec, algorithm: string): Promise<string | null> {
        if (algorithm !== 'md5') return null
        return createHash('md5').update(this.page(path)).digest('hex')
      }
    }
    ```
  </Tab>
</Tabs>

A real service returns the hash it stores. This example computes MD5 and
leaves the others to Mirage, so `md5sum /notes/hello.txt` reads nothing, and
`sha256sum /notes/hello.txt` still reads the page.
