`find`, `du`, `ls -R`, `tree`, `grep -r` and `rg` can ask your VFS for a whole
folder tree in one call, instead of listing each folder. Return `None`
(TypeScript: `null`) and Mirage lists each folder.

For example, [S3](/python/vfs/s3) answers `find /data/` from one recursive
listing of the prefix.

## `read_tree`

Every file and folder below one folder.

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    async def read_tree(self, path: PathSpec) -> dict[str, FileStat] | None: ...
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    readTree(path: PathSpec): Promise<Map<string, FileStat> | null>
    ```
  </Tab>
</Tabs>

| Argument | Meaning |
| --- | --- |
| `path` | The folder. |

| Return | Mirage then |
| --- | --- |
| Every file and folder below `path`, keyed by its path below it (`guides`, `guides/start.md`), each with the `FileStat` that `stat` gives | Walks it without listing any folder. |
| `None` | Lists each folder with `readdir`. |

For a path that is not a folder, raise what `readdir` raises.

These commands call `read_tree`:

- `find`
- `du`
- `ls -R`
- `tree`
- `grep -r`, `rg`
- `cp -r` inside the mount, when your VFS overrides `copy`

These list each folder instead:

- `find -maxdepth N`
- `tree -L N`
- `rg --max-depth N`
- `ls` without `-R`
- `cp -r` to another mount

## `walk_limit`

Every walk stops at your VFS's
[`walk_limit`](/home/integration/search#walk_limit), whether
`read_tree` answered or Mirage listed each folder. `read_tree` still returns the
whole tree, and the command keeps what fits. Return `None` for a folder too
large to send in one call: Mirage then stops calling `readdir` once the limit
is spent.

## Example

This example extends `NotesVFS` from [Custom VFS](/home/setup/custom-vfs#example-a-read-only-vfs).
Its pages sit in one folder, so one `readdir` is the whole tree; a service with
nested folders would return them all from one recursive call:

<Tabs>
  <Tab title="Python" icon="/images/python-logo.svg">
    ```python
    from mirage import FileStat, PathSpec

    from notes import NotesVFS


    class TreeNotesVFS(NotesVFS):
        async def read_tree(self, path: PathSpec) -> dict[str, FileStat] | None:
            return {entry.name: entry for entry in await self.readdir(path)}
    ```
  </Tab>
  <Tab title="TypeScript" icon="/images/typescript-logo.svg">
    ```typescript
    import type { FileStat, PathSpec } from '@struktoai/mirage-node'
    import { NotesVFS } from './notes.ts'

    export class TreeNotesVFS extends NotesVFS {
      override async readTree(path: PathSpec): Promise<Map<string, FileStat> | null> {
        return new Map((await this.readdir(path)).map((entry) => [entry.name, entry]))
      }
    }
    ```
  </Tab>
</Tabs>

`find /notes`, `du -a /notes`, `ls -R /notes` and `tree /notes` then call
`read_tree` once. `find /notes -maxdepth 1` lists the folder instead.
