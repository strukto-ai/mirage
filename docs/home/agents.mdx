## Access

Every connection goes to one Mirage server, so they all see the same workspaces and sessions. Most use its HTTP port, 8765 by default.

| Connection | What the agent gets | Reaches the server through |
| --- | --- | --- |
| <img noZoom src="/images/mcp-icon.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[MCP](/home/access/mcp) | A shell and six file tools through an MCP client. | the HTTP port |
| <Icon icon="folder-open" size={14} /> [FUSE](/home/setup/fuse) | The workspace as a local folder, for the agent's own file tools. | a folder the server mounts |
| <img noZoom src="/images/ssh-logo.svg" alt="" style={{ display: 'inline', width: '1em', height: '1em', margin: '0 0.4em 0 0', verticalAlign: '-0.125em' }} />[SSH](/home/access/ssh) | A remote shell, plus file access through SFTP, SCP or SSHFS. | its own SSH port |
| <Icon icon="globe" size={14} /> [HTTP](/home/access/http) or <Icon icon="brackets-curly" size={14} /> [RPC](/home/access/rpc) | An API for running commands and working with files. | the HTTP port |
| <Icon icon="terminal" size={14} /> [CLI](/home/access/cli) | `mirage` commands for workspaces and sessions, and `mirage-bash` as a shell. | the HTTP port |

- **Shell**: the agent's own shell is [`mirage-bash`](/home/access/cli#mirage-bash), so every command it runs goes to the workspace.
- **MCP**: the agent gets Mirage's seven tools beside its own, from its plugin or `mirage mcp`.
- **SSH**: the agent's own tools run in the workspace. Codex needs nothing more; Cursor, VS Code and Antigravity run their server on a [machine](/home/setup/machine/overview): see [Editors over SSH](/home/agents/remote-ssh).
- **FUSE**: the agent's own tools work on the workspace, mounted as a folder.
- **ACP**: an ACP client runs the agent through [`mirage acp`](/home/agents/acp), which answers its file reads and writes from the workspace and hands it Mirage's tools.

Codex can also run in the workspace from a remote harness, through [exec-server forward](/home/agents/codex#exec-server-forward).
