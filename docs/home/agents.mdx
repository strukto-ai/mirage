## Access

These connections work independently of your agent's programming language.

| Connection | What the agent gets |
| --- | --- |
| [MCP](/home/access/mcp) | Shell and file tools through an MCP client. |
| [FUSE](/home/setup/fuse) | A VFS exposed by your own app as a folder its existing file tools can read and write. |
| [SSH](/home/access/ssh) | A remote shell, plus file access through SFTP, SCP or SSHFS. |
| [HTTP](/home/access/http) or [RPC](/home/access/rpc) | An API for running commands and working with files. |
| [CLI](/home/access/cli) | Workspace access through `mirage` commands. |

## Supported agents

### Coding agents

Run the agent as it is, on a workspace the `mirage` CLI creates.

| Agent | Shell | MCP | SSH | FUSE |
| --- | :-: | :-: | :-: | :-: |
| [Claude Code](/home/agents/claude-code) | ✓ | ✓ | | ✓ |
| [Codex](/home/agents/codex) | | ✓ | ✓ | ✓ |
| [Grok Build](/home/agents/grok-build) | | ✓ | | ✓ |

- **Shell**: the agent's own shell is [`mirage-bash`](/home/access/cli#mirage-bash), so every command it runs goes to the workspace.
- **MCP**: the agent adds Mirage's seven tools, from its plugin or `mirage mcp`.
- **SSH**: the agent's own tools run in the workspace.
- **FUSE**: the agent's own tools work on the workspace, mounted as a folder.

Or load Mirage into the agent as a TypeScript plugin, which replaces its own file and shell tools:

| Agent | Plugin |
| --- | --- |
| [Pi Coding Agent](/typescript/agents/pi) | `@struktoai/mirage-pi` |
| [OpenCode](/typescript/agents/opencode) | `@struktoai/mirage-opencode` |
| [DeepSeek Harness](/typescript/agents/dsh) | `@struktoai/mirage-dsh` |
