Mirage provides familiar Unix-style commands over virtual paths, with availability determined by the mount's capabilities and your session's permissions.

Tables list common supported flags; use `man COMMAND` or `COMMAND --help` for the full command reference. Compatibility varies by command, so a familiar name does not imply every option from the original program.

| Command | Purpose | Common flags |
| --- | --- | --- |
| `ls` | List entries | `-l`, `-a`, `-A`, `-h`, `-R`, `-d`, `-t`, `-S`, `-r`, `-F`, `-L`, `--sort` |

| `tree` | Show a directory tree | `-a`, `-d`, `-L DEPTH`, `-I PATTERN`, `-P PATTERN`, `-x` |
| `du` | Count file and directory bytes | `-h`, `-s`, `-a`, `-d DEPTH`, `-c`, `-L`, `-S`, `-x` |
| `df` | Show mount capacity, when available | `-h`, `-H`, `-k`, `-i`, `-a`, `-T`, `-P`, `-B SIZE` |
| `mount` | List configured mounts | `-l`, `-t TYPES` |
| `file` | Identify content type | `-b`, `-i`, `-L`, `-h` |
| `mkdir` | Create directories | `-p`, `-v`, `-m MODE` |
| `touch` | Create files or update timestamps | `-a`, `-m`, `-c`, `-d DATE`, `-r FILE`, `-t TIME`, `-h` |
| `cp` | Copy files or directories, including across mounts | `-r`, `-R`, `-a`, `-L`, `-P`, `-n`, `-u`, `-v`, `-t DIR`, `-T`, `-b`, `-x` |
| `mv` | Move or rename entries | `-f`, `-n`, `-u`, `-v`, `-t DIR`, `-T`, `-b`, `--no-copy`, `--exchange` |
| `rm` | Remove entries | `-r`, `-R`, `-f`, `-v`, `-d`, `-i`, `-I`, `--one-file-system` |
| `rmdir` | Remove empty directories | `-p`, `-v`, `--ignore-fail-on-non-empty` |

| `setfattr` | Set or remove an extended attribute | `-n NAME`, `-v VALUE`, `-x NAME`, `-h` |

## Search and compare

| Command | Purpose | Common flags |
| --- | --- | --- |
| `find` | Select paths and run actions | `-name`, `-iname`, `-path`, `-type`, `-size`, `-mtime`, `-newer`, `-newermt`, `-empty`, `-mindepth`, `-maxdepth`, `-print0`, `-printf`, `-delete`, `-exec`, `-prune`, `-ls`, `-L`, `-xdev` |
| `grep` | Search lines | `-E`, `-F`, `-G`, `-P`, `-i`, `-v`, `-n`, `-r`, `-R`, `-l`, `-c`, `-o`, `-q`, `-e`, `-f`, `-A`, `-B`, `-C`, `--include`, `--exclude` |
| `rg` | Search recursively with path filters | `-i`, `-S`, `-F`, `-n`, `-l`, `-c`, `-g`, `-t`, `-T`, `--hidden`, `--files`, `--json`, `-U`, `-P`, `-z`, `--pre` |
| `search` | Search through a backend's search capability | `--method`, `--top-k`, `--threshold` |
| `diff` | Compare text files or directory trees | `-u`, `-U N`, `-q`, `-r`, `-N`, `-i`, `-w`, `-b`, `-x`, `-X` |
| `cmp` | Compare bytes | `-s`, `-l`, `-b`, `-n N`, `-i SKIP` |
| `patch` | Apply a patch | `-p N`, `-R`, `-i FILE`, `-N` |
| `look` | Find lines with a prefix | `-f` |

`egrep` and `fgrep` invoke `grep` with `-E` and `-F` respectively. Compressed-file search is covered under [Data & Network](/home/core/data-network#archives-and-compression).

| Command | Purpose | Common options |
| --- | --- | --- |

## Limits

- File operations depend on the backend; a read-only mount cannot accept writes. Permission and owner metadata may live in Mirage's overlay rather than the remote service.
- Mount roots are protected from removal, renaming, and use as copy sources. `mount` lists configured mounts; it does not attach new backends.
- `ln -s` creates a virtual symlink. Without `-s`, a regular file is copied; there is no shared hard-link inode.
- `find` supports `-a`, `-o`, `!`, parentheses, and both `-exec ... \;` and `-exec ... {} +`. Tests must precede actions in each AND chain, and OR branches must use the same action. `-newer` and `-newermt` must be in a top-level AND chain. `-execdir` and `-ok` are unsupported.
- `rg` cannot sort by creation time. `ls --color` and `grep --color` are accepted without colored output.
- `xargs -p` and `-o` fail because there is no terminal. `timeout` models signals as task actions; its commands cannot trap OS signals.
