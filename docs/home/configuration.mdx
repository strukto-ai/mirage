Mirage settings live at three levels. A server runs workspaces, and each
workspace runs sessions.

| Level | What it sets | Where you set it |
| --- | --- | --- |
| [Server](/home/configuration/server) | Port, sign-in, rate limits, and the ceilings every workspace stays under | `~/.mirage/config.toml`, `MIRAGE_*` environment variables, or server options in code |
| [Workspace](/home/configuration/workspace) | Mounts, CLIs, runtimes, network, limits, and where state and caches live | `workspace.yaml`, or `Workspace(...)` in code |
| [Session](/home/configuration/session) | What one session can run and see, and its own limits, network, `cwd` and `env` | A profile under `profiles` in `workspace.yaml`, which a session names when it starts |

Limits can be set at all three levels. A profile can raise or lower the
workspace's value, but never past the server's ceiling. See
[Limits](/home/limits).

Credentials for mounts, CLIs and machines, and environment variables, are on
[Service Credentials](/home/credentials).
