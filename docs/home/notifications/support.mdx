Your application receives a notification from a service, tells Mirage which
virtual files changed, and the agent reacts.

## Receive and report changes

`ws` is your Mirage workspace. These functions work with every VFS:

| Action | Python | TypeScript |
| --- | --- | --- |
| Listen for file and directory changes under a path | `ws.events("/data")` | `ws.events('/data')` |
| Tell Mirage that a file or directory changed | `await ws.notify(change)` | `await ws.notify(change)` |

<CodeGroup>
```python Python
async for change in ws.events("/data"):
    print(f"Event: {change.kind.value}")
    print(f"Virtual path: {change.path.virtual}")
```

```typescript TypeScript
for await (const change of ws.events('/data')) {
  console.log(`Event: ${change.kind}`)
  console.log(`Virtual path: ${change.path.virtual}`)
}
```
</CodeGroup>

For example, someone edits `report.csv` in your connected storage. When your
application reports that change, the listener prints:

```text Output
Event: update
Virtual path: /data/report.csv
```

`update` means the existing file's contents or metadata changed.

Start the listener before calling `ws.notify(change)` from your notification
receiver in a separate task. Mirage does not start a file watcher or webhook
server for you.

<CodeGroup>
```python Python
from datetime import datetime, timezone
from mirage.types import FileChangeKind, FileEvent, PathSpec

change = FileEvent(
    kind=FileChangeKind.UPDATE,
    path=PathSpec.from_str_path("/data/report.csv"),
    timestamp=datetime.now(timezone.utc),
)
await ws.notify(change)
```

```typescript TypeScript
import { FileChangeKind, FileEvent, PathSpec } from '@struktoai/mirage-node'

const change = new FileEvent({
  kind: FileChangeKind.UPDATE,
  path: PathSpec.fromStrPath('/data/report.csv'),
  timestamp: new Date(),
})
await ws.notify(change)
```
</CodeGroup>

This reports that `/data/report.csv` was updated. The running listener above prints:

```text Listener output
Event: update
Virtual path: /data/report.csv
```

`notify()` does not print anything or edit the file itself.

The Disk example creates, updates and deletes local files, then prints:

```text Disk output
read before: 'first quarter'

watcher events:
  create /data/reports/q3.txt
  update /data/reports/q1.txt
  delete /data/reports/q2.txt

read after notify: 'first quarter, revised'

```

For S3, a saved `ObjectCreated:Put` notification for `report.csv` in your
configured bucket produces:

```text S3 output

```

## Poll

Fetch changed files from the service, on a schedule or after a notification.
Create `hook` with `vfs.delta_hook()` (Python) or `vfs.deltaHook()` (TypeScript).
Call `await hook.pull(root, checkpoint)`, send each item in `result.changes`
to `ws.notify()`, and save `result.checkpoint` for the next call.
See the [Python and TypeScript examples](#poll-examples).

| VFS | Notification service | Python | TypeScript |
| --- | --- | --- | --- |
| Airtable | [Webhooks API](https://airtable.com/developers/web/api/webhooks-overview) | `vfs.delta_hook()` | `vfs.deltaHook()` |
| Box | [Long-poll events](https://developer.box.com/guides/events/user-events/polling) | `vfs.delta_hook()` | `vfs.deltaHook()` |
| Box | [Events API responses](https://developer.box.com/guides/events/user-events/polling) | `BoxEventHook.to_events` | `BoxEventHook.toEvents` |
| Dropbox | [Webhooks or long polling](https://docs.dropboxapi.com/dropbox-api/docs/detecting-changes) | `vfs.delta_hook()` | `vfs.deltaHook()` |
| Gmail | [Pub/Sub notifications](https://developers.google.com/workspace/gmail/api/guides/push) | `vfs.delta_hook()` | `vfs.deltaHook()` |
| Google Calendar | [Push notifications](https://developers.google.com/workspace/calendar/api/guides/push) | `vfs.delta_hook()` | `vfs.deltaHook()` |
| Google Drive, Docs, Sheets, Slides | [Drive notifications](https://developers.google.com/workspace/drive/api/guides/push) | `vfs.delta_hook()` | `vfs.deltaHook()` |
| OneDrive / SharePoint | [Microsoft Graph notifications](https://learn.microsoft.com/en-us/graph/change-notifications-overview) | `vfs.delta_hook()` | `vfs.deltaHook()` |

For other VFS types, your application can detect changes and report them
directly with `ws.notify()`.
