# dir

Directories. Runs on monty and quickjs on both hosts, wasi on the python host and pyodide on the typescript host. A case with a `backends` list also runs over RAM, disk, ssh, S3
and redis.

| File           | Pins                                                                                                                                                                                                                    | Differs                                                                                                                                                                                       |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `readdir.json` | `os.listdir`, `Path.iterdir` and QuickJS `os.readdir`: a mount, a missing directory (ENOENT), a listing past a failing record, nested mounts and a link to one, a mount point is a directory, the tree above the mounts | monty: the `OSError` (EIO) a failing backend raises has no `strerror`. pyodide: a write above the mounts lands in its own in-memory file system, and a link that aliases a mount is not found |
| `mkdir.json`   | `os.mkdir`, `os.makedirs` and `Path.mkdir`, with their errors                                                                                                                                                           |                                                                                                                                                                                               |
| `rmdir.json`   | `os.rmdir`, `Path.rmdir` and `shutil.rmtree`; a non-empty directory is refused                                                                                                                                          | monty: no `shutil`                                                                                                                                                                            |
| `glob.json`    | `glob.glob` (recursive), `Path.glob`, `Path.rglob`, `os.walk` and `os.scandir`                                                                                                                                          | monty: no `glob`, `Path.rglob`, `os.walk` or `os.scandir`. quickjs: QuickJS has no glob; the case checks it is absent                                                                         |
