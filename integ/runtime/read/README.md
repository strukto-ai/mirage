# read

Reads that reach a mount. Runs on monty and quickjs on both hosts, wasi on the python host and pyodide on the typescript host. A case with a `backends` list also runs over RAM, disk, ssh, S3 and redis, and over RAM, disk and redis with the file cache on.

| File         | Pins                                                                                                                                                                                                                                            | Differs                                                                                                                                                                                                                                                                   |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `read.json`  | `read`, `read_text`, `read_bytes`, line iteration (`getline` in QuickJS) and QuickJS `read` into an `ArrayBuffer`; a read touches only the files it opens; a file over 1 MiB is read in ranges; `mmap` of a mounted file is refused with ENODEV | monty: file objects are not iterable, and there is no `glob` module. On S3 a second read comes from the cache. The host entry point's ledger records every read it asks for, a cached one too. wasi: no `mmap` module in its build. host: the file has no `fileno` to map |
| `pread.json` | `seek` then `read(n)`, a seek from the end and past it, `os.pread` leaving the position alone, reads across a 1 MiB chunk edge, a seek before the start refused with EINVAL                                                                     | monty: no `os.open`, `os.pread` or `os.lseek`; `seek` and `tell` work.                                                                                                                                                                                                    |
| `readv.json` | `os.readv` fills its buffers in order and moves the position, `os.preadv` reads at an offset and leaves it; node's `FileHandle.readv` on the host                                                                                               | monty: no `os.open`. wasi: no vectored calls in its build. pyodide: no `os.preadv`. quickjs: no vectored reads                                                                                                                                                            |
| `seek.json`  | `readline`, `tell`, `seek` from each whence in text and binary, `readlines` and line iteration; `os.lseek` from each whence; QuickJS `getline`, `seek`, `tell`, `getByte` and `eof`, and `os.seek`; node's positioned `read` and `readLines`    | monty: a file is not iterable, and there is no `os.open`                                                                                                                                                                                                                  |
