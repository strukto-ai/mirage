# program

What one guest program gets from the line that runs it, the same on every
runtime that runs programs.

| File          | Pins                                                                                                                                                                                                                                                                                          | Runs on                                                                                                                                                                      |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `argv.json`   | `sys.argv` for a `-c` program with arguments                                                                                                                                                                                                                                                  | wasi, local, sandlock                                                                                                                                                        |
| `input.json`  | input read as it arrives, as from a pipe: a program that reads one line of an endless writer, or none, ends at once; input over 1 MiB from a file on each backend, redirected and piped, read whole and a line at a time                                                                      | wasi, pyodide, quickjs, local; the backend case on monty too, whose input arrives whole as the `stdin` global (it has no `sys.stdin`), so it cannot take an endless writer's |
| `output.json` | stdout through a pipe to `grep`; an endless writer stopped once its reader has enough; output kept and the runtime reusable after a failure; closed stdout and stderr, binary output, an exit code after close; over 1 MiB of output redirected into a file on each backend, then appended to | monty, wasi, pyodide, quickjs, local; the closed-output case on wasi, pyodide and local (Monty's `sys.stderr` has no `write`)                                                |
| `eval.json`   | a one-line program prints its result                                                                                                                                                                                                                                                          | monty, wasi, pyodide, quickjs, local                                                                                                                                         |
