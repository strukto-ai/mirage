# path

Calls on one path: its metadata, its name and its links. Runs on monty and quickjs on both hosts, wasi on the python host and pyodide on the typescript host. Link
calls run on wasi and pyodide only: QuickJS builds without them and Monty
has none. A case with a `backends` list also runs over RAM, disk, ssh, S3 and redis.

| File           | Pins                                                                                                                                               | Differs                                                                                                                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `stat.json`    | `os.stat` fields and tuple form, `Path.stat`, `is_file`, `is_dir`, `exists`, the root, a stat after a refused read                                 | monty (ts): no tuple form. wasi, pyodide and quickjs: the root has `nlink` 1 (2 on Linux). wasi and quickjs (py): directories carry no permission bits, and quickjs (py) `std.open` opens a directory |
| `rename.json`  | `os.rename`, `os.replace`, `Path.rename` and `shutil.move`; a rename across mounts or into a nested mount is EXDEV and leaves both sides           | monty: no `shutil`, and no `errno` to name EXDEV. wasi and quickjs: across mounts fails with ENOENT, not EXDEV                                                                                        |
| `unlink.json`  | `os.remove` and `Path.unlink`; a missing file and a directory are refused                                                                          | monty and wasi: unlinking a directory on RAM or redis raises `FileNotFoundError`, not `IsADirectoryError`                                                                                             |
| `symlink.json` | `os.symlink`, `os.readlink` (EINVAL and ENOENT), `os.lstat`, `os.path.islink`, `Path.is_symlink`, `os.scandir`, renaming a link                    | pyodide: a link that aliases a mount is not found                                                                                                                                                     |
| `link.json`    | `os.link` is refused with EPERM                                                                                                                    | pyodide: no `os.link`                                                                                                                                                                                 |
| `utime.json`   | `os.utime`, also with `follow_symlinks=False`, `os.chmod`, and QuickJS `os.utimes`                                                                 | wasi: `os.chmod` does nothing. pyodide: `utime(follow_symlinks=False)` raises `NotImplementedError`                                                                                                   |
| `xattr.json`   | `os.getxattr`, `setxattr`, `listxattr` and `removexattr` round trip with the shell; only pyodide has them, and the others are checked to lack them |                                                                                                                                                                                                       |
| `cwd.json`     | the shell's `cd` reaches the guest, relative paths resolve in every call, `os.chdir` stays in the guest                                            | monty: a module attribute cannot be reassigned, and on ts `os.chdir` fails (the host must return a `stat_result`). wasi and quickjs (py): `getcwd()` after `chdir('..')` keeps the `..`               |
