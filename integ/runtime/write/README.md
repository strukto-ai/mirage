# write

Writes that reach a mount. Runs on monty and quickjs on both hosts, wasi on the python host and pyodide on the typescript host. A case with a `backends` list also runs over RAM, disk, ssh, S3 and redis, and over RAM, disk and redis with the file cache on.

| File            | Pins                                                                                                                                                                                                                                                                  | Differs                                                                                                                                                                                                                                                                                         |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `write.json`    | `write_text`, `write_bytes` and `write` reach the mount; a loop of small writes reaches it as one op; a read-only mount refuses with EROFS; a mount at `/` is served like any other                                                                                   | monty: each write is its own op, since the engine gives the entry point no close to gather a file's writes at, so on S3 a write loop rewrites the object once per write. pyodide: a mount at `/` is not served. host: the ledger records the ops the entry point asked for, on S3 and redis too |
| `pwrite.json`   | `os.pwrite` writes at an offset, and a write past the end leaves zeros in the gap                                                                                                                                                                                     | monty: no `os.pwrite`. On S3 and redis a `pwrite` is a read and a whole write                                                                                                                                                                                                                   |
| `writev.json`   | `os.writev` writes its buffers in order and `os.pwritev` at an offset; node's `FileHandle.writev` on the host                                                                                                                                                         | monty: no `os.open`. wasi: no vectored calls in its build. pyodide: no `os.pwritev`. quickjs: no vectored writes                                                                                                                                                                                |
| `truncate.json` | `truncate` cuts a file, a write past the cut leaves zeros, `os.truncate` needs no handle, `os.ftruncate` cuts through a descriptor, and `os.truncate` of a missing file is ENOENT                                                                                     | monty: no `os.truncate`                                                                                                                                                                                                                                                                         |
| `exit.json`     | a file still open at exit, or when `timeout` stops the program, lands on the mount, and a caught `os._exit` still ends it: nothing after reaches the mount or the output                                                                                              |                                                                                                                                                                                                                                                                                                 |
| `sync.json`     | `os.fsync` lands a descriptor's writes before its close, and a second open sees them before they land; node's `FileHandle.sync` and `datasync` on the host                                                                                                            | monty: no `os.open`                                                                                                                                                                                                                                                                             |
| `parallel.json` | four sessions writing one file at once: their offset writes and their appends all land, on stores that write in place and on those that read and write back the whole file                                                                                            | monty: no `os.pwrite`                                                                                                                                                                                                                                                                           |
| `order.json`    | two descriptors on one file: the later write wins where the two overlap and the earlier one keeps the rest, however they close                                                                                                                                        | monty: no `os.open`                                                                                                                                                                                                                                                                             |
| `fd.json`       | `os.open` with `O_CREAT`, `O_EXCL`, `O_APPEND` and `O_RDWR`, `os.write`'s count, `os.lseek`, `os.fsync`, `os.ftruncate` and `os.fstat`; QuickJS `os.open`, `os.write`, `os.seek` and `os.close`; node's `wx`, `appendFile`, positioned `write`, `sync` and `truncate` | monty: no `os.open`. quickjs: no `fsync` or `ftruncate` in `os`                                                                                                                                                                                                                                 |
