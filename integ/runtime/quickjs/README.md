# quickjs

What only QuickJS has.

| File          | Pins                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `print.json`  | `print` and `puts` write raw; `printf`, more `printf` conversions                                                                                                                                                                                                                                                                                                                                 |
| `argv.json`   | a stdin operand; typed argv that names no mount                                                                                                                                                                                                                                                                                                                                                   |
| `invoke.json` | `--version` for `js` and `node`, stdin, module mode, classic scripts at `/`, errors, no Node globals, a missing script                                                                                                                                                                                                                                                                            |
| `async.json`  | jobs past an `await` reach the mount; an error in one, or a rejected module, fails the run                                                                                                                                                                                                                                                                                                        |
| `std.json`    | `std` and `os` as qjs runs them on WASI, which both hosts run, against its own output: globals, signals, `strerror`, the environment, `writeFile`, `loadFile`, `fdopen`, every `FILE` call, `evalScript`, `loadScript`, `os.sleep`; the standard streams as descriptors 0 to 2; timers and read handlers once the script ends. Not pinned: `bjson` and top-level `await` in an async `evalScript` |
