# quickjs

What only QuickJS has.

| File          | Pins                                                                                              |
| ------------- | ------------------------------------------------------------------------------------------------- |
| `print.json`  | `print` and `puts` write raw; `printf`, more `printf` conversions                                 |
| `policy.json` | policy scripts in JavaScript: a file read, a deny, an entry script                                |
| `argv.json`   | a stdin operand; typed argv that names no mount                                                   |
| `invoke.json` | `--version` for `js` and `node`, stdin and module mode, errors, no Node globals, a missing script |
